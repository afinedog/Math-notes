## 边值问题的弱形式

- **经典两点边值问题**：$-\dfrac{d^2u}{dx^2} = f，x\in (0,1)$，边值 $\begin{cases} u(0) = 0 \\ u'(1) = 0 \end{cases}$
- **推导**：
  - 设函数 $v(0) = 0$，则 $L^1$ 内积 $(f,v) = \dis\int^1_0 fvdx = -\int^1_0 u''vdx = \int^1_0 u'v'dx$
  - 设右式为泛函 $a(u,v)$，$V = \hkh{v\in L^2(0,1)\bigm| a(u,v) < \infty，v(0) = 0}$
