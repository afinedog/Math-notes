# 变分问题的数值解法


## Ritz-Galekin法

- **思想**：先在有穷维子空间求解，再逼近无穷维
- **符号约定**：
  - $U$ 表示满足本质边值条件的索伯列夫空间
  - $L$ 是微分算子，$a(u,v)$ 是（方程分部积分 + 边值代入）后求出的双线性泛函
  - 设 $U_n$ 是 $U$ 的 $n$ 维子空间，$\p_1,...,\p_n$ 是 $U_n$ 的一组基函数，线性表出式 $u_n = \sum\limits^n_{i=1} c_i\p_i$
- **Ritz法**：
  - **思想**：根据最小势能原理，用求偏导的方法，选取系数使得 $J(u_n)$ 取极小值
  - **推导**：
    - 由双线性分解得 $J(u_n) = \dfrac{1}{2}\sum\limits^n_{i,j=1} a(\p_i,\p_j)c_ic_j - \sum\limits^n_{j=1} c_j(f,\p_j)$
    - 易得驻点方程组 $\dpfrac{J(u_n)}{c_j} = 0$ 可化为 $\sum\limits^n_{i=1} a(\p_i,\p_j)c_i = (f,\p_j)，j=1,...,n$
    - 该线性方程组的解就是 $U_n$ 上的最小值
  - <font color='chartreuse'>不难发现它就是最小二乘问题的法方程（二次型最优化问题的解）</font>
- **Galekin法**：
  - **思想**：根据虚功原理得到 $U_n$ 上的方程 $a(u_n,v_n) = (f,v_n)$
  - **推导**：
    - 设 $u_n = \sum\limits^n_{i=1}c_i\p_i$
    - 分别取 $v_n = \p_1,...,\p_n$ 可得 $\sum\limits^n_{i=1} a(\p_i,\p_j)c_i = (f,\p_j)，j=1,....,n$

### 解的存在唯一性

- **R-G存在唯一定理**：
  - 设 $f\in L^2$
  - 则 $\forall v_n\in U_n$，方程 $a(u_n,v_n) = (f,v_n)$ 在 $U_n$ 上存在唯一解
  - **证明**：
    - 只需证明法方程的系数矩阵满秩即可
    - 由 $a$ 的双线性 + 正定性 + 基的线性无关性，定义反证易得满秩
  - **推论**：系数矩阵 $A$ 对称正定

### 解的收敛性

- **符号约定**：
  - $\|\cdot\|_m$ 表示 $H^m$ 的范数
  - $\|\cdot\|_E$ 表示能量范数 $\|u\|_E = \sqrt{a(u,u)}$
- **Ritz误差估计（索伯列夫范数）**：
  - 设 $u$ 是变分问题的解，$u_n$ 是Ritz方法的解
  - 则存在与 $u,n$ 无关的常数 $\e > 0$ 使得 $\|u-u_n\|_1 \leq \e\inf\limits_{v\in U_n} \|u-v\|_1$
  - <font color='red'>这里的 $\e$ 应当取足够小的数</font>
  - **证明**：
    - 由解性得 $\forall v_n\in U_n$ 都有 $\begin{cases} a(u-u_n,u_n) = 0 \\ a(u,v_n) = (f,v_n) \\ a(u_n,v_n) = (f,v_n) \end{cases}$
    - 再由 $a$ 的正定性 + 范数的连续性得存在 $\g > 0$ 使得 $$\|u-u_n\|_1^2 \leq \frac{1}{\g}a(u-u_n,u-u_n) = \frac{1}{\g}a(u-u_n,u) = \frac{1}{\g}a(u-u_n,u-v_n)$$
    - 再由 $a$ 的连续性即得 $a(u-u_n,u-v_n) \leq M\|u-u_n\|_1\|u-v_n\|_1$
    - 综上，取 $\e = \dfrac{M}{\g}$ 即可
  - <font color='red'>注意这里用到了 $a$ 的正定性，所以不能用于Galekin法的误差估计
  - 但是Galekin法一般要求满足强制性，即 $a(u,u) \geq \a \|u\|^2$，此时也能得到相同结论</font>
  <!-- - **理解**：
    - 通过解性转化，通过连续性放缩 -->
- **Ritz收敛定理**：若 $\{\p_i\}^\infty_{i=1}$ 的线性组合在 $U$ 上稠密，则Ritz法的解收敛
  - **证明**：
    - 由稠密性得任意 $\e$ 都有线性组合系数 $\{d_i\}$ 满足 $\|u-\sum\limits^m_{i=1} d_i\p_i \|_1 < \dfrac{\e}{\b}$
    - 再由引理即得 $\|u-u_n\|_1 \leq  \b\dfrac{\e}{\b} = \e$

### 其它误差估计式

- **等价定理**：
  - 设 $V$ 是Hilbert空间，$a$ 是其上的双线性泛函
  - 若 $a$ 满足
    - **强制性**：$\forall v\in V，\exists \a > 0$ 使得 $a(v,v) \geq \a \|v\|^2_V$
    - **连续性**：$\forall u,v\in V，\exists M > 0$ 使得 $a(v,v) \leq M \|u\|_V\|v\|_V$
  - 则内积范数和能量范数等价
  - **证明**：显然
  - **实例**：
    - 当 $a(u,v) = \dis\int (p\nabla u\nabla v + quv)$ 时，对称正定，故等价
    - 当 $a(u,v) = \dis\int \nabla u\nabla v$ 时，$\|u\|_E = \|\nabla u\|_0$，在 $H^1$ 上只是半范数，更弱
      - <font color='red'>但由庞加莱不等式，$H^1_0$ 上范数可被半范数控制，此时等价</font>
- **Ritz误差估计（能量范数）**：
  - 设 $u$ 是边值问题的解，$u_n$ 是Ritz方法的解
  - 则 $\|u-u_n\|_E = \min\limits_{v\in U_n} \|u-v\|_E$
  - <font color='red'>估计式证明都要用 $a$ 的C-S不等式，所以能量范数估计式比索伯列夫范数更简洁
  - 在椭圆方程的边值问题中，两个范数相互等价。但其它方程可能不一样</font>
  - **证明**：
    - 由解性得同上的三个等式
    - 再由连续性即得 $$\hspace{-0.8em}\|u-u_n\|_E^2 = a(u-u_n,u-u_n) = a(u-u_n,u-v_n) \leq \|u-u_n\|_E\|v-v_n\|_E$$
      - <font color='red'>注意这里用了C-S不等式，依赖于 $a(u,v)$ 的正定性</font>
    - 再由解的存在唯一性即得最小值可以取到
- **Ritz误差估计（半范数）**：
  - 设 $u$ 是边值问题的解，$u_n$ 是Ritz方法的解
  - 则存在与 $u,n$ 无关的常数 $\e > 0$ 使得 $\|u-u_n\|_0 \leq \e^2 \|f\|_0$
  - **证明**：
    - 设 $w$ 是两点边值问题 $Lw = u-u_n，x\in (a,b)，\begin{cases} w(a) = 0 \\ w'(b) = 0 \end{cases}$ 的解
    - **第一不等式**：
      - **不等式1**：
        - 此时 $$\|u-u_n\|^2_0 = (u-u_n,u-u_n) = (u-u_n,Lw)$$
        - 由边值条件分部积分得右端可化为 $a(u-u_n,w)$
        - 再由解性即得 $\forall v\in U_n$ 都有 $右端 = a(u-u_n,w-v) $
        - 再由C-S不等式即得 $$ \|u-u_n\|^2_0 \leq \|u-u_n\|_E\|w-v\|_E $$
        - 即 $\|u-u_n\|_0 \leq \cfrac{\|u-u_n\|_E\|w-v\|_E}{\|w''\|_0}$
      - **不等式2**：
        - 再由范数正定性，可取 $v$ 足够接近 $w$，从而 $\inf\limits_{v\in U_n}\|w-v\|_E \leq \e \|w''\|_0$
      - **综合不等式**：
        - 综合上面两个不等式即得 $\|u-u_n\|_0 \leq \e \|u-u_n\|_E$
    - **第二不等式**：
      - 再由范数正定性 + 连续性得 $\inf\limits_{v\in U_n}\|u-v\|_E \leq \e \|Lu\|_0$
      - 再由能量范数收敛引理即得 $\|u-u_n\|_E \leq \e \|Lu\|_0 $
    - **右端不等式**：
      - 综合第一、第二不等式即得结论

### 边值条件的齐次化

- **非齐次边值条件**：
  - 对于非齐次的自然边值条件，应当修改右端项 $(f,\p_j)$
  - 对于非齐次的本质边值条件，应当修改基函数 $u_n$ 后再使用R-G方法
  - <font color='red'>根据齐次情况的讨论，我们发现用到边值条件的地方只有证明边界项为零
    - 边值融入能量泛函：只需 $puu'|^b_a = 0$
    - Ritz法的最小势能原理：只需 $pu'v|^b_a = 0$
    - Galekin法的乘试探函数分部积分：只需 $pu'v|^b_a = 0$</font>
- **实例**：
  - 前面的两点边值问题，当边值条件为 $\begin{cases} u(a) = \a \\ u'(b) = \b \end{cases}$ 时
    - **自然边值**：R-G方程右端改为 $(f,\p_j) + p(b)\b \p_j(b)$
    - **本质边值**：
      - 基函数改为 $u_n(x) = u_\a(x) + \sum\limits^n_{i=1} c_i\p_i(x)$
        - 其中 $\p_i(a) = 0，u_\a(x)$ 是任意满足 $u_\a(a) = \a$ 的函数
    - **R-G方程**：$$\sum\limits^n_{i=1} a(\p_i,\p_j)c_i = (f,\p_j) + p(b)\b\p_j(b) - a(u_\a,\p_j)$$
    - <font color='chartreuse'>二维边值问题的 $u_0(x)$ 难以直接写出，只能用插值法给出近似函数</font>

## 傅立叶谱方法

- **符号约定**：
  - $H^m(0,2\pi)$ 是 $(0,2\pi)$ 上复变函数的索伯列夫空间
  - $H^m_p(0,2\pi)$ 是其中 $2\pi$ 周期函数构成的子空间
  - **内积**：$(f,g)_m = \dis\int^{2\pi}_0 \sum^m_{s=0} f^{(s)}\ol g^{(s)}dx$
  - **范数**：内积范数
  - 设 $(f,g) = (f,g)_0，\|f\| = \|f\|_0$
- **谱方法引理**：
  - 设 $f\in H^m(0,2\pi)$，$f_N$ 是傅里叶级数在 $-K,K$ 之间的部分和
  - 则 $\forall 0\leq s\leq m$，存在 $C$ 使得 $\|f(x) - f_N(x)\|_s \leq CN^{s-m}\|f\|_m$
  - **证明**：
    - 设 $\wt f(k)$ 是傅里叶系数 $\dfrac{1}{2\pi}(f,e^{ik\pi})$
    - 对傅里叶级数两端求广义导数得 $\dfrac{d^sf(x)}{dx^s} = \sum\limits^\infty_{k = -\infty} \wh f(k)(ik)^s e^{ikx}，0\leq s\leq m$
    - 再由正交性易得 $$\norm{\frac{d^sf(x)}{dx^s}}^2 = \int^{2\pi}_0 \dkh{\sum^\infty_{j = -\infty} \wh f(j)(ij)^s e^{ijx}}\dkh{\sum^\infty_{k = -\infty} \wh f(k)(ik)^s e^{ikx}}dx \\\ \\ = 2\pi\sum^\infty_{k = -\infty} k^{2s}|\wh f(k)|^2 $$
    - 即 $$\cfrac{d^j(f-f_N)}{dx^j} = \cfrac{d^j}{dx^j}\sum_{|n| > N} |\wh f(n)|^2 n^{2(j-m)}n^{2m} \leq 2\pi N^{2(j-m)}\sum_{|n| > N} |\wh f(n)|^2n^{2m} \\ \ \\ \leq N^{2(j-m)}\norm{\frac{d^m f}{dx^m}}^2$$
- **谱方法定理**：
  - 设 $U_N = \span\{e^{ikx}\}^N_{k=-N}$，$P_N:H\to U_N$ 是 $L^2$ 投影算子
  - 则 $\forall f\in H$，存在唯一的 $f_N = P_Nf\in U_N$ 满足 $\forall v\in U_N，(f_N,v) = (f,v)$
- **实例**：
