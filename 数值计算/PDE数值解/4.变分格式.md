# 偏微分方程边值问题的变分格式（弱形式）

## 变分法原理（最小势能原理）

### 经典变分问题（最速降线问题）

- **物理问题**：给定起点 $A(0,0)$ 和终点 $B(x_1,y_1)$，求小球只在重力作用下，沿什么曲线的坡下降速度最快
- **数学模型**：
  - 由机械能守恒，$mgy = \dfrac{1}{2}mv^2$，即 $v = \sqrt{2gy}$
  - 由数分知识，弧长微元 $ds = \sqrt{1+(y')^2}dx$
  - 由定义得时间微元 $dt = \dfrac{ds}{v}$，总时间 $T = \dis\int^{x_1}_0 dt = \int^{x_1}_0 \frac{\sqrt{1+(y')^2}}{\sqrt{2gy}}dx$，要求函数 $y(x)$ 使得 $T$ 最小

### 最小势能原理

- **变分原理（欧氏空间）**：设矩阵 $A$ 对称正定，$J(\bs x) = \dfrac{1}{2}x^TAx - b^Tx$，则下列两问题等价
  - **极值问题**：求 $\bs x_0\in \R^n$ 使得 $J(\bs x_0) = \min\limits_{\R^n} J(\bs x)$
  - **线性方程组问题**：求方程组 $Ax = b$ 的解
  - **证明**：详见数值线性代数
  - <font color='chartreuse'>在物理中，变分原理又称为最小势能原理。$J$ 表示能量</font>
  - <font color='red'>将这个思想从欧氏空间推广到函数空间，就能得到变分问题的解法
  - 再由于我们是为了求解特定的微分方程，故函数空间应当满足一些要求。为此我们提出了索伯列夫空间
    - 由于微分方程存在边值条件，故需要对索伯列夫空间的函数加上边值限制
    - 用分部积分公式 + 边值条件处理时，必须保证函数和导数的积分有意义，故索伯列夫空间要求函数和导数都 $p$ 阶可积</font>
- **变分原理（索伯列夫空间）**：
  - 设 $y(x)$ 是函数，泛函 $J[y] = \dis\int^b_a F(x,y,y')dx$
  - 则下列两问题等价
    - **变分问题**：求 $J[y]$ 在索伯列夫空间的极小值点
    - **欧拉-拉格朗日方程**：求 $\dpfrac{F}{y} - \dfrac{d}{dx}\dpfrac{F}{y'} = 0$ 的解
    - <font color='red'>一般来说需要给索伯列夫空间和E-L方程再加入边值条件限制，否则可能不存在极小值点，或方程存在无穷多解</font>
  - **证明**：
    - <font color='chartreuse'>仿照数值线性代数的扰动法即可，详细过程在后面的两点边值问题中</font>
  - <font color='red'>它有两个应用场景：
    - 理论物理中常将物理问题建模为数学上的变分问题，然后转化为求解E-L微分方程
    - 计算数学中常将偏微分方程的边值问题转化为变分问题，然后再用数值法求解</font>

## E-L方程法求解变分问题

### 最速降线问题

- **变分问题**：求 $y$ 使得 $T[y] = \dis\int^{x_1}_0 \frac{\sqrt{1+(y')^2}}{\sqrt{2gy}}dx$ 最小
- **E-L方程的化简**：
  - 由链式法则，E-L方程两边对 $y$ 积分得 $F-y'\dpfrac{F}{y'} = C$
  - 代入 $F = \cfrac{\sqrt{1+(y')^2}}{\sqrt{y}}$ 后计算得 $\cfrac{1}{\sqrt{y}\sqrt{1+(y')^2}} = C$
  - 两边平方后变形可写为 $y(1+(y')^2) = 2a$
- **求解隐式ODE（参数法）**：
  - 设 $y' = \cfrac{1}{\tan\frac{\t}{2}}$，则可化为 $y = a(1-\cos\t)$
  - 将上式微分得 $dy = a\sin\t d\t$，从而 $dx = \dfrac{dy}{y'} = a(1-\cos\t)d\t$
  - 两边积分得 $x = a(\t - \sin\t) + C$，从而得到参数解（摆线）
  - 最后由初值条件得 $C = 0$

### 弦平衡问题

- **物理问题**：设弦长度为 $l$，两端固定在 $A(0,0)$ 和 $B(l,0)$
  - 当有强度为 $f(x)$ 的外荷载垂直向下作用在弦上，$u(x)$ 表示弦的平衡位置，$T$ 表示弦的张力
- **边值问题**：力学原理得平衡位置满足 $\begin{cases} -Tu'' = f(x)\quad 0<x<l & 微分方程 \\\\ u(0) = 0，u(l) = 0 & 边值条件\end{cases}$
- **变分问题**：由最小势能原理，平衡位置的总势能最小
  - 应变能 $W_内 = \dis\frac{1}{2}\int^l_0 Tu'(x)^2dx$
  - 外力功 $W_外 = -\dis\int^l_0 fudx$
  - 总势能 $J(u) = W_内 + W_外$，只需求该泛函的最小值即可
  - <font color='chartreuse'>求值的前提是这些数学公式都有意义</font>
- **选取索伯列夫空间**：
  - 当 $f\in H^0(I)，u\in H^1(I)$ 时，势能 $J(u)$ 恒有意义
  - 设 $H^1(I)$ 中全体满足齐次边值条件的函数为 $H^1_0(I)$，则变分问题可描述为求 $u\in H^1_0$ 使得 $J(u_*) = \min\limits_{u\in H^1_0} J(u)$
- **Lp内积形式（双线性泛函）**：由边值条件 + 分部积分公式易得 $$ J(u) = \frac{1}{2}(Lu,u) - (f,u)$$



## Sobolev空间

### 弱导数

- **紧支光滑函数类**：设 $C^\infty_0(I)$ 表示区间 $I$ 上无穷阶可微，且在边界某邻域上为 $0$ 的函数
- **弱导数**：<font color='chartreuse'>用分部积分定义的导数</font>
  - 设 $f\in L^2(I)$，若存在 $g\in L^2(I)$ 满足 $\forall \p\in C^\infty_0(I)$ 都有 $$ \int^b_a g(x)\p(x) dx =  -\int^b_a f(x)\p'(x)dx $$，则称 $g$ 是 $f$ 在 $I$ 上的弱导数
  - **实例**：$f(x) = |x|$ 的弱导数为 $g(x) = \begin{cases} -1 & [-1,0) \\ 1 & [0,1] \end{cases}$
  - **a.e.唯一性**：同一函数的弱导数几乎处处相等
    - **证明**：由下面的变分法基本引理直得
  - **存在条件**：$f$ 存在弱导数 $\LR f \ae$ 绝对连续，且导数可积
  - **反例（阶梯函数不存在弱导数）**
    - **证明**：
      - 设 $I = [-1,1]$，$f = \begin{cases} 0 & [-1,0] \\ 1 & (0,1) \end{cases}$
      - 设 $g$ 是 $f$ 的弱导数，则 $$\forall \p\in C^\infty_0(I)，\int^1_{-1} g(x)\p(x)dx = -\int^1_0 \p'(x)dx = \p(0)$$
      - 即 $g(x)$ 是狄拉克函数。<font color='chartreuse'>下面证明它不在 $L^2(I)$ 中</font>
      - 取磨光子 $\p_\e = \begin{cases} e^{\dfrac{1}{(x/\e)^2-1}} & |x|<\e \\\\ 0 & 其它 \end{cases}$
        - 易得积分范数 $\lim\limits_{\e\to 0}\|\p_\e\|_{L^2} = 0$
        - 再易得 $\p_\e(0) = \dfrac{1}{e}$
        - 再由积分C-S不等式 $|\p_\e(0)| \leq \|g\|\|\p_\e\|$
        - 显然上面三个条件在 $\e\to 0$ 时矛盾
- **变分法基本引理**：
  - 设 $f\in L^2(I)$
  - 若 $\forall \p\in C^\infty_0(I)$ 都有 $\dis\int^b_a f(x)\p(x)dx = 0$，则 $f(x) = 0 \ae$
  - **证明（连续函数空间）**：
    - <font color='chartreuse'>当 $f\in C(\ol I)$ 时有 $f \equiv 0$</font>
    - 反设 $f(x_0) > 0$，则由连续性，$f$ 在某个邻域 $O(x_0,\eta)$ 也为正，
    - 再取以其为支集的光滑正值函数 $\p(x) = \begin{cases} e^{\dfrac{1}{(x-x_0)^2-\eta^2}} & |x-x_0|<\eta \\\\ 0 & 其它 \end{cases}$ 即得矛盾

### 索伯列夫空间

- **一般表示**：$W^{m,p} = \hkh{f\in L^p(I)\mid f',...,f^{(m)}\in L^p(I)}$
- **常用表示**：$H^m = W^{m,2}$
  - <font color='red'>在 $p=2$ 时，索伯列夫空间有许多优良的性质
    - 仅当 $p=2$ 时是内积空间
    - 能量一般为函数的平方积分
    - 傅里叶级数收敛，Parseval定理成立</font>

### 直线上二次积分的Sobolev空间（1阶2次方）

- **符号约定**：$f'$ 表示弱导数
- **1阶Sob空间**：$H^1(I) = \hkh{f\in L^2(I)\mid f'\in L^2(I)}$
  - **内积**：$(f,g)_1 = \dis\int^b_a [fg+f'g']dx$
  - **完备性**
- **m阶Sob空间**：$H^m(I) = \hkh{f\in L^2(I)\mid f',...,f^{(m)}\in L^2(I)}$
  - **内积**：$(f,g)_m = \dis \int^b_a \sum^m_{k=0} f^{(k)}g^{(k)}dx$
  - **完备性**

### 平面上二次积分的Sobolev空间（2阶2次方）

- **弱偏导数**：定义同弱导数，用 $f_x,f_y$ 等表示
- **1阶Sob空间**：$H^1(I) = \hkh{f\in L^2(G)\mid f_x,f_y\in L^2(G)}$
  - **内积**：$(f,g)_1 = \dis\int^b_a [fg + f_xg_x + f_yg_y]dx$


## 变分法求解偏微分方程

### 两点边值问题

- **微分方程**：$Lu = -\dfrac{d}{dx}(p\dfrac{du}{dx}) + qu = f，x\in (a,b)$
  - <font color='red'>显然线性微分方程 $Lu = f$ 对应的二次泛函为 $J(u) = \dfrac{1}{2}(Lu,u) - (f,u)$</font>
  - **边值条件**：$u(a) = 0，u'(b) = 0$
  - **其它条件**：
    - $\ol I = [a,b]，f\in H^0(I)$
    - $p\in C^1(\ol I)，p(x) \geq \min\limits_{x\in I}p(x) > 0$
    - $q\in C(\ol I)，q\geq 0$
- **二次泛函**：设 $a(u,v) = \dis\int^b_a \Big[ p\frac{du}{dx}\frac{dv}{dx} + quv \Big]dx$，则由边值条件 + 分部积分公式易得 $$J(u) = \frac{1}{2}a(u,u)-(f,u)$$
  - <font color='red'>易得 $a(u,v)$ 是双线性泛函（函数内积），且满足对称性、正定性、连续性（有界性）
  - 它实际上就是索伯列夫空间内积的变体</font>
- **变分问题**：
  - 设 $H^1_E$ 是 $H^1$ 中满足左边值条件 $u(a) = 0$ 的全体函数
  - 则只需求 $u_*\in H^1_E$ 使得 $J(u_*) = \min\limits_{u\in H^1_E} J(u)$
- **变分法原理（最小势能原理）**：
  - 设 $f\in C(I)$
  - 若 $u_*\in C^2$ 是上述边值问题的解，则它是 $J$ 的极小值点
  - 若 $u_*\in C^2\cap H^1_E$ 是 $J$ 的极小值点，则它是边值问题的解
  - **证明（1）**：
    - <font color='red'>任取 $v\in H^1_E$，考虑 $\p(\l) = J(u_*+\l v)$
      - 展开计算得 $\p(\l) = J(u_*) + \l\Big[ a(u_*,v) - (f,v) \Big] + \dfrac{\l^2}{2}a(u,v)$
      - 由正定性，第三项恒正，故只需证明第二项非负即可</font>
    - 易得 $a(u_*,v) - (f,v) = \dis\int^b_a (pu_*'v' + qu_*v - fv)dx$
    - 对第一项分部积分（积 $v$）可化为 $pu_*'v|^b_a + \dis\int^b_a\fkh{-(pu_*')' + qu_* - f}vdx$
    - 代入泛定方程 + 边值条件 + $v$ 的定义即得上式为零
  - **证明（2）**：
    - 由上面推导得 $\forall v\in H^1_E，a(u_*,v)-(f,v) = 0$
    - **解性**：
      - 取 $v\in C^\infty_0(I)$，则它在边界处为零，故上式变为 $\dis\int^b_a [Lu_*-f]vdx = 0$
      - 再由变分法基本引理即得 $u_*$ 是方程的解
    - **边值性**：
      - 由 $H^1_E$ 定义得 $u$ 必须满足左边值条件
      - 由解性得 $\forall v\in H^1_E$，$p(b)u'_*(b)v(b) = 0$
        - 再由 $p(b) > 0$，取 $v(b) > 0$ 即得 $u_*'(b) = 0$，即 $u_*$ 必须满足右边值条件
- **古典解**：二次连续可微解
  - <font color='chartreuse'>边值问题不一定存在古典解</font>
- **广义解**：连续且按段连续可微的解
  - **实例**：弦平衡问题
  - <font color='chartreuse'>广义解不满足最小势能原理</font>
- **强制边值条件**：无法通过极值条件推出，故必须加入到变分问题的索伯列夫空间限制中
  - <font color='chartreuse'>比如上面的左边值条件</font>
- **自然边值条件**：可以通过极值条件推出，故不必加入变分问题的索伯列夫空间限制中
  - <font color='chartreuse'>比如上面的右边值条件</font>

## 变分法原理（虚功原理）

- <font color='red'>虚功原理和最小势能原理虽然形式上相像，但它们实际是完全不同的两条道路
  - 最小势能原理是转化为优化问题，它要求的条件更强，但最终化简的也更彻底
    - 我们的思路是：根据方程构造二次泛函 $J$，再直接求它的极值就行了
    - 它要求 $J(u)$ 是对称正定的双线性泛函
  - 虚功原理本质是转化为求根问题，它要求的条件更弱，但只能将微分方程化为积分方程
    - 我们的思路是：构造测试函数 $v$，再通过分部积分 + 边值条件将微分方程转化为积分形式
    - 由于测试函数转移了一些微分阶数，所以对解的可微性要求变低了，称为弱形式</font>
- **虚功原理**：
  - 设 $u\in C^2$
  - 则 $u$ 是上述边值条件的解 $\LR u\in H^1_E$ 且满足 $\forall v\in H^1_E，a(u,v)-(f,v) = 0$
  - <font color='red'>物理意义是：外力在虚位移上做的功，等于内力在虚应变上做的功
    - $v$ 是虚位移，$u$ 是真位移，$f$ 是外力
    - $a(u,v)$ 是内力虚功，$-(f,v)$ 是外力虚功</font>
  - **证明**：
    - 用 $v\in H^1_E$ 乘原方程两端后积分得 $\dis\int^b_a \ffkh{-(pu')'v + quv - fv}dx = 0$
    - 第一项分部积分后由 $u,v$ 边值条件即得 $\dis\int^b_a (pu'v' + quv - fv)dx = 0$
    - 显然它就是 $a(u,v) - (f,v) = 0$
- **虚功原理（一般形式）**：下列两个命题等价
  - $u\in C^2$ 且满足 $$\begin{cases} Lu = -\dfrac{d}{dx}(p\dfrac{du}{dx}) + r\dfrac{du}{dx} + qu = f \\\\ u(a) = 0 ，u'(b) = 0 \end{cases}$$
  - $u\in C^2\cap H^1_E$ 且满足 $$ \begin{cases} a(u,v) - (f,v) = 0 ，\forall v\in H^1_E \\\\ a(u,v) = \dis\int^b_a \Big[ p\frac{du}{dx}\frac{dv}{dx} + r\frac{du}{dx}v + quv \Big]dx \end{cases} $$
  - <font color='red'>即将方程替换为更一般的形式后也成立，此时 $a(u,v)$ 非对称正定</font>


## 二阶椭圆边值问题的变分解法

### 最小势能原理（泊松方程 + 第一边值条件）

- **泊松方程**：$-\D u = f，(x,y)\in G$
  - <font color='red'>显然方程仍然可写为 $Lu = f$ 的形式，故对应泛函仍为 $J(u) = \dfrac{1}{2}(Lu,u) - (f,v)$</font>
- **第一边值条件**：$u|_\G = 0$
- **二次泛函**：设 $a(u,v) = \dis\iint_G (u_xv_x + u_yv_y)dxdy$，则由边值条件 + 格林第一公式易得 $$J(u) = \frac{1}{2}a(u,u)-(f,u)$$
  - <font color='red'>$a(u,v)$ 是双线性泛函，且满足对称性、正定性、连续性（有界性）</font>
- **变分问题**：
  - 设 $H^1_0$ 是 $H^1$ 中满足边值条件 $u|_\G = 0$ 的全体函数
  - 则只需求 $u_*\in H^1_0$ 使得 $J(u_*) = \min\limits_{u\in H^1_0} J(u)$
- **最小势能原理**：
  - 设 $f\in L^2(G)$
  - 若 $u_*\in C^2(\ol G)$ 是上述边值问题的解，则它是 $J$ 的极小值点
  - 若 $u_*\in C^2(\ol G)\cap H^1_0(G)$ 是 $J$ 的极小值点，则它是边值问题的解
  - **证明**：与一维类似

### 最小势能原理（泊松方程 + 第三边值条件）

- **边值条件分类**：设 $\G$ 分段光滑
  - 第一边值条件 $u|_\G = 0$ 是本质边值条件
  - 第二/三边值条件 $\dpfrac{u}{n} + \a u|_{\G} = 0，\a\geq 0$ 是自然边值条件
  - **证明**：
    - **能量泛函转化**
      - 设 $J(u) = \dfrac{1}{2}(-\D u, u) - (f,u)$
      - 由格林公式 + 边值条件得 $$J(u) = \dis\iint_G (u_{xx}^2 + u_{yy}^2)dxdy - \frac{1}{2}\int_\G \a u^2ds - \iint_G fudxdy$$
      - 设 $a(u,v) = \dis\iint_G (u_xv_x + u_yv_y)dxdy + \int_G \a uvdy$
        - 显然 $J(u) = \dfrac{1}{2}a(u,v) - (f,u)$
    - **扰动**：
      - 设 $u_*,u\in H^1(G)$，考虑 $\p(\l) = J(u_*  + \l u)$
      - 仿照原来计算即可得到结果
      - <font color='red'>在求解过程中没有在索伯列夫空间加上边值约束，所以是自然边值条件</font>


### 虚功原理（泊松方程 + 混合边值条件）

- **混合边值条件**：设边界 $\G$ 分为互不相交的两部分，其中 $u|_{\G_1} = 0，\dpfrac{u}{n} + \a u|_{\G_2} = 0，\a\geq 0$
- **二次泛函**：设 $a(u,v) = \dis\iint_G (u_xv_x + u_yv_y)dxdy + \int_{\G_2} \a uvds$
- **虚功原理**：
  - 设 $u\in C^2(\ol G)$
  - 则 $u$ 是混合边值条件的解 $\LR u\in H^1_E$ 且满足 $\forall v\in H^1_E，a(u,v)-(f,v) = 0$
  - **证明（必要性）**：
    - 取 $v\in H^1_E$ 乘原方程两端后积分得 $\dis\int_G \ffkh{(-\D u)v-fv}dxdy = 0$
    - 由分部积分 + 边值条件得第一项可化为 $a(u,v)$，即原式化为 $a(u,v)-(f,v) = 0$
  - **证明（充分性）**：
    - 设 $H^1_E$ 是满足第一边值条件的索伯列夫空间，上式逆推即可将积分形式化为原方程
- **虚功原理（一般形式）**：下列命题等价
  - $u\in C^2$ 且满足 $$\begin{cases} Lu = -\dfrac{d}{dx}(p\dfrac{du}{dx}) + r\dfrac{du}{dx} + qu = f \\\\ u(a) = 0 ，u'(b) = 0 \end{cases}$$
  - $u\in H^1_E$ 且满足 $$ \begin{cases} a(u,v) - (f,v) = 0 ，\forall v\in H^1_E \\\\ a(u,v) = \dis\int^b_a \Big[ p\frac{du}{dx}\frac{dv}{dx} + r\frac{du}{dx}v + quv \Big]dx \end{cases} $$
  - <font color='chartreuse'>即将方程替换为更一般的形式后也成立，此时 $a(u,v)$ 非对称正定</font>
