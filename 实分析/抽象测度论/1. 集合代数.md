## 集合代数（仅对有限次集合运算封闭）

- **重复定理**：若对单次运算封闭，则对有限次运算也封闭
  - **证明**：归纳即可
  - <font color='red'>所以下面我们只需要讨论单次运算即可</font>
- **集合系**：设 $X$ 是集合，则其上的（一族对某些运算封闭的集合）称为集合系
  - $\pi$ **系**：交封闭的非空集合系
    - **真 $\pi$ 系**：<font color='chartreuse'>$\pi$ 系，且不是半环</font>
      - $\{A，B，A\cap B\}$
  - **半环**：交封闭，（元素差可表为元素有限并）的非空集合系
    - **真半环**：<font color='chartreuse'>半环，且不是环</font>
      - $\R$ 上全体左开右闭区间
        - **证明**：$(a,b] - (c,d] = (a,c]\cup (d,b]$
      - $\N$ 上的 $\hkh{\{1\},...,\{n\},\{S_n\}}$
      - 有限拓扑基：$X=\{1,2,3,4\}，\mathcal{B}=\hkh{\{2\},\{3\},\{1,2,3\},\{2,3,4\}}$
  - **环**：并和差封闭的非空集合系
    - **真环**：<font color='chartreuse'>环，且不是域</font>
      - $\R$ 上全体左开右闭区间的有限并 $\hkh{\mathop{\bigcup}\limits^n_{k=1} (a_k,b_k]}$
      - $\N$ 上全体 $0$ ~ $n$ 的自然数集 $S_n$
      - $\Z$ 上全体子环
        - **证明**：
          - 易得子环都可写为 $n\Z$ 的形式，故显然关于补不封闭
  - **半域**：交封闭，（元素补可表为元素有限并）的非空集合系
    - **真半域**：<font color='chartreuse'>半域，且不是域</font>
  - **域**：交和补封闭的非空集合系（**域也称为代数**）
    - **真域**：<font color='chartreuse'>域，且不是 $\l$ 系</font>
      - $\R$ 上的有理数域
        - **证明**：单增极限为无理数集，不封闭
      - $\R$ 上全体区间
- **第一关系定理**：域 $\subset$ 环 $\subset$ 半环 $\subset \pi$ 系
  - **证明**：
    - 由对偶律得：交的补 $\LR$ 并，补的交 $\LR$ 差
    - 定义直得半环是 $\pi$ 系
    - 定义直得环是半环
    - 定义直得域是半域
- **第二关系定理**：
  - 环 + 含全集 = 域
  - 半域 + 并封闭 = 域
  - **证明**：显然
  - **反例**：
    - 环，且不是半域
      - <font color='chartreuse'>$X = \R$，则全体有限子集对补不封闭</font>
    - 半域，且不是环
      - <font color='chartreuse'>$X = \{1,2,3,4\}$，则 $\hkh{\{1\},\{2\},\{3,4\},X}$ 对并不封闭</font>


## 可列代数（可列次运算封闭）

- **单调系**：若集合系满足（单增/减集列）都具有（可列并/交封闭性），则称为单调系
- **$\l$ 系**：
  - **定义1**：包含全集 $X$，关于差封闭，单增集列关于可列并封闭
  - **定义2**：包含全集 $X$，关于补封闭，不相交集列关于可列并封闭
    - **证明**：
      - 包含全集 + 差封闭 = 包含空集 + 补封闭
      - 差封闭 + 单增可列并封闭 = 不相交可列并封闭
  - **实例**：
    - 拓扑空间中的全体开集族、全体闭集族
- **$\sigma$ 域**：
  - **定义1**：包含全集 $X$，关于补封闭，关于可列并封闭
  - **定义2**：可列次交并差补封闭
  - **实例**：
    - Borel集族
    - Lebesgue可测集族
    - 幂集族 $\mc P(X)$
    - 平凡域 $\{\varnothing,X\}$
    - **可数集系**：若 $X$ 不可数，则 $A = \hkh{E\subset X\mid E\ 或\ E^c可数}$ 是 $\sigma$ 域
    - **半环并系**：半环上所有元素的有限并族
      - **证明(folland)**：
- **可列关系定理**：$\sigma$ 域 $\subset \l$ 系 $\subset$ 单调系
  - **证明**：定义易得

## 集合系的进化

- **关系引理**：单调系和 $\pi$ 系不相包含
  - **反例**：
    - 设 $\mc M$ 是 $X = [0,1]$ 上的全体勒贝格测度为 $0$ 或 $1$ 的Borel集，则它是单调系，但不是 $\pi$ 系
    - $X = \R$ 上的全体有限子集是 $\pi$ 系，不是单调系
- **$\l$ 系进化定理**：
  - **添加封闭性**：$\l$ 系 = 单调系 + 差封闭 + 包含全集
    - **证明**：这就是定义
- **$\sigma$ 域进化定理**：
  - **添加可列性**：$\sigma$ 域 = 域 $\land$ 单调系
    - **证明**：
      - 取非单调集列 $A_n$ 的单增子列 $A_{n_k}$，其具有极限 $A$
      - 由于若 $A_{n1} \subset A_{n2}$，则 $A_{n1}\cup A_{n2} = A_{n2}$
      - 从而 $\mathop{\bigcup}\limits^\infty_{n=1} A_n = \mathop{\bigcup}\limits^\infty_{k=1} A_{n_k} = A$
    - **本质**：<font color='red'>单增子列的并 = 集列的并</font>
  - **添加交封闭性**：$\sigma$ 域 = $\l$ 系 $\land\ \pi$ 系
    - **证明**：
      - 包含全集 + 差封闭性 = 补封闭性
      - 交封闭性 + 补封闭性 = 并封闭性
      - 从而其形成域。再由 $\l$ 系是单调系即得结论
    - **实例**：
      - 拓扑空间中全体开集、全体闭集
        - $[a,b) = \mathop{\bigcup}\limits^\infty_{n=1} [a,b-\frac{1}{n}]$，可列并不封闭
        - 其为 $\l$ 系，不是 $\sigma$ 域。<font color='chartreuse'>添加交封闭性后，进化为Borel集族</font>
  - **添加补封闭性**：$\sigma$ 域 = 包含全集的 $\sigma$ 环
    - **$\sigma$ 环**：对可列并封闭的环
    - **证明**：同上即可

## 集合系的生成

- **生成**：设 $\mc S$ 是集族
  - **生成的环**：$r(\mc{S})$ 表示全体包含 $\mc S$ 的环的交
  - **生成的单调系**：$m(\mc{S})$
  - **生成的 $\l$ 系**：$\l(\mc{S})$
  - **生成的 $\sigma$ 域**：$\sigma(\mc{S})$
- **半环生成定理**：半环 $\mc{Q}$ 生成的环 $r(\mc{Q}) = \mathop{\bigcup}\limits^\infty_{n=1}(\mathop{\bigcup}\limits^n_{k=1} A_k)$，其中 $A_k$ 两两不交
  - **证明（互包法）**：
    - 环的并封闭性得 左>右
    - 环定义+生成环最小性得 右>左
  - **实例**：半环 $\hkh{\{1\},\{2\},...,\{n\},\{S_n\}}$ 生成的环是 $\mathcal{P}(S_n)$
- **域生成定理**：若 $\mc{F}$ 是域，则 $\sigma(\mc{F}) = m(\mc{F})$
  - <font color='red'>本质就是 $\sigma$ 域进化定理</font>
  - **证明（互包法）**：
    - 由域是单调系 + 生成单调系最小性得 左>右
    - 由域含全集 + 环进化条件 + 环定义得 右是域。再由生成域最小性得 右>左
  - **实例**：
- **$\pi$ 系生成定理**：若 $\mc{P}$ 是 $\pi$ 系，则 $\sigma(\mc{P}) = \l(\mc{P})$
  - <font color='red'>本质就是 $\sigma$ 域进化定理</font>
  - **证明（互包法）**：
    - $\sigma$ 域是 $\l$ 系，生成 $\l$ 系最小性得 左>右
    - 由 $\pi$ 系定义得 右是 $\pi$ 系，由 $\pi\to\sigma$ 进化条件得 右是 $\sigma$ 域，再由生成 $\sigma$ 域最小性得 右>左
  - **实例**：
- **实例**：
  - 设 $\mc A$ 是 $\R$ 上的全体左开右闭区间，$\mc B$ 是 $\mc A$ 中全体有限交
  - 则 $\mc B$ 是 $\pi$ 系，$\sigma(\mc B) = \mc B\cup \mc B^c$

## 习题与推论

- **无生成定理**：存在某个 $\sigma$ 域，它不是被某个更小的半环生成的
  - **反例**：
    - $\R$ 的全体子集
      - **证明**：
        - 显然它的基数为 $2^\alef$，故只需考虑可数半环
        - 再由于可数半环生成的 $\sigma$ 域至多为 $\alef$，故不可能存在生成关系

### $\sigma$ 域的性质


- **积子集传递性**：
  - 设 $X = \prod X_\a$，$\mc M_\a$ 是 $X_\a$ 上的 $\sigma$ 域
  - 则
    - **张量 $\sigma$ 域**：$\otimes_\a M_\a = \hkh{\pi_\a^{-1}(E_\a) \mid E_\a\in M_\a}$ 是 $X$ 上的 $\sigma$ 域
    - **积生成条件**：若 $X$ 是可数积，则 $\otimes_\a M_\a$ 是 $\hkh{\prod E_\a\mid E_\a\in M_\a}$ 生成的 $\sigma$ 域
  - **证明**：仿照积拓扑的证明
- **积生成传递性**：
  - 设 $\sigma$ 域 $\mc M_\a$ 由 $\mc E_\a$ 生成
  - 则
    - （$\mc E_\a$ 子集的逆投影）可生成 $\otimes_\a M_\a$
    - 若维度可数，则（$\mc E_\a$ 子集的直积）可生成 $\otimes_\a M_\a$
- **张量 $\sigma$ 域是积集合的稠密子集**
