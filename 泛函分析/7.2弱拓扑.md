# 对偶空间的拓扑

- **符号约定**：
  - 数域 $\K = \R$ 或 $\C$

## 拓扑向量空间的H-B定理

- **拓扑向量H-B定理**：
  - 设 $X$ 是拓扑向量空间，$p$ 是其上的连续半范数，$X_0$ 是子空间
    - <font color='red'>半赋范空间中，诱导拓扑的半范数族都连续，其它则不一定</font>
  - 若 $f_0$ 是 $X_0$ 上的线性泛函，其满足**受控条件**：$\forall x\in X_0，|f_0(x)| \leq p(x)$
    - <font color='chartreuse'>可被次线性控制</font>
  - 则 $\ms X$ 上存在一个连续线性泛函 $f$ 满足
    - **受控条件**：$\forall x\in X，|f(x)| \leq p(x)$
    - **延拓条件**：$\forall x\in X_0，|f(x)| = f_0(x)$
  - **证明**：
    - 我们只需额外证明 $f$ 的连续性，其它部分仿照复H-B定理即可
    - 由线性得只需原点处连续即可，再由受控条件 + 半范数连续性 + 三角不等式易得
- **局部凸连续延拓定理**：
  - 设 $X$ 是局部凸空间，$X_0$ 是子空间
  - 若 $f_0$ 是 $X_0$ 上的连续线性泛函，则其可连续线性延拓到 $X$ 上
  - **证明**：
    - 由局部凸性得可半赋范性，从而存在连续半范数族
    - 由半赋范空间的连续线性算子定理，存在有限集 $J$ 和 $C>0$ 使得 $$\forall x\in X，|f(x)|\leq C\max\limits_{i\in J} p_i(x) $$
    - 设 $p = C\max\limits_{i\in J}p_i$，显然它满足受控条件，故由拓扑向量H-B定理即可
- **局部凸对偶分离性**：局部凸空间的对偶空间是分离的
    - <font color='red'>局部凸空间上存在足够多的非平凡连续线性泛函，且它们全体构成的族分离</font>
  - **证明**：
    - 即它可半赋范，故存在连续半范数 $p$ 满足存在 $x_0$ 使得 $p(x_0) \neq 0$
      - <font color='red'>比如M泛函</font>
    - 仿照单点延拓定理，子空间 $\{\K x_0\}$ 中可构造连续线性泛函 $g(tx_0) = tp(x_0)$
    - 再由局部凸连续延拓定理即得结论

## 对偶诱导拓扑

- **符号约定**：
  - $E$ 是线性空间，$F$ 是 $E^*$ 的某个分离的子空间
  - $\sigma(E,F)$ 是半范数族 $|F| = \hkh{|f|:f\in F}$ 诱导的 $E$ 上拓扑
    - <font color='chartreuse'>易得线性泛函满足三角不等式
    - 取绝对值后满足非负性和正齐次性</font>
- **对偶诱导拓扑局部凸定理**：$\Big( E,\sigma(E,F) \Big)$ 是局部凸的
  - <font color='red'>两个拓扑下，局部凸性相同</font>
  - **证明**：
    - 对偶诱导拓扑原点开球 $\LR$ 原点开区间在 $F$ 中泛函下的原象。再由 $F$ 连续性即得它在原拓扑下是原点开邻域，再由 $F$ 线性即得是凸集
  - **本质**：<font color='chartreuse'>其实半赋范空间就是局部凸空间……都不用证</font>
- **线性组合引理**：
  - 设 $E$ 是线性空间，$f,f_1,...,f_n$ 是线性泛函，则下面命题等价：
    - $f$ 是 $f_1,...,f_n$ 的线性组合
    - 存在常数 $C\geq 0$ 使得 $\forall x\in E，|f(x)| \leq C\max\limits_{1\leq k\leq n} |f_k(x)|$
    - $\mathop{\bigcap}\limits^n_{k=1} \ker f_k \subset \ker f$
  - **证明**：
    - $(1)\to (2)\to (3)$ 显然
    - $(3)\to (1)$：
      - 设 $G = \hkh{\ddkh{f_1(x),...,f_n(x)}\Bigm| x\in E}$，易得它是 $\K^n$ 的子空间
      - 设 $\p:G\to \K，\ddkh{f_1(x),...,f_n(x)}\mapsto f(x)$
        - **良定义**：由题设条件易得单值性，从而是良定义
        - **线性**：定义易得
      - 由H-B定理，存在线性延拓 $\wt \p:\K^n\to \K$
        - 由线性映射的矩阵表示，可设 $\a_1,...,\a_n$ 是 $\K^n$ 的一组基，且满足 $\wt \p(y_1,...,y_n) = \sum\limits^n_{i=1} \a_i y_i$
        - 再将 $\wt\p$ 限制在 $G$ 上就有 $f(x) = \wt \p\ddkh{f_1(x),...,f_n(x)} = \sum\limits^n_{i=1} \a_i f_i(x)$
  - **理解**：构造值域空间，延拓后再用基表示线性映射
- **对偶诱导拓扑连续定理**：$\Big( E,\sigma(E,F) \Big)^* = F$
  - <font color='red'>设 $f$ 是 $E$ 上线性泛函，则 $f$ 关于 $\sigma(E,F)$ 连续 $\LR f\in F$
  - 两个拓扑下，线性泛函连续性相同</font>
  - **证明**：
      - 由定义得 $f$ 连续 $\LR$ 存在 $g_1,...,g_n\subset |F|$ 和 $C> 0$ 使得 $$\forall x\in E，|f(x)| \leq C\max\limits_{1\leq i\leq n} g_i(x)$$
      - 由线性组合引理即得它等价于 $f$ 是 $g_1,...,g_n$ 的线性组合，即 $f\in F$
- **Mazur推论**：设 $A$ 是 $E$ 中凸集，则 $\ol A = \ol A^\sigma$
  - <font color='red'>两个拓扑下，凸集闭包相同</font>
  - **证明**：由Mazur定理直得

### 弱拓扑

- **符号约定**：
  - 关于弱拓扑的性质叫做 $w$ 性质
- **弱拓扑**：设 $E$ 是局部凸空间，则称 $\sigma(E,E^*)$ 是 $E$ 上的弱拓扑
  - <font color='chartreuse'>前面已知局部凸空间的对偶空间是分离的，故该诱导拓扑是良定义</font>
  - <font color='red'>已知半范数族拓扑是使得该族均连续的最粗局部凸拓扑
  - 所以弱拓扑就是保证连续线性泛函仍然连续的情况下，构造的最粗局部凸拓扑</font>
- **基本性质**：
  - **局部凸性**：弱拓扑空间是局部凸的
    - <font color='red'>两个拓扑下，局部凸性相同</font>
  - **连续等价性**：$\Big( E,\sigma(E,E^*) \Big)^* = E^*$
    - <font color='red'>两个拓扑下，线性泛函连续性相同
    - 只有 $E^*$ 中线性泛函才连续</font>
  - **Mazur推论**：设 $A$ 是 $E$ 中凸集，则 $\ol A = \ol A^w$
    - <font color='red'>两个拓扑下，凸集闭包相同</font>

### 弱 $*$ 拓扑

- **符号约定**：
  - 关于弱 $*$ 拓扑的性质叫做 $w^*$-性质
  - $x$ 的取值映射 $\wh x:E^*\to K，f\mapsto f(x)$
  - 全体取值映射构成的线性空间 $\wh E$
- **弱 $*$ 拓扑**：设 $E$ 是局部凸空间，则称 $\sigma(E^*,\wh E)$ 是 $E^*$ 上的弱 $*$ 拓扑
  - <font color='red'>显然 $\wh E$ 是分离的，故该诱导拓扑是良定义</font>
- **基本性质**：
  - **局部凸性**：弱 $*$ 拓扑空间是局部凸的
    - <font color='chartreuse'>前面已证</font>
  - **线性同构性**：自然映射在值域上的限制 $J_\sigma:E\to \wh E，x\mapsto X$ 是线性同构
    - <font color='red'>注意不是线性同胚，即局部凸空间不一定自反</font>
  - **诱导拓扑等价写法**：$\sigma(E^*,\wh E) = \sigma(E^*,E)$
    - <font color='chartreuse'>因为是同构，元素存在一一对应，故我们可以使用这种写法</font>
  - **连续等价性**：$\Big( E^*,\sigma(E^*,E) \Big)^* = E$
    - <font color='red'>$E$ 中全体元素的取值映射都是 $w^*$ 连续的，且只有它们是 $w^*$ 连续的</font>
  - **Mazur推论**：设 $A$ 是 $E^*$ 中凸集，则 $\ol A = \ol A^{w*}$

### 强拓扑

- **符号约定**：
  - 关于强拓扑的性质称为 $\b$ 性质（但一般说是原拓扑的性质）
- **强拓扑**：设 $E$ 是局部凸空间，则它原本的拓扑称为强拓扑
- **强半范数族**：可诱导局部凸空间拓扑的半范数族
  - <font color='red'>凸平衡开邻域的M泛函</font>

### 对偶强拓扑

- **符号约定**：
  - 关于对偶强拓扑的性质称为 $\b^*$ 性质
- **对偶强半范数族**：设 $E$ 是局部凸空间，$\mc B$ 是全体有界集，则半范数族 $p_B(f) = \sup\limits_{x\in B} |f(x)|$ 称为 $\b(E^*,E)$
  - <font color='chartreuse'>定义直得非负性
  - 线性直得正齐次性
  - 由确界和绝对值的性质易得三角不等式</font>
- **对偶强拓扑**：$\b(E^*,E)$ 诱导的拓扑称为 $E^*$ 上的强拓扑
- **实例（赋范情况）**：
  - 若 $E$ 是赋范线性空间，则 $\b(E^*,E)$ 就是算子范数诱导的拓扑
  - **证明**：
    - 设算子范数拓扑为 $\tau$，对偶强拓扑为 $\tau_\b$
    - **左包右**：
      - 设 $B_E$ 是闭单位球
      - 由有界性得存在 $C$ 使得 $B \subset MB_E$
      - 故 $p_B(f) = \sup\limits_{x\in B}|f(x)| \leq \sup\limits_{\|x\|\leq C} |f(x)| = C\sup\limits_{\|x\|\leq 1} |f(x)| = C\|f\|$
      - 即 $p_B(f)$ 可被 $\|f\|$ 控制，从而 $\tau_\b\subset \tau$
    - **右包左**：
      - 再取 $B = B_E$，则 $p_B(f) = \sup\limits_{\|x\|\leq 1}|f(x)| = \|f\|$，即算子范数也是对偶强范数的一种，从而 $\tau\subset \tau_\b$

### 极集

- **符号约定**：
  - $\cobal(A)$ 表示 $A$ 的凸平衡包
  - $\ccb(A)$ 表示 $A$ 的闭凸平衡包
- **极集**：设 $E$ 是局部凸空间，$A\subset E$，则 $A^\circ = \hkh{x^*\in E^*\Bigm| \forall x\in E，|x^*(x)| \leq 1}$
  - <font color='red'>所有能把集合 $A$ 压入单位闭球的连续线性泛函</font>
- **基本性质**：
  - **反单调性**：$A\subset B \red\Rt B^\circ \subset A^\circ$
    - **证明**：定义易得此时 $B$ 的极集元素必定也是 $A$ 的极集元素
  - **凸平衡性**：
    - **证明**：
      - 任取 $x^*,y^*\in A^\circ$，由线性 + 三角不等式 + 极集定义易得琴生不等式 $$\abs{\ddkh{tx^* + (1-t)y^*}(x)} = |tx^*(x) + (1-t)y^*(x)| \leq t+1-t = 1$$
      - 平衡性同理
  - $w^*$-**闭性**
    - <font color='red'>弱拓扑更粗，故闭集性更难满足</font>
    - **证明**：
      - 任取 $a\in A$，前面已知 $\wh a$ 是 $w^*$ 连续的，故 $\wh a^{-1}(\ol B_\K)$ 是 $w^*$ 闭集
      - 再易得 $A^\circ = \mathop{\bigcap}\limits_{a\in A} \wh a^{-1}(\ol B_\K)$，故它也是 $w^*$ 闭集
    - <font color='red'>证明弱闭性基本都用"连续线性泛函的原象是闭集"，因为这就是定义</font>
  - **凸平衡闭包**：$\ccb(A) = \ol{\cobal(A)}$
    - **证明**：
- **运算律**：
  - **数乘律**：$(\l A)^\circ = \dfrac{1}{|\l|} A^\circ$
    - **证明**：定义易得
  - **对偶律**：$\dkh{\mathop{\bigcup}\limits_{i} A_i}^\circ = \mathop{\bigcap}\limits_{i} A_i^\circ$
    - **证明**：定义易得
- **极集等价定理**：$E$ 中子集的极集和 $E^*$ 中子集的极集是完全类似的
  - **证明**：验证即可
- **双极集**：极集的极集 $A^\cc = (A^\circ)^\circ \subset E$
  - <font color='red'></font>
- **双极定理**：
  - 设 $E$ 是局部凸空间，$A\subset E，B\subset E^*$
  - 则
    - $A^\cc=  \ccb(A)$
    - $B^\cc = \ccb(B)$
  - **证明**：
    - 只需证明 $A^\cc = A \LR A$ 是闭平衡凸集即可
    - **必要性**：由极集的凸平衡闭包性直得
    - **充分性**：
      - 显然 $A\subset A^\cc$
      - 任取 $x\in E\j A$，则由H-B定理，存在 $x^*\in E^*$ 满足 $\begin{cases} x^*(x) > 1 \\ \sup |x^*(A)| \leq 1 \end{cases}$，从而 $x^*\in A^\circ$，但 $x\notin A^\cc$，即 $A^\cc\subset A$
