# Riesz-Fredholm理论

- **符号约定**：
  - 空间默认为 $B$ 空间
  - $I$ 表示恒等变换
  - $\d_{ij}$ 表示Kronecker符号

## 紧算子方程

- **紧算子方程**：设 $A\in\cx$，$T = I-A$，则 $Tx = y$ 称为紧算子方程
  - <font color='red'>单纯的紧算子一般没有适定性，故不讨论 $Ax = y$ 的形式
  - 再已知恒等映射适定，我们关心它取紧扰动时是否仍然适定</font>
  - **共轭方程**：$T^*x = y$ 称为原方程的共轭方程
- **Fredholm二择一定理**：
  - 设 $Tx = y$ 是紧算子方程
  - 则方程的解只可能有以下两种情况
    - 齐次方程仅零解 $\LR$ 非齐次方程存在唯一解
    - 齐次方程存在解空间 $\LR$ 非齐次方程无解，或解为仿射子空间
  - <font color='red'>本质是高代知识的推广，紧算子保证解空间是有限维的，故类似证明即可</font>
  - **证明**：由下面的Riesz-Fredholm定理易得
- **解的存在条件**：非齐次方程有解 $\LR \ker T^*\perp y$
  - <font color='red'>本质是像核对偶定理</font>
  - **证明**：由下面的Riesz-Fredholm定理易得

### 常见的紧算子方程

- **代数方程**：$y\in\R^n$
  - <font color='red'>代数方程对应的紧算子就是有限维空间算子（矩阵）</font>
  - **Fredholm二择一定理**：
    - 齐次方程仅零解 $\LR$ 非齐次方程存在唯一解
    - 齐次方程存在解空间 $\LR$ 非齐次方程无解，或解为仿射子空间
    - <font color='chartreuse'>高代知识</font>
  - **共轭关系**：
    - $Ax = y$ 和 $A^Tx = y$ 称为共轭方程
    - 齐次时，共轭方程的解空间维数相同
- **积分方程**：设 $x,y\in L^2[0,1]$，$K\in C[0,1]^2$，则以下两方程互为共轭 $$x(t) = \int^1_0 K(t,s)x(s)ds + y(t)$$  $$x^*(t) = \int^1_0 K(t,s)x^*(s)ds + y^*(t)$$
  - <font color='red'>由Riesz表示定理，$x$ 和 $x^*$ 关于内积一一对应
  - 积分方程对应的紧算子就是Hilbert-Schmidt算子</font>
  - **共轭关系**：
    - 解的情况相同
    - 齐次方程的解空间维数有限且相同
  - **像核对偶性**：
    - 齐次方程满足
      - 原方程有解 $\LR x^*\perp y \LR \dis\int^1_0 x^*(t)y(t)dt = 0$
      - 共轭方程有解 $\LR x\perp y^*\LR \dis\int^1_0 y^*(t)x(t)dt = 0$

## Fredholm结论

- **Fredholm结论**：积分方程中
  - **像与核的互补性**：$\ker T = \{\t\}\red\Rt \Im T = \ms X$
  - **同谱同维性**：$\sigma(A) = \sigma(A^*)$，$\dim\ker T = \dim \ker T^* < \infty$
  - **像与核的对偶性**：$\Im T = \ker(T^*)^\perp$，$\Im (T^*) = \ker T^\perp$
  - <font color='red'>Fredholm结论针对积分方程，而R-F定理针对一般的紧算子方程</font>
- **Riesz-Fredholm定理**：
  - 设 $\ms X$ 是 $B$ 空间，$A\in \mf C(\ms X)，T = I-A$
  - 则
    - **谱集相同**：$\sigma(T) = \sigma(T^*)$
    - **维数相同**：$\dim \ker T = \dim \ker(T^*) < \infty$
    - **像核对偶性**：
      - $\Im T = (\ker T^*)^\perp = \hkh{x\in\ms X\mid f(x) = 0，\forall f\in \ker(T^*)}$
      - $\Im T^* = (\ker T)^\perp = \hkh{f\in\ms X^*\mid f(x) = 0，\forall x\in \ker T}$

### 闭值域算子

- **闭值域算子**：值域是闭集的算子
- **闭值域引理**：若 $A\in\cx$，则 $T = I-A$ 是闭值域算子
  - <font color='red'>有界线性算子的像核对偶关系只在闭包下成立，所以添加上闭值域条件后就具有完全的对偶关系
  - 恒等紧扰动算子是最典型的有界闭值域算子</font>
  - **证明**：
    - 设核的商映射 $\wt T: (\ms X/\ker T)\to\ms X，[x] \mapsto Tx$
    - **线性**：易得
    - **有界性**：易得
    - **可逆性**：易得
    - **逆连续性**：
      - 反设不连续，则 $\exist [w_m]\nto \t，\wt T[w_n]\to \t$
      - 此时存在子列 $\norm{[w_{m_n}]} \geq \varepsilon$
      - 将子列单位化 $[x_n] = \cfrac{[w_{m_n}]}{\|[w_{m_n}]\|}$
      - 则 $\forall x_n\in [x_n]$，都有 $\|x_n\| < 2$
      - 由 $A$ 是紧算子，存在像收敛子列 $\{Ax_{n_k}\} \to z$
        - 由 $(I-A)x_n\to \t$，得 $x_{n_k}\to z$
        - 从而 $Tz = \t$，即 $[z] = [\t]$
        - $\|[x_{n_k}]\| = \|[x_{n_k}-z]\| \leq \|x_{n_k}-z\| \to 0$，与 $[\|[x_{n_k}]\|] = 1$ 矛盾

### R-F定理的证明

- **谱集相同性**：
  - **证明**：显然 $T = I-A$ 有界，再由Banach伴随谱定理即得结论
- **像核平凡引理**：$\ker T  = \{\t\} \LR \Im T = \ms X$
  - <font color='red'>若是单射或满射，则必定是双射
  - 它就是平凡情况下的像核直和定理</font>
  - **证明（必要性）**：
    - 反设不然，则空间序列 $\begin{cases} \ms X_0 = \ms X \\ \ms X_k = T(\ms X_{k-1}) \end{cases}$ 是单减序列
    - 由R引理，存在 $\ms X_0$ 单位球面上的点列 $\{y_k\in X_k\}$ 满足 $\dist(y_k,\ms X_{k+1}) \geq \dfrac{1}{2}$
    - 易得 $\forall p,n\in\N$ 都有 $$ \|Ay_n - Ay_{n+p}\| = \|y_n - Ty_n + Ty_{n+p}-y_{n+p}\|\geq \frac{1}{2} $$
    - <font color='chartreuse'>因为由单调性可得 $Ty_n-Ty_{n+p}+y_{n+p}\in \ms X_{n+1}$，再由上述距离不等式即可</font>
    - 也就是说，此时单位球在 $A$ 下的像不是列紧集，与 $A$ 的紧性矛盾
  - **证明（充分性）**：仿照上面即可
- **维数有限性**：$\ker T，\ker T^*$ 维数有限
  - **证明**：
    - 设 $B_1$ 是 $\ker T$ 上的闭单位球，则由 $T$ 定义得 $B_1 = \ol{AB_1}$
    - 再由于 $A$ 是紧算子，故 $B_1$ 是紧集
    - 再由无穷维单位球的非紧性，此时只能是 $\ker T$ 维数有限。对偶情况同理
  - **本质**：<font color='red'>构造紧扰动算子其实就是为了单位球像的紧性</font>
- **维数相等性**：
  - **证明**：
    - 设 $\{x_1,...,x_n\}$ 是 $\ker T$ 的基，$\{f_1,...,f_m\}$ 是 $\ker T^*$ 的基
    - 由Banach对偶基引理，存在 $\{y_1,...,y_m\}$ 使得 $f_i(y_j) = \d_{ij}$
    - 反设 $n<m$，考虑映射 $$\wt T : \Big[ \span\{x_1,...,x_n\}\oplus \ms X_1 \Big] \to \Big[ \span\{y_1,...,y_n\}\oplus \Im T \Big]$$ $$\wt T\dkh{\sum^n_{i=1} c_ix_i + y} =  \sum^n_{i=1} c_iy_i + Ty$$
      - **变换性**：
        - 由有限维直和分解定理，定义域是 $\ms X$ 全体
        - 再由 $y_i$ 定义，陪域也是 $\ms X$ 全体
      - **满射性**：
        - 由于 $\span\{x_1,...,x_n\} = \ker T$，故 $\wt T(\ms X_1) = T(\ms X_1) = \Im T$
        - 再由 $\wt T$ 定义得 $\wt T(x_i) = y_i$，故这部分也是满射
        - 综上即得满射性
    - 但显然此时 $y_m\notin \Im \wt T$，与满射性矛盾，故只能是 $m\leq n$
      - 即此时 $\dim \ker T^* \leq \dim\ker T$
      - 同理 $\dim \ker T^{**} \leq \dim\ker T^*$
      - 再由于 $\dim \ker T \leq \dim\ker T^{**}$，互包即得维数相等
- **像核对偶定理**：
  - **证明**：
    - 由闭值域引理，此时 $\Im T$ 是闭集，故 $\Im T = (\ker T^*)^\perp$
    - 再由维数相等定理，$$\dim \ker T^{**} = \dim\ker T^* = \dim\ker T$$
      - 再由自然映射的等距同构性即得 $\ker T = \ker T^{**}$，从而 $$\Im T^* = (\ker T^{**})^\perp = (\ker T)^\perp$$

### 直和分解

- **余维数**：$\codim M = \dim(\ms X\j M)$
- **像核维数定理**：
  - 设 $A\in\cx，T = I-A$
  - 则 $\dim\ker T = \codim\Im T < \infty$
  - **证明**：
    - 由维数相等性 + 像核对偶定理直得结论
- **像核直和定理**：
  - 设 $A\in\cx$，$T = I-A$
  - 则存在闭线性子空间 $\ms X_1$ 和有限维子空间 $\ms Y_1$ （$\dim \ms Y_1 = \dim \ker T$）满足 $$\ms X = \ker T \oplus \ms X_1 = \ms Y_1 \oplus \Im T$$
  - **证明**：
    - 由有限维直和分解定理 + 像核对偶定理 + 像核维数定理即得结论
