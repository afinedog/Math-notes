# 伴随算子（共轭算子）（转置矩阵）

- **符号约定**：
  - 配对关系符号 $f(x) = \lang f,x \rang$
  - 内积符号 $(x,y)$
  - $\K$ 表示 $\R$ 或 $\C$
  - 算子均为有界线性算子（否则无法讨论伴随）

## 伴随算子

- **伴随算子（转置定义）**：
  - 设 $\ms X,\ms Y$ 是 $B^*$ 空间，$T\in\opxy$
  - 若 $T^*:\ms y^*\to\ms X^*$ 满足转置性，则称为 $T$ 的共轭算子
    - <font color='red'>注意这是算子，不是泛函
    - 后面会知道转置性已经包含了连续线性</font>
  - **转置性（配对写法）**：$\forall f\in\ms Y^*，\forall x\in\ms X$，都有 $\lang Tx,f \rang = \lang x,T^*f \rang$
    - <font color='chartreuse'>容易发现，这就是高等代数中的转置矩阵</font>
  - **转置性（映射写法）**：$\forall f\in\ms Y^*，\forall x\in\ms X$，都有 $f(Tx) = (T^*f)x$
    - <font color='red'>当 $f,x$ 同时出现时，（把 $T$ 作用于 $x$）和（把 $T^*$ 作用于 $f$）是等价的</font>
- **伴随算子（映射定义）**：$T^*:\ms Y^*\to \ms X^*，f\mapsto fT$
  - <font color='red'>通过复合原本的算子，将像空间泛函变为原象空间泛函</font>
- **实例**：
  - **欧氏空间**：
    - 设
      - 连续线性算子 $A:\K^m\to \K^n$
      - 连续线性泛函 $f:\K^m\to \R$ 可写为 $y_f$
    - 则伴随算子 $A^T:\K^n\to\K^m$ 满足
      - $\lang f,Ax \rang = \lang A^Tf,x \rang$
      - $y_f^TAx = x^TA^Ty_f$

### 伴随算子的性质

- **唯一性**：
  - **证明**：
    - 反设不唯一，则 $\lang Tx,f \rang = \lang x,T^*_1f \rang = \lang x,T^*_2f \rang$，即 $\forall x,f$ 都有 $\ip{x, (T_1^*-T_2^*)f } = 0$
    - 由向量判零定理得只能是 $T^*_1 = T^*_2$
- **线性**：
  - **证明**：由 $x,f,T$ 的线性易得对 $\forall x\in\ms X$ 都有 $$\lang T^*(f+g),x \rang = \lang f+g,Tx \rang = \lang f,Tx \rang + \lang g,Tx \rang = \lang T^*f,x \rang + \lang T^*g,x \rang$$
    - 再由 $x$ 的任意性，即得 $T^*(f+g) = T^*f + T^*g$
- **连续性**
  - **证明**：
    - 设 $f\in\ms Y^*$，且 $g(x) = f(Tx)$，由转置性 + 唯一性即得 $T^*(f) = g$
      - <font color='chartreuse'>只需证明 $g$ 有界即可</font>
    - 由C-S不等式，$|f(Tx)| \leq \|f\|\cdot\|T\|\cdot\|x\|$，从而 $g$ 有界
    <!-- - 即 $g\in \ms X^*$，从而 $T^*\in\op(\ms Y^*,\ms X^*)$ -->
- **像等式**：$\|T^*f\| = \|fT\|$
  - <font color='red'>这是转置性的显然推论，本质是伴随映射等距同构性的引理</font>
  - **证明**：
    - 易得 $\|T^*f\| = \sup\limits_{\|x\|=1}\|(T^*f)x\| = \sup\limits_{\|x\|=1}\|f(Tx)\| = \|fT\|$
- **左不等式**：$\|T^*\| \leq \|T\|$
  - <font color='red'>因为是 $T^*$ 的本质是复合，故C-S不等式直得
  - 几何意义懒得想了，这东西本质是前面章节的嵌套。这种嵌套是无止境的，越嵌套越复杂</font>
  - **证明**：
    - 由像等式 + C-S不等式得 $\|T^*\| = \sup\limits_{\|f\|=1}\|T^*f\| = \sup\limits_{\|f\|=1}\|fT\| \leq \|T\|$
- **右不等式**：$\|T\| \leq \|T^*\|$
  - <font color='red'>找到合适的 $f$ 使得可以应用C-S不等式</font>
  - **证明**：
    - 在 $Tx$ 处进行单点延拓可得到 $f$ 满足 $\begin{cases} f(Tx) = \|Tx\| \\ \|f\| = 1 \end{cases}$
      - <font color='red'>即直线 $\{\l Tx\}$上的正比例泛函 $f(\l Tx) = \l\|Tx\|$ 保范延拓到整体
      - 方法是取控制泛函 $p$ 使得其它方向上的伸展能力都比不过 $Tx$ 方向</font>
    - 由定义 + C-S不等式得 $$\|Tx\| = |f(Tx)| = |(T^*f)x| \leq \|T^*f\|\cdot \|x\| \leq \|T^*\|\cdot\|x\|$$

## 伴随映射

- **伴随映射**：$*:\opxy\to\opyx，T\mapsto T^*$
  - <font color='red'>伴随映射一般用 $()^*$ 算符表示</font>
  - **线性**：设 $a,b\in\K，A,B\in\opxy$，则 $(aA+bB)^* = aA^* + bB^*$
    - **证明**：定义易得
  - **穿脱原理**：$(AB)^* = B^*A^*$
    - **证明**：定义易得
  - **可逆性**：若 $A^{-1}$ 存在且有界，则 $(A^*)^{-1}$ 存在且有界，且 $(A^*)^{-1} = (A^{-1})^*$
    - **证明**：定义易得
  - **等距同构性**：
    - **证明**：
      - **双射性**：由可逆性直得
      - **等距性**：由左右不等式直得
- **伴随保范延拓定理**：$T^{**}$ 是 $T$ 在 $\ms X^{**}$ 上的保范延拓，即 $\|T^{**}\| = \|T\|$
  - <font color='red'>这里的延拓是嵌入后的延拓，而不是包含下的延拓</font>
  - **证明（延拓性）**：
    - 设 $U: \ms X\to\ms X^{**}$，$V: \ms Y\to\ms Y^{**}$ 都是自然映射，$f\in\ms Y^*$
    - 则 $\lang T^{**}Ux,f \rang = \lang Ux,T^*f \rang = \lang x,T^*f \rang = \lang f,Tx \rang = \lang VTx,f \rang$
      - <font color='chartreuse'>第一个等号：转置性
      - 第二个等号：由等距同构性，$Ux$ 和 $x$ 在 $T^*f$ 的作用下相同
        - （把“在 $f$ 作用下相同”这个概念进行扩展，可以引出弱收敛的概念）
      - 第三个等号：转置交换性
      - 第四个等号：由等距同构性，$VTx$ 和 $Tx$ 在 $f$ 的作用下相同</font>
      <!-- - 共轭性（$T^*f = fT^{**}$） + 延拓性（$Ux = x$） + 共轭性（$T^*f = fT$） + 延拓性（$VTx = Tx$） -->
    - 再由 $f$ 任意性即得 $T^{**}(Ux) = V(Tx)$，即 $T^{**}|_{\ms X} = T$，从而是 $T$ 的延拓
  - **证明（保范性）**
    - 由伴随映射的等距同构性，伴随映射的幂依然等距同构，从而保范
  - **本质**：第二对偶空间扩张性的算子表示

### 自然映射的伴随算子

- **符号约定**：
  - $J_X$ 表示 $\ms X$ 的自然映射
  - $\id_X$ 表示 $\ms X$ 的恒等映射
- **自然映射的伴随算子（消星映射）**：$J_X^*: \ms X^{***}\to\ms X^*$
  - <font color='chartreuse'>它可以将空间的“星号”减少</font>
  <!-- - **证明**：
    - 设 $f:\ms X^{**}\to \ms Y$，则由定义易得 $fJ = J^*f$
    - 左边是复合关系，$\ms X\to\ms X^{**}\to\ms Y$
    - 右边是作用关系，$J^*$ 的定义域在对偶空间上，故不是复合映射。为了与左边等同，需要 $J^*f:\ms X\to\ms Y$，即 $J^*f\in \ms X^*$，即得结论
  - **理解（消共轭性）**：自然映射将算子 $x$ 映射成 $x^{**}$，故自然共轭映射将自然映射变成它的逆算子，即将 $x^{**}$ 映射成 $x$ 的算子，故减少了星号（加一个减两个，总体减了一个） -->
- **商映射性**：
  - **证明**：
    - 任取 $f\in \ms X^*$，存在 $\Phi_f\in \ms X^{***}$ 使得任意 $X\in \ms X^{**} $ 都有 $\Phi_f(X) = X(f)$
      - <font color='red'>$\Phi_f$ 是取值映射，它是 $J_X^*$ 作用的对象，但不是所有对象
      - 可以层层解开上面的嵌套</font>
    - 此时 $\lang J_X^*\Phi_f,x \rang = \lang \Phi_f,J_Xx \rang = \lang J_Xx,f \rang = f(x)$
      - <font color='chartreuse'>第一个等号：转置性
      - 第二个等号：由等距同构性，$J_Xx$ 在 $f$ 和 $\Phi_f$ 的作用相同
      - 第三个等号：</font>
    - 显然 $J_X^*\Phi_f = f$，从而是满射
      - <font color='chartreuse'>满射必定是某种商映射</font>
- **左逆性**：$J_X^*\circ J_{X^*} = \id_{X^*}$
  - **证明**：
    - 满射必定存在右逆。再易得自然映射对偶的逆必定是某个自然映射
- **等距同构性**：$J_X^*$ 限制在 $\Im J_{X^*}$ 上是等距同构
  - **证明**：
    - 由第一同构定理，此时 $p:\ddkh{\ms X^{***}/\ker J_X^*} \to \ms X^*$ 是等距同构
    - 再由 $J_{X^*}$ 单射性 + 互逆关系即得结论

## Hilbert空间的伴随算子

- **符号约定**：
  - $H$ 表示Hilbert空间

### 基础性质

- **伴随映射**：$*:\ms L(H)\to \ms L(H)，T\mapsto T^*$
  - <font color='red'>由于Hilbert空间和对偶空间等距同构，故伴随映射可以看作变换</font>
- **伴随映射的性质**：
  - **共轭线性**：$(aA+bB)^* = \ol aA + \ol bB$
    - <font color='red'>注意：这里和复Banach情况不同，也是非常容易弄混的点
      - 共轭的出现本质是因为经过了Riesz表示定理中转，严格来说中转过后的伴随映射和Banach意义下的伴随映射不是一个东西
      - 但由于Riesz表示是保范同构，故在泛函分析中的所有性质都是相同的，可以看成一个东西
      - 所以就导致了这种"双重情况"出现：对于Hilbert空间，如果你想用Riesz表示定理，那就要规定共轭线性。而不用它也太傻了，所以还是用吧</font>
    - **证明**：由Riesz表示定理，线性泛函都等价于某个内积，故当然具有共轭性
    - <font color='red'>本质原因是我们规定内积是共轭双线性函数，必须有共轭性才能在复数域上得到内积的正定性，内积结构才是良定义的。只要你想用内积结构，就必须带上共轭性</font>
  - **对合性**：$(A^*)^* = A$
    - **证明**：由Hilbert空间和对偶空间等距同构直得
  - **等距同构性**：
    - $\|A^*\| = \|A\|$
    - $\|A^*A\| = \|AA^*\| = \|A\|^2 = \|A^*\|^2$  
    - **证明**：

### 自伴算子

- **自伴算子**：设 $H$ 是Hilbert空间，$A\in\ms L(H)$，若 $A = A^*$，则称为自伴算子
  - <font color='red'>自伴算子的定义是依赖于空间的自对偶性（Riesz表示定理）的，所以只有Hilbert空间上才能定义自伴算子</font>
  - **实例**：
    - 正交投影算子 $\LR$ 自伴算子 + 幂等算子
      - <font color='red'>详见前面</font>
    - $\R^{n\times n}$ 上的自伴算子：对称方阵
    - $\C^{n\times n}$ 上的自伴算子：Hermite方阵
    - $L^2(\R)$ 上的乘法算子
      - 设 $f\in L^\infty$，定义乘法算子 $F_f:x(t)\to f(t)x(t)$
      - 则 $F_f$ 自伴 $\LR f$ 是实函数
      - **证明**：
        - 易得 $(Fx,y) = \dis\int_\R fx\ol y = \int_\R x\ol{(\ol fy)} = (x,F^*y)$
        - 故当且仅当 $\ol f = f$ 时满足自伴性 
    - $L^2(\Omega,\ms B,\mu)$ 上的乘积积分算子：
      - 设 $K\in L^\infty(\Omega\times\Omega,\mu)$，$K(x,y) = K(y,x)$
      - 则 $\dis A: u(x)\mapsto \int_\Omega K(x,y)u(y)d\mu(y)$ 自伴
      - **证明**：
- **自伴算子的性质**：
  - **实线性封闭性**：全体自伴算子构成实线性空间
    - **证明**：
      - **实线性封闭性**：易得自伴算子关于实线性运算封闭
        - <font color='red'>由于共轭性，复数乘运算不封闭</font>
      - **无乘法封闭性**：由高代易得 $(AB)^* = AB \LR AB = BA$
        - <font color='red'>可交换自伴算子构成含幺交换环</font>
      - **含零性**：零映射是自伴算子
      - **含幺性**：恒等映射是自伴算子
  - **完备性**：全体自伴算子是闭集
    - **证明**：
      - 设自伴算子列 $A_n\to A$，只需证明 $(Ax,y) = (x,Ay)$ 即可
      - 线性添项 + C-S不等式易得 $$|(Ax,y) - (x,Ay)| \leq 2\|A_n-A\|\cdot\|x\|\cdot\|y\|\to 0$$
  - **闭限制传递性**：自伴算子 $A$ 在闭不变子空间 $H_1$ 上的限制 $A_{H_1}$ 也是自伴的
    - **证明**：
  - **复合传递条件**：$AB$ 是自伴算子 $\LR AB = BA$
    - **证明**：
      - 由自伴定义即可
  - **二次型实值性**：$A$ 是自伴算子 $\LR \forall x\in H$，$(x,Ax)\in\R$
    - **证明**：
      - **必要性**：由自伴性 + 内积的共轭双线性，$(x,Ax) = (Ax,x) = \ol{(x,Ax)}$，从而是实数
      - **充分性**：按照极分解计算可得  $4(x,Ay) = 4(Ax,y)$，从而自伴
  - **二次型范数定理**：若 $A$ 是自伴算子，则 $\|A\| = \sup\limits_{\|x\| = \|y\| = 1} (Ax,y) = \sup\limits_{\|x\| = 1} (Ax,x)$
    - <font color='red'>算子范数等价于二次型范数的诱导范数</font>
    - **证明**：
      - 即证 $\sup\limits_{\|x\| = 1} \|Ax\| = \sup\limits_{\|x\| = 1} (Ax,x)$
      - 由内积范数定义，$\|Ax\| = \sqrt{(Ax,Ax)}$
      - 计算较复杂，从略
- **Cartesian分解定理**：
  - 设 $H$ 是Hilbert空间
  - 则任取 $T\in \op(H)$ 都存在唯一的自伴算子 $A,B$ 满足 $T = A+iB$
  - **证明**：
    - **存在性**：取 $A = \cfrac{T+T^*}{2}，B = \cfrac{T-T^*}{2i}$ 即可
    - **唯一性**：
      - 反设不唯一，则此时 $(A_1-A_2) = i(B_1-B_2)$
      - 即 $\forall x\in H$，都有 $\Big( (A_1-A_2)x,x \Big) = \Big( i(B_1-B_2)x ,x \Big)$
      - 由自伴的线性封闭性 + 二次型正定性，此时左边是实数，右边是虚数，故只能为 $0$
  - **实例**：
    - $\C$ 中，设 $T(z) = z$，则 $z = x+iy$

### 正规算子

- **正规算子**：设 $H$ 是Hilbert空间，$A\in \ms L(H)$，若 $A^*A = AA^*$，则称为正规算子
  - <font color='red'>同上，为了保证定义域和陪域合理，必须空间自对偶，即必须是Hilbert空间</font>
  - **实例**：
    - **自伴算子**
    - $L^2(\R)$ 上的乘法算子
      - 设 $f\in L^\infty$，定义乘法算子 $F_f:x(t)\to f(t)x(t)$
      - 则 $F_f$ 正规
- **正规算子的性质**：
  - **复线性封闭性**：全体正规算子构成复线性空间
  - **完备性**：全体正规算子是闭集
  - **复合传递条件**：$AB$ 是正规算子 $\LR AB = BA$
  - **无二次型实值性**
    - **反例**：$A:\C\to \C，x \mapsto i$
  - **无二次型范数定理**
- **伴随保范定理**：$A$ 是正规算子 $\LR \forall x\in H，\|Ax\| = \|A^*x\|$
  - <font color='red'>正规算子最常用的性质和判别法</font>
  - **证明**：
    - **必要性**：定义易得 $(Ax,Ax) = (A^*x,A^*x)$，开平方即可
    - **充分性**：
      - 移项得 $\Big( (A^*A-AA^*)x,x \Big) = 0$
      - 易得 $T = A^*A - AA^*$ 是自伴算子，由二次型范数定理得只能是 $T = \t$，从而得到结论
- **Cartesian定理**：$A$ 是正规算子 $\LR$ Cartesian分解中，实部和虚部的自伴算子可交换
  - **证明**：定义易得

### 实例

- **Volterra算子**：$T:L^1[a,b]\to L^1[a,b]，f\mapsto F$
  - <font color='red'>其中 $F$ 是 $f$ 的上限函数</font>
  - 若取 $C[a,b]$ 的一致范数，则 $T^*:BV[a,b]\to L^\infty[a,b]，T^*\p(x) = \dis\int^b_x d\p(t)$
    - **证明**：
      - 定义 + Fubini定理易得
  - 若取 $L^1[a,b]$ 的积分范数，则 $T^*:L^\infty[a,b]\to L^\infty[a,b]，T^*\p(x) = \dis\int^b_x \p(t)dt$
    - **证明**：
      - 定义 + Fubini定理易得
- **乘积积分算子**：
  - 设
    - $(\O,\ms B,\mu)$ 是测度空间，$K(x,y)\in L^2(\O)$
    - 算子 $T:u\mapsto \dis\int_\O K(x,y)u(y)d\mu(y)$，其中 $u\in L^2(\O)$
      - <font color='chartreuse'>这里只知道映射规则，不知道像的性质，所以无法写出陪域</font>
  - 则
    - $T\in \ms L\Big(L^2(\O)\Big)$
    - $T^*f(x) = \dis\int_\O \ol{K(x,y)}f(y)d\mu(y)$
  - **证明**：定义 + Fubini定理易得
- **卷积算子**：
  - 设 $K\in L^1(\R)$，算子 $T:f\mapsto (K*f)$，其中 $f\in L^p(\R)，1\leq p\leq \infty$
  - 则
    - $T \in \ms L\Big(L^p(\R)\Big)$
    - 设 $\wt K(x) = K(-x)$，则共轭算子 $T^*:f\mapsto (\wt K*f)$
  - **引理（Young不等式）**：$\|K*f\|_p \leq \|K\|_1\cdot\|f\|_p$
  - **证明**：
    - 由Fubini定理，变形易得 $$\int_\R \Big[ (K*f)(x) \Big] g(x)dx = \int_\R \Big[ (\wt K*g)(y) \Big] f(y)dy$$
    - 即 $\lang K*f,g \rang = \lang \ol K*g,f \rang$，从而 $T^* = \wt K*$
  - **推论**：
    - 若将 $\R$ 换为 $\C$，则 $T^*:f\mapsto (\wt{\ol K}*f)$

## 像与核的对偶

- **对偶正交**：
  - 设 $\ms X$ 是 $B$ 空间，$M$ 是子集
  - 则
    - **零化子空间**：$M^\perp = \hkh{f\in \ms X^* \Bigm | \forall x\in M，f(x) = 0}$
    - **预零化子空间**：$N_\perp = \hkh{x\in \ms X \Bigm | \forall f\in N，f(x) = 0 }$
  - <font color='red'>希尔伯特空间（自对偶空间）中，这两者等价
  - 它们的本质是极集，详见弱收敛章节</font>
- **像核对偶引理1**：若 $T\in \opx$，则 $\begin{cases} \ol{\Im T} = (\ker T^*)_\perp \\ \ker T = (\Im T^*)_\perp \end{cases}$ 
  - <font color='red'>注意：像不一定是闭集，故这里是像的闭包。但核一定是闭集
  - 要等到后面的紧扰动算子才能得到完整的像核对偶定理
  - 要等到后面的Fredholm算子才能得到完整的像核维数定理</font>
  - **证明（1）**：
    - **右包左**：
      - 任取 $f\in\ker T^*$，此时 $f(Tx) = (T^*f)x = 0$，从而 $Tx\in\ker f$，即 $\ol{\Im T}\subset \ker f$
      - 再由 $f$ 的任意性即得结论
    - **左包右**：
      - 反设存在 $x_0\in \Big[ (\ker T^*)^\perp\j \ol{\Im T} \Big]$
      - 由H-B定理，存在单点延拓 $f\in\ms X^*$ 满足 $\begin{cases}   f(x_0) = \|x_0\|  \neq 0 \\\\ f(x) = 0 \qquad \forall x\in\ol{\Im T}   \end{cases}$
        - 此时 $\forall x,f(Tx) = 0$，由向量判零定理，$T^*f = \t$
        - 再由 $x_0$ 定义即得 $f(x_0) = 0$，矛盾
  - **证明（2）**：
    - **右包左**：
      - 任取 $x\in \ker T$，此时 $\forall g\in \ms X^*$ 都有 $g(Tx) = 0$
      - 故 $\forall f\in \Im T^*$ 都有 $f(x) = T^*g(x) =  g(Tx) = 0$，即 $x\in (\Im T^*)_\perp$
      - 再由 $x$ 的任意性即得结论
    - **左包右**：
      - 即已知 $\forall f\in \Im T^*$ 都有 $f(x) = 0$，要证 $Tx = 0$
      - 即已知 $\forall g\in \ms X^*$ 都有 $g(Tx) = 0$，要证 $Tx = 0$
      - 显然这就是向量判零定理
  - **理解**：
    - <font color='red'>实际上讨论定义就行，但（1）的左包右稍微复杂一些
    <!-- - 此时已知任意满足 $fT = \t$ 的 $f$ 都有 $f(x) = 0$，要证 $x\in \Im T$ -->
      - 此时已知任意满足 $\Im T\subset \ker f$ 的 $f$ 都有 $x\in \ker f$，要证 $x\in \Im T$
      - 显然我们还需要排除 $x\in \mathop{\bigcap}\limits_{f}\ker f\j\Im T$ 的情况，所以我们构造了一个很简单的 $f$，应用向量判零定理发现 $\ker f = \Im T$，故上面交集为空，情况排除</font>
- **像核对偶引理2**：若 $T\in \opx$，则 $\begin{cases} \ol{\Im T^*} \subset (\ker T)^\perp \\ \ker T^* = (\Im T)^\perp \end{cases}$
  - <font color='red'>注意这里第一个是包含而非取等
  - 在希尔伯特空间中可以取等，从而有下面的直和关系</font>
  - **证明（1）**：
    - 等价于 $\exists gT = f$，要证 $\ker T\subset \ker f$，这是显然的
  - **证明（2）**：
    - **右包左**：等价于已知 $fT = \t$，要证 $f(\Im T) = 0$，这是显然的
    - **左包右**：等价于已知 $f(\Im T) = 0$，要证 $fT = \t$，这是显然的
- **像核直和引理**：
  - 设 $H$ 是Hilbert空间，$T\in\ms L(H)$
  - 则 $H = \Ker T\oplus \ol{\Im T^*}$
  - <font color='red'>只有希尔伯特空间（自对偶空间），这个直和才有意义</font>
  - **证明**：由零化子空间的正交性 + 正交补的直和性直得

### 闭值域定理

- **闭值域定理**：
  - 设 $\ms X,\ms Y$ 是 $B$ 空间，$T\in\opxy$，
  - 则 $\Im T$ 是闭集 $\LR \Im T^*$ 是闭集
  - **证明**：
    - **引理**：若 $T^*$ 是单射，$\Im T^*$ 是闭集，则 $T$ 是满射
      - **证**：
        - 此时 $T^*:Y^*\to \Im T$ 是双射，由Banach逆算子定理即得存在 $\d > 0$ 使得 $\forall y^*\in Y^*$ 都有 $\|T^*y^*\| \geq \|\d y^*\|$
        - <font color='red'>由前面保开球性的结论，只需证明存在 $O_Y(0,\d)\subset \ol{ TB_X(0,1) }$ 即可</font>
        - 反设 $y_0$ 是差集的点，由于 $\ol{TB_X(0,1)}$ 是闭凸子集，故由凸集分离定理即得存在 $y_0^*$ 满足 $\begin{cases} y_0^*(y_0) > 1  \\ |y_0^*(y)| \leq 1 & \forall y\in \ol{TB_X(0,1)} \end{cases}$
          - 即 $\forall x\in B_X(0,1)$ 都有 $|y_0^*(Tx)| \leq 1$，从而 $\|T^*y_0^*\| \leq 1$
          - 再易得 $\|y_0^*\| \geq \dfrac{1}{\d}$，故 $\|T^*y_0^*\| \geq \d\|y_0^*\| > 1 \geq \|T^*y_0^*\|$，矛盾
    - **必要性**：
      - 设 $\wt T$ 是正则商投影，易得 $T = \id\circ \wt T\circ \pi$，故可构造正合列 $$ \ms X \xto{\pi} \ms X/\ker T \xto{\wt T} \ol{\Im T} \xemto{\id} \ms Y$$
      - 由于 $\wt T$ 是双射，由逆算子定理即得它可逆，同理 $\wt T^*$ 也可逆
      - 易得 $\id^*$ 是限制映射 $f\mapsto f|_{\ol{\Im T}}$，故由H-B定理得它是满射
      - 易得 $\pi^*$ 是自然映射 $f\mapsto f\circ\pi$，易得它的值域为 $(\ker T)^\perp$
      - 综上即得 $\Im(T^*) = \Im(\pi^*) = (\ker T)^\perp$，再由像核对偶引理即得是闭集
    - **充分性**：
      - 已知 $\wt T^*$ 是单射
      - 由题设得 $\Im T^*$ 是闭集
        - 已知 $\id^*$ 是满射，$\pi^*$ 是等距嵌入，故 $\Im \wt T^* = \Im T^*$ 也是闭集
      - 由引理即得 $\Im \wt T$ 是闭集，故 $\Im T = \Im T$ 也是闭集
- **伴随可逆定理**：
  - 设 $\ms X,\ms Y$ 是 $B$ 空间，$T\in\opxy$
  - 则 $T$ 可逆 $\LR T^*$ 可逆
  - <font color='red'>它等价于后面的Banach伴随谱定理</font>
  - **证明**：由闭值域定理直得

### 对偶基

- **Hilbert对偶基定理**：
  - 设 $H$ 是Hilbert空间，$M$ 是有限维子空间，$\{x_1,...,x_n\}$ 是一组基
  - 则 $H^*$ 中存在唯一的对偶基 $\{f_1,...,f_n\}$ 满足 $f_i(x_j) = \d_{ij}$
  - **证明**：
    - 由Riesz表示定理直得（对偶基就是平面的法向量）
- **Banach对偶基引理1**：
  - 设 $\ms X$ 是 $B$ 空间，$M$ 是有限维子空间，$\{x_1,...,x_n\}$ 是一组基
  - 则 $\ms X^*$ 中存在一组对偶基 $\{f_1,...,f_n\}$ 满足 $f_i(x_j) = \d_{ij}$
  - <font color='red'>注意：不唯一，因为H-B延拓不唯一</font>
  - **证明**：
    - 任取 $x\in M$ 都有 $x = \sum\limits^n_{i=1} \a_i x_i$
    - 由欧氏空间的结论 + 有限维空间拓扑向量同构于欧氏空间，即得 $M^*$ 上存在对偶基 $\{\p_1,...,\p_n\}$
    - 再由H-B定理，将每个 $\p_i$ 保范延拓到 $\ms X$ 上，即得对偶基
- **Banach对偶基引理2**：
  - 设 $\ms X$ 是 $B$ 空间，$N$ 是 $\ms X^*$ 的有限维子空间，$\{f_1,...,f_n\}$ 是一组基
  - 则 $\ms X$ 中存在一组基 $\{x_1,...,x_n\}$ 满足 $f_i(x_j) = \d_{ij}$
  - <font color='red'>注意：不唯一，因为H-B延拓不唯一</font>
  - **证明**：
    - 已知有限维空间自反，故存在有限维子空间 $M\subset \ms X$ 使得 $N^* \cong M$
      - 取 $\{\p_1,...,\p_n\}$ 为 $M$ 的对偶基，再保范延拓即可
      - 易得限制映射 $R:\ms X^{**}\to N，Rg(x) = g(x)$ 是满射，故空间拉回 $\ms X$
- **Banach对偶基定理**：
  - 设 $\ms X$ 是 $B$ 空间，$M\subset \ms X$ 和 $N\subset \ms X^*$ 是维数相同的两个子空间
  - 若 $N$ 和 $M^\perp$ 无交
    - <font color='red'>等价于限制映射 $R:N\to M^*，f\mapsto f|_{M}$ 是同构，即 $N\cong M^*$</font>
  - 则存在两组基满足 $f_i(x_j) = \d_{ij}$
  - <font color='red'>注意：不唯一</font>
  - **证明**：
    - 构造配对矩阵 $A = \Big( f_i(x_j) \Big)_{n\times n}$，由无交性易得它满秩
      - <font color='red'>它类似双线性函数的Gram矩阵，注意它不对称</font>
    - 由两个对偶基引理，$f_i$ 和 $x_j$ 都存在对偶基，将它们分别写为对方对偶基的线性组合，即得 $A = PIQ$，即变为单位阵
      - <font color='red'>我们这里不是在做相似变换（只改变一组基），而是在做满秩分解（同时改变两组基）</font>
- **有限维直和分解定理**：
  - 设 $\ms X$ 是 $B$ 空间，$M$ 是有限维子空间
  - 则存在闭线性子空间 $\ms X_1$ 满足 $\ms X = M \oplus \ms X_1$，对偶情况同理
  - <font color='red'>这个结论不是平凡的，即闭线性子空间的代数补不一定也是闭的。必须是有限维才行
    - 本质是要求代数和拓扑性质的相容性</font>
  - **证明**：
    - 由维数有限性，可设 $\{x_1,...,x_n\}$ 是 $M$ 的基
    - 由Banach对偶基定理，存在 $g_1, ..., g_n\in\ms X^*$ 满足 $g_{i}(x_j) = \d_{ij}$
    - 取 $\ms X_1 = \mathop{\bigcap}\limits^n_{i=1} \ker g_i$ 即可
      - **闭集性**：
        - **证**：由闭集的有限交封闭性易得结论
      - **线性子空间性**：
        - **证**：由 $\ker g_i$ 的定义，易得线性封闭性
      - **无交性**：$M\cap \ms X_1 = \{\t\}$
        - **证**：由 $g_i$ 定义易得
      - **和性**：$\forall x\in \ms X，x-\sum\limits^n_{i=1} g_i(x)x_i \in \ms X_1$
        - **证**：由 $g_i$ 定义易得
      - 最后由 $\forall x,\hkh{g_i(x)x_i}$ 也是 $M$ 的基，即得结论
  - **本质**：
  - **反例**：$c_0$ 在 $\ell^\infty$ 中是闭的，但不存在闭的补空间

## 习题

- **完备自反传递性**：$B$ 空间 $\ms X$ 自反 $\LR\ms X$ 的对偶空间自反
  - **必要性**：设 $x_0^{***}\in \ms X^{***}$，即证 $\exist x^*\in\ms X^*$，使得 $\lang x_0^{***}, x^{**} \rang = \lang x^{**},x_0^* \rang$
    - 设自然映射为 $J$，则 $J^*: \ms X^{***}\to\ms X^*$，左式 $= \lang x_0^{***},Jx \rang$
    - **限制等价性**：原式 $= \lang J^*x_0^{***},x \rang = \lang x_0^*,x \rang$
      - **理解**：本质上就是把第二共轭空间的算子限制到了原空间中。而因为空间自反，所以限制后等价
    - 再由限制等价性，原式 $=\lang x^*,x^{**} \rang$，即得右式
  - **充分性**：第二共轭空间延拓性 + B空间闭集性 + Pettis定理直得
  - **本质**：必要性是限制等价，充分性是嵌入等价
    - 限制等价只需要自反
    - 嵌入等价则需要闭集性（完备性）
  - **推论**：这么说我的猜想没错，第二共轭空间大于原空间的情况中，肯定有完备性的区别
- **自然映射闭值域性**：自然映射是闭值域映射 $\LR$ 原空间完备
  - **证明**：
    - **必要性**：取自然映射的伴随算子，利用其逆性
    - **充分性**：自然映射连续嵌入性直得
  - **本质**：B空间自反传递性的一个子命题罢了
- **连续判定法**：
  - 设 $T:\ms X\to \ms Y$ 是 $B$ 空间的线性算子
  - 若 $\forall g\in\ms Y^*$，$gT$ 都是有界线性泛函，则 $T$ 有界
  - **证明**：
    - 反设 $T$ 无界，则存在 $x_n\to x_0$ 使得 $T(x_n)\to \infty$，但 $T(x_0) = y_0$
    - 由任意性得存在 $gT(x_n)\to g(\infty) = \infty$，但 $gT(x_0) = y_0$，与有界性矛盾
      - <font color='red'>这样 $g$ 的存在性不是显然的，比如 $g(x) = 0$ 也是有界线性泛函。最好用H-B定理证明存在性</font>
