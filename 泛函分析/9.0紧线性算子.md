# 线性算子的紧性

- **符号约定**：
  - 默认为复 $B$ 空间
  - $B_u$ 表示单位球
- **思想**：
  - 紧算子是非常重要的研究对象，它能导出很好的收敛性，从而在PDE中非常有用

## 紧线性算子

- **紧算子**：$B$ 空间上的线性算子 $A$，满足单位球像的闭包 $\ol{A(B_u)}$ 是紧集
  - <font color='red'>单位球 $\to$ 相对紧集</font>
  - **等价定义**：
    - **相对紧定义法**：单位球 $\to$ 相对紧集
    - **一般定义法**：有界集 $\to$ 相对紧集
    - **预紧定义法**：有界集 $\to$ 完全有界集
      - <font color='red'>注意：只有在完备度量空间中，由H定理才有预紧 $\LR$ 相对紧</font>
    - **收敛子列定义法**：有界点列的像存在收敛子列
      - <font color='red'>这是最常用的判别方法</font>
- **紧算子的性质**：
  - **连续性（有界性）**
    - **证明**：由单位球相对紧性 + 紧集存在最值，$\|Ax\| \leq \sup\limits_{x\in B_u} \|Ax\|\cdot \|x\|$
    - **反例**：恒等算子 $I:\ell^2\to \ell^2$ 连续但不紧
      - **证明**：
        - 设 $e_n$ 是全体仅第 $n$ 分量为 $1$，其余均为 $0$ 的向量，则全体 $e_n$ 的集合有界，但不存在收敛子列，故不是紧的
        - <font color='chartreuse'>本质就是有界闭集不一定是紧集</font>
  - **值域可分性**
    - <font color='red'>这个性质很重要，它可以大大简化全连续判别法</font>
    - **证明**：
      - 易得 $\Im A = \mathop{\bigcup}\limits^\infty_{n=1} A(nB_u) =  \mathop{\bigcup}\limits^\infty_{n=1} nA(B_u)$
      - 由单位球像的列紧性 + Hausdorff定理 + 完全有界可分定理即得结论
  - **闭限制传递性**：设 $\ms X_0$ 是闭线性子空间，则 $A|_{\ms X_0}$ 是紧算子
    - **证明**：
      - 由拓扑结论，紧集的闭子集也是紧集，再由紧算子定义即得结论
  - **复合传递性**：紧算子和有界线性算子的任意次序复合都是紧的
    - **证明**：
      - 由连续线性算子的保有界性 + 保紧性直得结论
- **紧算子空间**：$\cxy$
  - **线性封闭性**
  - **完备性**
    - **证明**：
      - 设 $T_n$ 是紧算子列，收敛到 $T$
      - 对 $\ol{T_n(B_u)}$ 取有穷 $\frac{\e}{2}$ 网 $\{y_1,...,y_m\}$，显然 $\ol{T(B_u)} \subset \mathop{\bigcup}\limits^\infty_{i=1} B(y_i,\e)$，即其存在有穷网，从而是紧集
    - **推论**：$\cxy$ 在 $\opxy$ 中是闭集

## 全连续算子

- **全连续算子**：$A\in\opxy$ 满足：若 $x_n\xto{w}x$ ，则 $Ax_n\to Ax$
  - <font color='red'>即弱收敛 $\Rt$ 像集强收敛
  - 全连续算子的作用是把弱极限转化为强极限，紧算子的作用是构造强极限</font>
- **紧 $\LR$ 全连续定理**
  - 紧算子是全连续算子
  - 若 $\ms X$ 是自反空间，则全连续算子是紧算子
  - <font color='red'>本质是自反空间具有弱凝聚性，从而弱子列极限总存在，故总能找到强子列极限</font>
  - **证明**：
    - **必要性**：
      - 反设不是全连续算子，则存在弱收敛 $x_n$ 和不收敛子列 $\|Ax_{n_i} - Ax_0\| \geq \e_0$
      - 由弱收敛 + 共鸣定理得 $x_n$ 有界
      - 再由 $A$ 是紧算子，$x_{n_i}$ 的像中存在收敛子列，设为 $Ax_{n_i}\to z$
      - 由弱收敛得 $\forall y^*\in\ms Y^*，\lang y^*,Ax_{n_i}-Ax_0 \rang = \lang A^*y^*, x_{n_i}-x_0 \rang\to 0$，即 $Ax_{n_i}\xto{w} Ax_0$
      - 由强弱极限相等即得 $x_0 = z$，矛盾
    - **充分性**：
      - 由弱凝聚定理，若 $x_n$ 有界，则有子列 $x_{n_i}\xto{w}x$
      - 由全连续性得 $Ax_{n_i}\to Ax$，从而其为紧算子
- **紧 $\LR$ 伴随紧定理**：$T\in\cxy \LR\Rt T^*\in\cyx$
  - **证明**：
    - **必要性**：
      - 任取 $y_n^*\in\ms Y^*$，设 $\p_n:\ol{T(B_u)} \to \K，y \mapsto \lang y_n^*,y \rang$
        - <font color='chartreuse'>显然 $\p_n = y^*_n|_{\ol{T(B_u)}}$
        - 此时它是紧集上的连续线性泛函，可用阿斯科利引理证明 $\p_n$ 存在收敛子列
          - 注意不同空间中拓扑不同，收敛性不同
        - 再由于 $\lang T^*y_n^*,x \rang = \lang y_n^*,Tx \rang = \p_n(y)$，故 $T^*$ 和 $\p_n$ 逐点收敛性相同</font>
      - **一致有界性**：$|\p_n(y)| \leq \|y_n^*\|\cdot \|y\| \leq \|T\|$
      - **等度连续性**：$|\p_n(y)-\p_n(z)| \leq \|y_n^*\|\cdot\|y-z\|\leq \|y-z\|$
      - 从而 $\{\p_n\}\in C(\ol{T(B_1)})$ 存在收敛子列
        - 显然此时 $\forall y$ 都有 $\{\p_n(y)\}$ 存在收敛子列
        - 由定义得 $\{T^*y_n^*\}$ 存在收敛子列
    - **充分性**：
      - 同上得 $T^{**}\in \mf C(\ms X^{**},\ms Y^{**})$
      - 设 $B_X$ 是单位球，则它是 $\ms X{**}$ 的有界集，故 $T^{**}B_X$ 是相对紧集，即完全有界
      - 再由于 $T = T^{**}|_\ms X$，故 $TB_X$ 也完全有界，即相对紧


## 实例

- **连续核积分算子（一维）**：
  - 设 $K(t,s)$ 连续
  - 则 $K:C[a,b]\to C[a,b]，u(t)\mapsto \dis\int^b_a k(t,s)u(s)ds$ 是紧算子
  - **证明**：
    - **单位球**：全体 $\sup\limits_{t\in [a,b]} |u(t)| < 1$ 的函数
    - **像完全有界性**：
      - **一致有界**：显然像 $\leq \sup \abs{\dis\int^b_a k(t,s)ds} = M$
      - **等度连续**：$$|v(t+\D t) - v(t)| = \abs{\dis\int^b_a \Big[ k(t+\D t,s)-k(t,s) \Big] u(s) ds }$$
        - 由积分上界不等式 + $k$ 连续性 + 闭区间，上式 $\leq (b-a)L\D t$
        - <font color='red'>注意这里需要一致连续才能存在李普希茨上界，故必须是闭区间</font>
      - 综上由阿斯科利引理 + 豪斯多夫定理即得列紧性，从而是紧算子
- **数列相乘算子**：
  - 设 $\{a_n\}$ 是数列，$K:\ell^p\to \ell^p，(x_1,...)\mapsto (a_1x_1,...)$ 
  - 则 $K$ 是紧算子 $\LR \lim\limits_{n\to\infty} a_n = 0$
  - **证明**：
    - **单位球**：$\sum\limits^\infty_{n=1} |x_n|^p < 1$
    - **像完全有界性**：
      - 由勒贝格空间的相对紧判定定理，紧算子 $\LR$ 单位球像的 $p$ 次和一致收敛
      - **充分性**：对任意 $\e$，取 $a_n$ 对应的 $N$，再由单位球的不增性直得结论
      - **必要性**：
        - 反设 $a_n$ 存在收敛到 $\l > 0$ 的子列，易得该子列对应的 $p$ 次和不一致收敛
- **函数相乘算子**：
  - 设 $f\in L^\infty[a,b]$，乘法算子 $F:L^p[a,b]\to L^p[a,b]，x(t)\mapsto f(t)x(t)$
  - 则 $F$ 是紧算子 $\LR f(t) = 0\ae$
  - <font color='red'>它的数列空间是不同的，数列空间的质量均匀分布，但函数空间的质量可集中到一处。所以只有平凡情况才能紧</font>
  - **证明**：
    - **单位球**：$\dis\int^b_a |x(t)|^p dt < 1$
    - **像完全有界性**：
      - 易得像集有界，由勒贝格空间的相对紧判定定理，紧算子 $\LR$ 像 $L^p$ 等度连续
      - **充分性**：显然此时积分为零
      - **必要性**：
        - 反设存在区间 $I$ 使得 $f(x) > \l > 0$，考虑质量逐渐集中到 $I$ 右端点上的一列 $x(t)$，显然它的 $\d\to 0$
      <!-- - 等价于总存在 $n_k$ 使得 $k$ 足够大时 $\dis\int^b_a |f(t)||x_{n_k}(t)-x_{0}(t)|dt < \e$ -->
- **连续核积分算子（高维）**：
  - **连续核**：$K\in C(\Omega\times\Omega)$
  - **定义域**：
    - 有界闭集 $\Omega\subset \R^n$
    - $\ms X = \ms Y = C(\Omega)$
  - **紧算子**：$T: C(\Omega)\to C(\Omega)，u\mapsto \dis\int_\Omega K(x,y)u(y)dy$
  - **证明**：
    - 设 $M = \max\limits_{x,y\in\Omega} |K(x,y)|$，则 $\|Tu\| \leq M\|u\|$
    - 由 $K$ 定义得一致连续性，$\forall \e>0，\exist \delta>0$，使得 $\forall y\in \Omega$，若 $|x-x'|<\d$，则有 $|K(x,y)-K(x',y)|<\e$
      - 此时 $|(Tu)(x) - (Tu)(x')| \leq \e\|u\| mes(\Omega)$
- **索伯列夫紧嵌入**：
  - **定义域**：有界开区域 $\Omega\subset \R^n$
  - **紧算子**：$A\in \ms L(H_0^1(\Omega))$，对给定的 $C\in\R$，满足 $\|Au\|_{H^1_0(\Omega)} \leq C\|u\|_{L^2(\Omega)}$
  - **证明**：
    - 由后面的Rellich定理，$\ell: H^1_0(\Omega)\to L^2(\Omega)$ 是紧嵌入
    - 由 $A: L^2(\Omega)\to H^1_0(\Omega)$ 连续，则由紧算子单复合传递性即得


## 紧算子的有穷秩逼近

- **有穷秩算子**：$T\in\opxy$，且 $\dim \Im T$ 有限
  - <font color='chartreuse'>高代中，线性映射的秩定义为像空间的维数。此处沿用了该定义</font>
  - **紧性**：有穷秩算子是紧算子
    - **证明**：
      - 由保有界性，单位球的像有界。再由有限维空间上紧集等价于有界闭集，即得结论
- **有穷秩算子空间**：$F(\ms X,\ms Y)$
  - **线性封闭性**：易得
  - **不完备性**
    - **反例**：设 $P_n$ 将Hilbert空间投影到前 $n$ 维子空间，则 $n\to\infty$ 时，依算子范数收敛到恒等映射，但无穷维空间中按算子范数不收敛
- **秩1算子**：$y\otimes f:\ms X\to \ms Y， x\mapsto \lang f,x \rang y$，其中  $f\in\ms X^*，y\in\ms Y$
  - <font color='red'>秩1算子可以看作张量积
  - 欧氏空间中，$y$ 是列向量，$f$ 是行向量，则 $yf$ 就是矩阵（张量积）</font>
  - **秩1性**：$\dim\Im y\otimes f = 1$
    - **证明**：
      - 显然像含于直线 $\span\{y\}$ 中，故秩为 $1$
- **秩1分解定理**：$T\in F(\ms X,\ms Y) \LR \exist y_i\in\ms Y,f_i\in\ms X^*$，使得 $T = \sum\limits^n_{i=1} y_i\otimes f_i$
  - <font color='red'>有穷秩算子都能分解为秩1算子的和
    - $y_i$ 是基
    - $f_i:$ 原向量 $\to$ 该基下的坐标
  - 注意：基的选取不唯一，故分解不唯一</font>
  - **证明**：
    - **充分性**：此时 $\Im T = \span\{y_1,\cdots,y_n\}$，故维度有限
    - **必要性**：
      - 由有穷秩性，像可被有限个基线性表出为 $Tx = \sum\limits^n_{i=1} \l_i(x)y_i$
        - <font color='chartreuse'>只需要证明 $\l_i$ 是有界线性泛函，即可表示为内积形式</font>
      - **线性**：$T$ 线性 + 坐标分解的唯一性
      - **连续性**：易得 $\|Tx\|$，$\sum\limits^n_{i=1} |\l_i(x)|$ 都是 $\Im T$ 上的范数，再由有穷性得两范数等价，从而 $\l_i$ 有界
      - 综上，$\forall i，\exist f_i\in \ms X^*$，使得 $\lang f_i,x \rang = \l_i(x)$**（证毕）**
  - **实例**：
    - 欧氏空间中，矩阵的基变换（解非齐次线性方程组）
  - **几何意义**：
    - 将 $x$ 逐个映射为 $Tx$ 在每个基上的分量，然后将其相加即可（像的坐标分解）
- **奇异值分解定理**：
  - 设 $H$ 是Hilbert空间，$u_i,v_i$ 是标准正交基，$T$ 是有穷秩算子
  - 则存在奇异值 $\sigma_i > 0$ 使得 $\forall x\in H，Tx = \sum\limits^n_{i=1} \sigma_i \lang x,v_i \rang u_i$
  - <font color='red'>奇异值分解的算子写法</font>
  - **证明**：它就是秩1分解定理
- **有穷秩逼近定理**：<font color='red'>有穷秩算子在紧算子空间中稠密，从而可以逼近任意紧算子</font>
  - **完备内积情况**：设 $\ms X$ 是Hilbert空间，则 $\ol{F(\ms X,\ms Y)} = \cxy$
    - **证明**：
      - **右包左**：由有穷秩算子是紧算子 + 紧算子空间的完备性直得
      - **左包右**：
        - 由 $\ol{T(B_u)}$ 是紧集，故由豪斯多夫定理得存在有穷 $\dfrac{\e}{2}$ 网将其覆盖，即 $$\ol{T(B_u)} \subset \mathop{\bigcup}\limits^n_{i=1}B(y_i,\frac{\e}{2})$$
        - 设 $E_\e = \span\{y_1,\cdots,y_n\}$，$P_\e$ 是 $E_\e$ 的正交投影算子
          - 则由 $\dim E_\e = n$ 即得 $P_\e T\in F(\ms X,\ms Y)$
          - <font color='chartreuse'>正交投影具有良好性质，但只有希尔伯特空间才能构造</font>
        - 由网性质，$\forall x\in B_u，\exist y_i$ 使得 $\|Tx - y_i\| < \dfrac{\e}{2}$
          - 再作用正交投影算子即得 $\|P_\e Tx - y_i\| < \dfrac{\e}{2}$
          - 最后由三角不等式即得 $\|Tx-P_\e Tx\| < \e$
      - **本质**：
        - <font color='red'>紧算子 + 维数不断扩大的正交投影算子 $\to$ 紧算子</font>
  - **完备可分情况**：设 $\ms X$ 是可分 $B$ 空间，若存在Schauder基，则 $\ol{F(\ms X)} = \mf C(\ms X)$
    - **引理**：Schauder基的坐标 $C_n(x)$ 是连续线性泛函
      - **证明**：
        - **线性**：由可分性得坐标数量可数，再由级数加法封闭性即得结论
        - **连续性**：
          - 设 $S_Nx = \sum\limits^N_{n=1} C_n(x)e_n$，定义上确界范数 $\square x\square = \sup\limits_{N\in\natnums} |S_N x|$
          - **范数完备性**：
            - 由Schauder基的定义易得
          - **范数等价性**：
            - $\|x\| = \lim\limits_{N\to\infty} \|S_Nx\| \leq \square x\square$
            - 由等价范数定理，它们等价
          - 作差 + 三角不等式得 $$\|C_n(x)e_n\| = \|S_nx - S_{n-1}x\| \leq 2\square x\square \leq 2M_1\|x\|$$
          - 再由C-S不等式即得 $C_n(x)$ 有界，从而连续
    - **定理证明**：
      - 由共鸣定理，$\|S_N\|\leq M$ 有界
      - 设 $T\in\cx$，任取 $\e > 0$
        - 由 $\ol{T(B_u)}$ 是紧集，豪斯多夫定理得存在有穷 $\cfrac{\e}{3M+1}$ 网，设为 $\{y_1,...,y_m\}$
        - 由Schauder基的定义，$\forall j，\exists N$ 使得 $\|y_j-S_Ny_j\| < \cfrac{\e}{3}$
        - 再由 $S_N$ 有界性即得 $\|S_N(Tx) - S_N(y_j)\| < \cfrac{\e}{3M+1}$
        - 结合上述三个不等式即得 $$\forall x\in B_u，\|Tx-(S_NT)x\| < \e$$
      - 此时 $T_\e = S_NT$ 是秩 $m$ 算子，且 $\|T-T_\e\| < \e$（**证毕**）
    - **本质**：
      - <font color='red'>紧算子 + 维数不断扩大的Scharder基坐标 $\to$ 紧算子</font>
    - **理解**：
      - <font color='red'>紧算子可导出有穷 $\e$ 网
        - 有穷个网点可张成有穷维子空间，从而构造有穷秩算子
        - 再由网的逼近性即得有穷秩算子的逼近性</font>


### Hilbert-Schmidt算子

- **H-S算子**：
  - 设 $H$ 是可分Hilbert空间，$\{e_n\}$ 是标准正交基，$T\in \ms L(H)$
  - 定义范数 $\|T\|^2_{HS} = \sum\limits^\infty_{n=1} \|Te_n\|^2 < \infty$
  - 若 $T$ 在该范数下有界，则称 $T$ 是H-S算子
  - <font color='red'>本质就是 $\tr(T^*T)$，详见后面
  - 欧氏空间中，就是矩阵全体元的平方和（Frobenius范数）</font>
- **H-S紧定理**：H-S算子是紧算子
  - **证明**：
    - **有穷秩投影**：设 $P_N$ 是 $\{e_1,...,e_N\}$ 的正交投影算子，易得 $TP_N$ 是有穷秩算子
    - **有穷秩逼近**：
      - 此时 $\|T-TP_N\|_{HS}^2 = \sum\limits^\infty_{n=1} \|(T-TP_N)e_n\|^2 = \sum\limits^\infty_{n=N} \|Te_n\|^2$
        - <font color='chartreuse'>$n\leq N$ 时 $TP_Ne_n = e_n$
        - $n>N$ 时 $TP_Ne_n = 0$</font>
      - 再由HS性得级数收敛，故 $N$ 足够大时 $\to 0$，从而可有穷秩逼近
- **H-S空间**：$\mc C_2(H)$ 表示全体 $H$ 上的HS算子
  - **线性**
    - **证明**：显然
  - **内积性**：
    - **证明**：取 $(S,T) = \tr(S^*T) = \sum\limits^\infty_{n=1} ( Se_n,Te_n)$
  - **完备性**：
    - **证明**：
- **H-S积分算子**：
  - 设矩形区域 $R = [a,b]^2$，函数 $k(t,s)\in L^2(R)$
  - 则 $K:L^2[a,b]\to L^2[a,b]，x(t)\mapsto \dis\int^b_a k(t,s)x(s)ds$ 是H-S算子
  - **证明**：
    - **可分Hilbert性**：
      - 已知 $\phi(t) = \cfrac{1}{\sqrt{b-a}}\exp\dkh{2\pi in\cfrac{t-a}{b-a}}$ 是 $L^2[a,b]$ 的一族标准正交基
        - <font color='chartreuse'>就是前面 $L^2[0,1]$ 取线性变换</font>
    - **H-S性**：
      - $\|K\|_{HS}^2 = \dis\sum\limits^\infty_{n=1} \|K\phi_n\|^2 = \sum^\infty_{n=1}\int^b_a dt\int^b_a k(t,s)\phi_n(s)ds$
      - 累次积分合并即化为 $\dis\sum^\infty_{n=1}\int_R k(t,s)\phi_n(s)dsdt = \|k\|_{L^2(R)}$
    - **有穷秩逼近**：
      - 易得 $\phi_{n,m}(s,t) = \phi_n(s)\ol{\phi_m}(t)$ 是 $L^2(R)$ 的一族标准正交基
      - 若设 $K_N = \dis\sum_{|n|,|m|\leq N} \lang k,\phi_{n,m} \rang\phi_{n,m}$，则易得 $\|K_N-K\|\to 0$
      - 由于 $\dim\Im K_N = 2N+1$，故 $K_N$ 是紧的，从而 $K$ 是紧的

  - 若 $\Im A\subset \Im K$，则 $A\in \cxy$
