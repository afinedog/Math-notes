# 共轭空间

- **背景**：为啥要把共轭空间和弱收敛放在一起：
  - 因为自反空间拥有延拓性、对偶对称性
  - 而弱收敛又是将原像性质传到函数性质上的媒介之一
- **符号约定**：
  - $\var(g)$ 表示复函数 $g$ 的全变差
  - 共轭空间、自共轭空间、共轭算子是、自共轭算子一套译名
  - 对偶空间、自反空间、伴随算子、自伴算子是一套译名
- **对偶配对**：
  - 以后用 $(f,x)$ 或 $(x,f)$ 表示 $f(x)$
  - <font color='red'>因为 $f$ 是 $x$ 的连续线性泛函，则 $x$ 同时也是 $f$ 的连续线性泛函。该配对满足对称性和双线性
  - 但是它不是同一个空间上元素的配对，所以怎么都不能看作内积，必须和内积区分开</font>


## 对偶空间（共轭空间）

- **对偶空间**：$B^*$ 空间 $\ms X$ 上的全体连续线性泛函称为 $\ms X$ 的对偶空间 $\ms X^*$
  - <font color='chartreuse'>由单点延拓定理，连续线性泛函的数量足够多，足以构成一个空间</font>
  - **第一泛函**：$\ms X^*$ 上的元素称为第一泛函
  - **对偶范数**：$\|f\| = \sup\limits_{\|x\|=1}|f(x)|$
    - <font color='chartreuse'>对偶空间的范数可被原空间诱导</font>
  - **完备性**：对偶空间在对偶范数下是 $B$ 空间
    - **证明**：
      - 只需证明有界线性泛函列的极限仍然有界即可，而这是显然的

### $\ell^p$ 的对偶空间

- **F.Riesz定理**：
  - 若正整数 $p,q$ 满足 $\begin{cases} \frac{1}{p}+\frac{1}{q} = 1 & 当p>1时 \\ q = \infty &  当p=1时 \end{cases}$，则 $(\ell^p)^* = \ell^q$
  - **证明**：证明参照后面的非自反例子 $(c_0)^{**} = (\ell^1)^* = \ell^\infty$ 即可

### $C[0,1]$ 的对偶空间

<!-- - **连续函数共轭空间**：$C[0,1]$ 的共轭空间 -->
- **有界变差空间**：全体无截距、右连续、有界变差的函数 $$BV[0,1] = \hkh{g:[0,1]\to \C \Biggm| g(0) = 0， g(t) = g(t+) ， \var(g) < \infty }$$
  - <font color='red'>规定无截距的目的是防止 $v(t)$ 端点处取值不同，但仍然被视为一个元素，从而不良定义
  - 规定右连续的目的是防止 $v$ 的内部间断处取值不同，但仍然被视为一个元素，从而不良定义
  - 本质都是通过取代表元来商掉等价情况</font>
  - **范数**：$\|g\|_v = \var(g)$
    - **证明**：由实变易得全变差满足范数性质
  - **完备性**：
- **连续函数对偶定理**：$C[0,1]^* \cong BV[0,1]$
  - <font color='chartreuse'>等距同构意义下的相等</font>
  - **等距同构映射**：$\p:C[0,1]^*\to BV[0,1]，F\mapsto v$，其中 $F(x) = \dis\int^1_0 x(t)dv(t)$
    - <font color='red'>这里的 $x$ 是 $C[0,1]$ 上的任意函数
    - 即每个函数泛函 $F$ 都可以写成 $x$ 与 $v'$ 在R-S测度下的积分值
      - 这种对应是一一的
      - $F$ 的对偶范数 $= v$ 的全变差范数</font>
  - **证明**：
    - **构造 $v$**：
      - 由H-B定理，$\forall f\in C[0,1]$，存在 $L^\infty[0,1]$ 上的保范延拓 $F$
      - 则取 $v(s) = F(\chi_{[0,s]})$ 即可
        - <font color='chartreuse'>等距性：详见下面证明
        - 满射性：由题设积分关系式即得
        - 线性：由题设积分关系式 + 微分线性 + 积分线性即得</font>
    - **有界变差性**：
      - 取 $[0,1]$ 的分划 $\{t_k\}^n_{k=1}$
      - 易得 $$\sum^n_{k=1} |v(t_k)-v(t_{k-1})| = F\dkh{\sum^n_{k=1} \e_k(\chi_{[0,t_k]} - \chi_{0,t_{k-1}})}$$
      - 由C-S不等式，上式 $\leq \|F\|_{\infty}\cdot\|...\|_\infty$
        - 由延拓的保范性，$\|F\|_{\infty} = \|f\|$
        - 再易得 $\forall n\in\N，\|...\|_{\infty} = 1$
        - 最后由 $n$ 任意性，推广到极限，即得全变差有界性
    - **积分关系式**：
      - 设 $x\in C[0,1]$
      - 设 $y(s) = \sum\limits^n_{k=1} x(t_k)\Big[ \chi_{[0,t_k]}(s) - \chi_{[0,t_{k-1}]}(s) \Big]$
      - 设 $F(y) = \sum\limits^n_{k=1} x(t_k)\Big[ v(t_k)-v(t_{k-1}) \Big]$
      - 由 $x$ 的连续性，计算易得当划分极小时 $\|y- x\|_{\infty}\to 0$，再由 $F$ 的连续性即得 $F(y)\to F(x)$
      - 由R-S积分的定义，即得题设积分关系式
    - **等距性**：
      - 由积分上下界不等式，$|f(x)| \leq \|x\|\var(v)$，再由定义即得 $\|f\| \leq \var(v)$
      - 在上面有界变差性的证明中，已经得到 $\var(v) \leq \|f\|$
      - 综上，$\|v\| = \var(v) = \|f\|$

### Hilbert空间的对偶空间

- **Riesz共轭同构**：
  - 设 $H$ 是复数域上的Hilbert空间
  - 由Riesz表示定理，存在等距同构 $\tau:H\to H^*，x\mapsto \lang \cdot,x \rang$
  - 易得它满足共轭线性，故称为Riesz共轭同构
  - <font color='red'>因为这个等距同构是内积诱导的，而内积满足共轭双线性</font>
- **Hilbert共轭定理**：设 $H$ 是Hilbert空间，则 $H^*$ 与 $H$ 等距同构
  - **证明**：
    - 由R表示定理，$\forall f\in H^*，\exists y_f\in H$ 使得 $\lang f,x \rang = \lang y_f,x \rang$，且 $\|y_f\| = \|f\|$
      - <font color='chartreuse'>实际上 $f$ 和 $y_f$ 是一一对应的</font>
    - 构造映射 $\tau:H^*\to H，f\mapsto y_f$
      - **共轭线性**：由内积的共轭双线性易得
      - **等距性**：由上面结论即得等距性
  - **实例**：
    - $\R^n$
    - $\C^n$
    - $L^2[a,b]$
    - $\ell^2$
- **连续线性泛函的内积表示法**：设 $\ms X$ 是Hilbert空间，$x\in \ms X，f\in \ms X^*$，则我们可以把 $f(x)$ 记为 $\lang f,x \rang$
  - <font color='red'>严格来说 $f\neq y_f$，但在同构意义下是等价的</font>

### 对偶空间与完备化空间

- **对偶完备化定理**：$\ms X^* = \dkh{\ol{\ms X}}^*$
  - <font color='red'>对偶空间无唯一性</font>
  - **证明**：由对偶空间定义 + 对偶空间完备性易得
- **同一对偶定理**：
  - 设集合 $X$ 关于范数 $A,B$ 都构成赋范线性空间
  - 若两个空间的完备化相同（设为 $\ms X$），则它们的对偶空间都是 $\ms X^*$
  - <font color='red'>对偶空间相等的情况非常多</font>
  - **证明**：由上个结论直得
- **Bessega定理**：存在不可数个 $B^*$ 空间，它们的对偶空间和 $\ell^1$ 等距同构

## 第二对偶空间（对偶空间的对偶空间）

- **第二对偶空间**：设 $\ms X$ 是 $B^*$ 空间，则 $\ms X^*$ 的对偶空间 $\ms X^{**}$ 称为 $\ms X$ 的第二对偶空间
  - <font color='chartreuse'>连续线性泛函的连续线性泛函</font>
  - **第二泛函**：$\ms X^{**}$ 上的连续线性泛函
    - **取值映射**：设 $x\in \ms X$，则 $X: \ms X^*\to \R，f \mapsto f(x)$ 是第二泛函
      - <font color='red'>可能存在不是取值映射的第二泛函</font>
  - **第二共轭范数**：$\|X\| = \sup\limits_{f\neq \bd 0} \cfrac{|X(f)|}{\|f\|} =  \sup\limits_{\|f\|=1} |X(f)|$
    - <font color='red'>取定 $x$ 时，寻找一个最大伸展方向和 $x$ 方向尽量匹配的 $f$
    - 若存在最大伸展方向和 $x$ 方向相同的 $f$，则 $\|X\| = \|x\|$
    - 后面的右不等式本质就是用H-B定理告诉你，这样的 $f$ 总是存在的</font>
  - **完备性**：同上
- **C-S不等式**：$|X(f)|\leq \|f\|\cdot \|x\|$
  - <font color='red'>$\|f\|$ 表示最大伸展方向上的伸展比例，$\|x\|$ 表示长度，所以两者乘积就是最好方向上 $\|x\|$ 长度向量的像，当然比任意一个 $\|x\|$ 长度向量的像都要长</font>
  - **证明**：
    - 易得 $\cfrac{|X(f)|}{\|f\|} \leq \sup\limits_{f\neq \bd 0} \cfrac{|X(f)|}{\|f\|} = \sup\limits_{\|f\|=1} |X(f)| = \sup\limits_{\|f\| = 1} |f(x)| = \|x\|$
- **左不等式**：$\|X\|\leq \|x\|$
  - <font color='red'>$\|f\| = 1$ 表明 $f$ 的最大伸展方向也只能保持范数不变，即 $f$ 是不增映射</font>
  - **证明**：
    - 由C-S不等式，$\|X\| = \sup\limits_{\|f\| = 1}|X(f)|\leq \sup\limits_{\|f\| = 1}\|f\|\cdot \|x\| = \|x\|$
- **右不等式**：$\|x\|\leq \|X\|$
  - <font color='red'>H-B定理保证有足够多的连续线性泛函，使得总能找到最大伸展方向与 $x$ 方向相同的 $f$</font>
  - **证明**：
    - 由单点延拓定理，$\forall x$，$\exists f\in \ms X^*$ 使得 $\begin{cases} f(x) = \|x\| \\ \|f\| = 1 \end{cases}$
      - <font color='red'>其实就是直线 $\{\l x\}$上的正比例泛函 $f(\l x) = \l\|x\|$ 保范延拓到整体
      - 方法是取控制泛函 $p$ 使得其它方向上的伸展能力都比不过 $x$ 方向</font>
    - 由C-S不等式，$\|x\| = |X(f)| \leq \|X\|\cdot\|f\| = \|X\|$

## 自反空间

- **自然映射**：$T: \ms X\to \ms X^{**}，x\mapsto X$，且满足等距性
  - **线性**：$T(x_1+x_2) = X_1 + X_2$
    - **证明**：
      - 设 $x = x_1+x_2$，则 $\lang T(x_1+x_2),f \rang = Xf = f(x) = f(x_1) + f(x_2)$
      - 由第二泛函的线性得 $(X_1+X_2)f = f(x_1)+f(x_2)$
      - 故等式两边相等（**证毕**）
  - **单射性**：
    - **证明**：
      - 反设 $Tx = Ty = X$，则 $\forall f\in\ms X^*$，都有 $f(x) = f(y) = X(f)$
      - 再由向量判零定理，得只能是 $x=y$
    - <font color='chartreuse'>如果只考虑某个 $f$ 的话，那么 $X$ 可以是等值面 $H^{f(x)}_f$ 上的所有点
    - 但要求对全体 $f\in\ms X^*$ 都成立，那么就是全体上述等值面的交集，显然只能是 $x$</font>
  - **非满射性**：
- **自然映射等距定理**：自然映射 $T$ 是 $\ms X$ 和 $\Im T\subset \ms X^{**}$ 的等距同构
  - <font color='red'>$\ms X$ 可等距嵌入 $\ms X^{**}$，若是自反空间则进化为等距同构</font>
  - **证明**：
    - **同构性**：
      - $T$ 线性：已知
      - $T$ 单射性：已知
      - <font color='chartreuse'>实际上等距映射必为单射，所以也没必要提前得到单射</font>
    - **等距性**：由前面的左右不等式直得
  <!-- - **本质**：
    - <font color='red'>对称性：若 $f$ 是 $x$ 的泛函，则 $x$ 也可看作 $f$ 的泛函，即第二泛函
    - 此时 $f(x)$ 可写为双线性形式 $(f,x)$</font> -->
- **自反空间**：自然映射是满射的 $B^*$ 空间
  - <font color='red'>它要求等距同构必须是自然映射，如果只有等距同构但不是自然映射，也不是自反空间</font>
  - **第二泛函正则性**：自反空间的第二泛函都是取值映射
    - **证明**：显然全体取值映射就是 $\Im T$

### 自反空间实例

- **某些勒贝格空间是自反空间**：$L^p\pad (1<p<\infty)$
  - <font color='red'>由Holder定理直得自反性</font>
  - **第一泛函（示例）**：$\dis f: L^p\to\R，u\mapsto \|u\| = \dkh{\int_\Omega |u(x)|^pdu}^{\frac{1}{p}}$
    - <font color='chartreuse'>第一泛函有很多，这只是一个示例</font>
  - **第二泛函（全体）**：$\dis X: (L^p)^*\to \R，f\mapsto (f,u) = \dkh{\int_\Omega |u(x)|^pdu}^{\frac{1}{p}}$
    - <font color='chartreuse'>第二泛函也有很多，但都可写为上面的形式</font>
  - **自然映射**：$T: L^p\to (L^p)^{**}，u\mapsto X$
- **欧氏空间是自反空间**
  - <font color='red'>Riesz表示定理即可</font>
  - **第一泛函（全体）**：$f_\a: V\to \R，\b \mapsto \lang \a,\b \rang$
  - **对偶空间**：$\a$ 所在的向量空间
  - **第二泛函（全体）**：$X: V^*\to \R，f_\a \mapsto (f_\a,\b)$
  - **第二共轭空间**：$\b$ 所在的向量空间（原空间）
  - **自然映射**：$T: V\to V^{**}，\b \mapsto X = \b$，恒等映射

### 自反空间反例

- **收敛数列空间不是自反空间**：设 $c_0$ 是全体收敛实数列，范数为最值 $\|a\| = \sup|a_n|$
  - <font color='red'>显然绝对收敛的级数作为数列必定收敛，收敛的数列必定有界，故 $\ell^1 \subset c_0\subset \ell^\infty$</font>
  - **第一泛函（全体）**：$c_0^*$ 的元素均可写为 $S_b: c_0\to \R，\{a_n\} \mapsto \sum\limits^\infty_{n=1}(a_n+b_n)$
    - **证明**：黎曼重排定理即可
  - **对偶空间**：$\ell^1$
    - **证明（等距同构法）**：
      - 设 $\{e_i\}^\infty_{i=1}$ 是自然坐标基
      - 此时基取值映射 $*: c_0^*\to \ell^1，f \mapsto \ddkh{f(e_1),...,f(e_n),...}$ 是等距同构
        - **满射性**：
          - 显然任意 $(x_1,...,x_n,...)\in \ell^1$ 都能给出泛函满足 $\begin{cases} f(e_1) = x_1 \\ ... \\ f(e_n) = x_n \\ ...\end{cases}$
          - 只需证明它满足有界线性
            - 由基的线性无关性易得满足线性（高代的线性扩张定理）
            - 由基的表出性 + 泛函线性 + 级数收敛性易得 $\forall a\in c_0$，$f(a) = f(\sum\limits^\infty_{n=1} a_ne_n) = \sum\limits^\infty_{n=1} a_nx_n$
              - 再由 $a_n$ 收敛和 $\sum\limits^\infty_{n=1} x_n$ 绝对收敛，显然 $\sum\limits^\infty_{n=1}a_nx_n$ 也绝对收敛，故有界
        - **等距性**：
          - 像的范数是 $\sum\limits^\infty_{n=1} |f(e_n)|$
          - 原象的范数是 $\|f\| = \sup\limits_{a\in c_0}\cfrac{|f(a)|}{\|a\|} = \sup\limits_{a\in c_0}\cfrac{\abs{\sum\limits^\infty_{n=1}a_nf(e_n)}}{\sup |a_n|}$
            - 显然只有 $a_n$ 是恒等数列时才最大，即两范数相等
    - **证明（泛函法）**：
      - 由于 $S_b$ 存在的条件是 $b_n$ 收敛，故只需证明第一泛函均可写成 $S_b$ 的形式
      - 为了保持线性和连续性，只有 $S_b$ 符合条件
  - **第二泛函（全体）**：$(\ell^1)^*$ 的元素均可写为 $X_d:\ell_1\to\R，\{c_n\}\mapsto \sum\limits^\infty_{n=1} (c_nd_n)$
    - **证明**：
  - **第二对偶空间**：$\ell^\infty$
    - **证明（等距同构法）**：
      - 设 $\{e_n\}^\infty_{n=1}$ 是自然坐标基
      - 此时基取值映射 $*:(\ell^1)^*\to \ell^\infty，f\mapsto \ddkh{f(e_1),...,f(e_n),...}$ 是等距同构
        - **满射性**：
          - 构造同上，只需证明有界性即可
          - 易得 $\forall a\in \ell^1$，$f(a) = \sum\limits^\infty_{n=1} a_nx_n$
            - 再由于 $a_n$ 绝对收敛，$x_n$ 有界，故 $\sum\limits^\infty_{n=1} a_nx_n$ 收敛
        - **等距性**：
          - 像的范数是 $\sup |f(e_n)|$
          - 原象的范数是 $\|f\| = \sup\limits_{a\in \ell^1} \cfrac{|f(a)|}{\|a\|} = \sup\limits_{a\in \ell^1}\cfrac{\abs{\sum\limits^\infty_{n=1} a_nf(e_n) }}{\sum\limits^\infty_{n=1} |a_n|}$
            - 显然只有 $a_n$ 在 $\sup |f(e_n)|$ 处非零，其余均为零时才最大，即两范数相等
            - <font color='red'>类似数值代数中向量 $1$ 范数和 $\infty$ 范数诱导的矩阵范数证明，本质都是线性规划问题</font>
    - **证明（泛函法）**：
      - 首先证明 $X_d$ 是连续线性泛函
        - 线性易得
        - 由Banach-Steinhaus定理，$\{X_d\}$ 在 $l^\infty$ 上一致有界，从而连续
      - 再由 $X$ 存在的条件是 $d_n$ 有界。只需证明 $l^1$ 上的连续线性泛函均可写成 $X$ 的形式
      - 而它等价于证明 $\forall c_n\in l^1，\forall S\in\R，\exist d_n\in l^\infty$，使得 $X_d(c_n) = S$
        - 由黎曼重排定理，用 $d_n$ 将 $c_n$ 更序，即可表出所有实数
      - <font color='chartreuse'>可惜这个证明不对。$l^1$ 是绝对收敛数列，而Riemann级数定理是条件收敛级数的性质。而且由于线性和连续性的限制，其实不需要任意实数均可被表出</font>
  - **自然映射**：$T:c_0\to \ell^\infty$
    - **非满射性**：有界不收敛数列不在值域内
- **某些勒贝格空间不是自反空间**：$L^1,L^\infty$
  - <font color='red'>证明需要用后面章节的结论</font>

### 常见自反空间

- **Hilbert空间自反定理**：Hilbert空间是自反空间
  - **证明（满射法）**：
    - Riesz表示定理得 $f(x) = (x,y_f)\quad (\forall x\in\ms X)$，从而 $y_f$ 和 $f$ 一一对应
    - 仿照上面欧氏空间的证明，即可得到自反性
    - **推论**：Hilbert空间的共轭空间均与自身等距同构
  - **证明（内积法）**：同下
- **有限维 $B^*$ 空间自反定理**：有限维赋范线性空间是自反空间
  - **证明（满射法）**：
    - 设 $\{f_1,...,f_n\}$ 是 $\ms X^*$ 的一组基
    - 考虑取值映射 $V:\ms X\to \K^n，x\mapsto \Big( f_1(x),...,f_n(x) \Big)$
      - **线性**：定义易得
      - **连续性**：由分量函数连续性易得
      - **满射性**：
        - 反设不是满射，则存在 $\a$ 使得其在 $\Im V$ 上的分量为 $0$
        - 此时 $\forall x\in\ms X，\ip{\sum\limits^n_{j=1}\a_jf_j，x} = 0$，由向量判零定理，$\sum\limits^n_{j=1}\a_jf_j = \t$，即 $\{f_j\}$ 线性相关，矛盾
  - **证明（内积法）**：
    - 设 $\{f_k\}$ 是 $\ms X$ 的一组基，$\{e_k\}$ 是 $\ms X^*$ 的标准正交基
    - 计算易得 $$\hspace{-0.5em}\lang x^{**},f \rang = \ip{ x^{**},\sum\limits^n_{k=1} \lang f,e_k \rang f_k} = \sum\limits^n_{k=1} \lang f,e_k \rang\lang x^{**},f_k \rang = \ip{f,\sum\limits^n_{k=1} \lang x^{**},f_k \rang e_k }$$
      - <font color='chartreuse'>第一个是正交分解，第二个是内积双线性拆解，第三个是内积双线性合并
      - 如果不是有限维，则无法这么简单的拆解和合并</font>
    - 设 $x = \sum\limits^n_{k=1} \lang x^{**},f_k \rang e_k$，则上式化为 $\lang x^{**},f \rang = \lang f,x \rang$， 得到一一对应关系，从而自反
  - **理解**：展开 $f$ 将内积对换，从而将 $x^{**}$ 转化为内积形式，即得到 $x$，从而建立对应关系
  - **本质**：用基来使问题标准化。由于研究对象是 $x$，故使用的是 $f$ 的基

### 自反空间的性质

- **对偶传递性**：自反空间的对偶空间也是自反空间
  - **证明**：
    - 已知 $\ms X^{**} = \ms X$，故 $\ms X^{***} = (\ms X^{**})^* = \ms X^*$
- **自反完备化定理**：$\ms X^{**} = (\ol{\ms X})^{**}$
  - **证明**：由对偶完备化定理直得
- **自反更大性**：自反空间的第二对偶空间通常比完备化空间更大
  - **实例**：
    - 设 $c_{00}$ 是有限支实数列空间，范数为 $\ell^1$ 范数
    - **完备化**：$\ell^1$
      - **证明**：易得 $c_{00}$ 在 $\ell^1$ 中稠密，再由 $\ell^1$ 完备即得结论
    - **对偶空间**：$\ell^\infty$
      - **证明**：由自反完备化定理易得（此时基取值映射 $(c_{00})^*\to \ell^\infty$ 是等距同构）
    - <font color='red'>前面已知第二对偶空间 $(\ell^\infty)^*$ 比 $\ell^1$ 大得多</font>
