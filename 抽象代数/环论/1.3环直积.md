# 环与直积

## 直积

- **环直积**：设 $R_i$ 是一族环，则 $\prod\limits_{i\in I} R_i$ 称为环直积
  - **加法**：各元直接相加
  - **乘法**：各元直接相乘 $\{a_i\}_{i\in I}\{b_i\}_{i\in I} = \{a_ib_i\}_{i\in I}$
- **（定理2.22）直积性质**：
  - 含幺性、交换性可传递
  - 规范投影是满同态
  - 规范逆投影是单同态
  - **证明**：类似群直积
- **（定理2.24）弱内直积**：
  - 若 $R$ 的理想列 $\{A_i\}^{n}_{i=1}$ 满足
    - **生成并性**：$\sum\limits^n_{i=1} A_i = R$
    - **不相交性**：$A_k\cap \sum\limits_{i\neq k} A_i = 0\quad (\forall 1\leq k\leq n)$
  - 则存在环同构 $R\cong \prod\limits^n_{i=1} A_i$
  - **证明**：已知 $(a_1,...,a_n) \mapsto \sum\limits^n_{i=1}a_i$ 是加法阿贝尔群同构，只需证明其为环同构即可


## 同余

- **同余等价**：
  - 设 $R$ 是环，$A$ 是理想
  - 若 $a,b\in R$ 满足 $a-b\in A$，则称 $a,b$ 模理想 $A$ 同余
  - <font color='red'>显然同余是等价关系</font>
- **（定理2.25）中国剩余定理**：
  - 设 $\{A_i\}^n_{i=1} \in \I_R，\{b_i\}^n_{i=1}\in R$
  - 若满足
    - **平方不太小性**：$R = R^2+A_i$
    - **两两覆盖性**：$R = A_i+A_j\pad (\forall i\neq j)$
  - 则存在 $b\in R$ 使得 $b\equiv b_i \pmod {A_i}$
  - **引理**：此时有 $$\forall k，R = A_k + \dkh{\mathop{\bigcap}\limits_{i\neq k}A_i}$$
  - **证明（引理）**：
    - 只需证明 $k=1$ 的情况即可。下面对 $i$ 归纳
    - **初始条件**：$R = A_1 + (A_2\cap A_3)$
      - 由题设，$R^2 = (A_1+A_2)(A_1+A_3) = A_1^2 + A_1A_3 + A_2A_1 + A_2A_3 $
      - 由乘积缩小性，原式可改写为 $\subset A_1+A_2A_3 \subset A_1+(A_2\cap A_3)$
      - 再由题设，$R = A_1 + R^2 \subset A_1 + (A_2\cap A_3)\subset R$
      - 综上即得**初始条件**
    - **归纳假设**：
      - 已知 $R = A_1 + (A_2\cap\cdots \cap A_{k-1})$
      - 显然有 $R^2 = \Big(A_1 + A_2\cap\cdots\cap A_{k-1}\Big)(A_1 + A_{k}) = \cdots$
      - 仿照初始条件的方法即可
  - **证明（定理）**：
    - 由引理得 $\forall k，\exists a_k\in A_k，r_k\in \mathop{\bigcap}\limits_{i\neq k}A_i$ 使得 $b_k = a_k + r_k$
      - 也即 $\begin{cases} r_k\equiv b_k \pmod{A_k} \\ r_k\equiv 0\pmod{A_i} & i\neq k\end{cases}$
      - 最后取 $b = r_1 + \cdots + r_n$ 即可
  - **理解**：
  - **本质**：
    - <font color='red'>环的模理想同余就是群的正规子群陪集同余
    - 中国剩余定理在有限群中就是若 $\forall N_iN_j = G$，则 $G\Bigm /\mathop{\bigcap}\limits^n_{i=1} N_i \cong \prod\limits^n_{i=1} G/N_i$</font>
  - **推论（唯一性）**：$b$ 在模 $\bigcap A_i$ 同余下唯一
    - **证明**：
      - 反设不唯一，则总有 $b\equiv c\pmod {A_i}$
      - 由任意性，$b-c\in \bigcap A_i$，也即 $b\equiv c\pmod{\bigcap A_i}$
- **（推论2.27）商积定理**： <a id = "商积定理"></a>
  - 若 $A_1,...,A_n \in \I_{R}$
  - 则存在单同态 $\t:R/(A_1\cap \cdots \cap A_n)\to R/A_1\times \cdots \times R/A_n$
  - **证明**：
    - 由环范畴的范畴直积定理，规范商映射 $\pi_k$ 可导出商积环同态 $$\t_1: R\to \prod\limits^n_{i=1} R/A_i，r\mapsto (r+A_i)^n_{i=1}$$
    - 易得 $\ker \t_1 = \mathop{\bigcap}\limits^n_{i=1} A_i$。再由环同构定理，存在环单同态 $$\t:R\Bigm /\dkh{\mathop{\bigcap}\limits^n_{i=1} A_i} \to \prod R/A_i$$
  - **推论**：若满足中国剩余定理条件，则 $\t$ 是环同构
    - **证明**：
      - 由中国剩余定理可得同余关系
      - 此时 $\t(b+\cap A_i) = (b+A_i)^n_{i=1} = (b_i+A_i)^n_{i=1}$，从而是满射
    - **反例**：
      - 设 $R = \Z，A_1 = (6)，A_2 = (4)$
      - 则 $\t:R/(A_1\cap A_2)\to R/A_1\times R/A_2$ 不是满射
      - **证明**：此时 $\t:Z_{12}\to Z_6\times Z_4$，前者是12阶，后者是24阶

### 习题

- **性质传递**：设 $R = \prod R_i$，则
  - 交换性等价
  - 含幺性等价
  - 可逆性等价：$x = (x_i)$ 是 $R$ 的可逆元 $\LR x_i$ 均为可逆元
  - 理想直积性：若 $R$ 含幺，$I$ 是有限理想，则 $I = \prod A_i$
- **直积因子**：两个理想 $I_1\times I_2 = R$

## 直和

- **环直和**：两个环全体元素相加也是环
  - **证明**：定义即可
- **同构定理**：
  - 有限情况下，直和就是直积
  - 无限情况下，直和就是弱直积
  - **证明**
- **内直和**：
  - 设 $R$ 是环，$A,B$ 是双边理想
  - 若满足
    - **生成并性**：$R = A+B$
    - **不相交性**：$A\cap B = \{0\}$
  - 则称 $R = A\oplus B$
  - <font color='red'>因为环是加法阿贝尔群，所以直积与直和就是阿贝尔群的直积与直和定义</font>

### 单理想

- **极小左理想**：
  - 设 $I$ 是 $R$ 的左理想
  - 若 $I$ 只包含 $(0),I$ 两个 $R$ 的左理想，则称为极小左理想
  - <font color='red'>注意包含的是 $R$ 的左理想，不是 $I$ 的左理想</font>
- **单理想（极小双边理想）**：只有平凡双边理想的双边理想
  - <font color='red'>群和模可以叫单的，因为群的正规子群、模的子模都没有左右之分
  - 但环的理想有左右之分，所以把单边理想叫做"极小理想"，双边理想才叫"单理想"</font>
- **单环**：只有平凡双边理想的环
  - <font color='red'>单环是（自身理想平凡），单理想是（只包含总环中平凡理想）</font>

### 正交分解

- <font color='red'>环的投影分解实际上是（环作为自身的模的投影分解）
  - 它的本质在模论，应用在群表示论，故本节可跳过</font>
- **环的中心**：全体与所有元素乘法可交换的元素
- **幂等元素**：$e^2 = e$
- **正交元素**：若幂等元素 $e_ie_j = 0$，则称两元素正交
- **投影引理**：
  - 设 $R$ 是含幺环
  - 若中心元素 $e$ 幂等，则 $1_R-e$ 也是中心幂等元素，且彼此正交
  - **证明**：定义易得
- **正交分解引理**：
  - 含幺环 $R$ 中，若存在中心幂等元素 $e$
  - 则 $R = eR \oplus (1_R-e)R$
  - <font color='red'>因为是中心元素，故改为右乘也成立</font>
  - **证明（互包）**：
    - 易得 $\forall r \in R$，都有 $er + (1_R-e)r = r$，故 $R\subset eR\oplus (1_R-e)R$
    - 再由于 $\forall er +(s-es)\in R$，故 $eR\oplus (1_R-e)R \subset R$
  - **本质**：
    - <font color='red'>就是高代中关于投影空间 $U = \p(V)$ 和 $W = V-\p(V)$ 的分解</font>
- **正交分解定理**：设 $R，R_1,...,R_n$ 是含幺环，则下列条件等价
  - $R\cong \prod R_i$
  - $R = \sum A_i$，其中 $A_i\cong R_i$ 是 $R$ 的双边理想
  - $R$ 存在中心幂等的正交元素族，满足 $\sum\limits^n_{i=1} e_i = 1_R$，且 $e_iR\cong R_i$
  - <font color='red'>双边理想要求中心性。如果是非双边理想可以删去中心性</font>
  - **证明**：
    - $(1)\LR (2)$ 由内外直积定义直得
    - $(3)\LR (1)$ 由正交分解引理归纳直得
  - **实例**：
    - 向量空间（域）的正交基
    - 同余类的素幂分解
  - **反例（无存在性）**：
    - 设 $R = \tvec{k & k \\ 0 & k}$，Jacobson根为 $J(R) = \tvec{0 & k \\ 0 & 0}$
      - 双边理想只有 $0,J(R),R$
      - 极小双边理想只有 $J(R)$，显然 $0,R$ 都不是它的直和补，故无法分解

### 最细分解

- **可分解理想**：能写成两个非零理想的直和
- **本原幂等元**：不能表示成两个正交幂等元的和
- **本原分解定理**：
  - 设 $e\neq 1$ 是 $R$ 的幂等元
  - 则理想 $eR$ 不可分解 $\LR e$ 是本原幂等元
  - <font color='red'>如果是双边理想，条件和结论都要加上中心性</font>
  - **证明**：
    - **必要性**：
      - 反设 $e = e_1+e_2$，则由正交分解定理得 $eR = e_1R\oplus e_2R$，矛盾
    - **充分性**：
      - 反设 $eR = A_1\oplus A_2$，两投影分别为 $e = e_1+e_2$
      - 此时 $R = (1-e)R\oplus A_1\oplus A_2$，再由于 $1 = (1-e)+e_1+e_2$，则由正交分解定理，$1-e,e_1,e_2$ 两两正交，矛盾
- **中心本原定理**：
  - 本原中心幂等元两两正交
  - 若 $1$ 是本原中心幂等元的和，则它们是全部的本原中心幂等元
  - **证明（正交性）**：
    - 设 $e_1,e_2$ 是本原中心幂等元
    - 易得 $e_1 = e_1e_2 + e_1(1-e_2)$
      - 验证易得右边两项都是中心幂等元，与本原性矛盾，故只能是某项为零，即 $e_1,e_2$ 正交或相等
  - **证明（和性）**
    - 设 $1 = e_1 + ... + e_n$
    - 反设存在另外的本原中心幂等元 $f$，则 $f = 1f = e_1f + ... + e_nf = 0$，与本原性矛盾
- **累次分解定理**：
  - 设 $R$ 是有限维半单代数（Artin环）
  - 则
    - 本原中心幂等元可分解为本原幂等元的和
    - 极小双边理想可分解为极小单边理想的直和
  - <font color='red'>当极小双边理想同时也是极小单边理想时，因子只有一个，是平凡分解</font>
  - **证明**：
    - **局部含幺性**：
      - <font color='red'>直和分解定理要求是含幺环。虽然双边理想不含总环的幺元，但它自身作为环时含幺（本原中心幂等元）</font>
      - 由群表示论的左正则模分解定理，极小双边理想必定存在本原中心幂等元。易得它满足幺元的一切性质
    - **极小单边理想存在性**：
      - <font color='red'>如前面反例，若不存在极小单边理想，当然也无法直和分解</font>
      - 由群表示论的左正则模分解定理，有限维半单代数必定存在极小左理想
    - **直和分解性**：
      - 显然（双边理想）必定是（单边理想），但反之不一定
      - 同理（本原中心幂等元）必定是（本原幂等元），但反之不一定
  - **本质**：
    - <font color='red'>（中心内不可分解）不等于（全局内不可分解）
    - 关于有限维半单代数，详见群表示论</font>
  - **实例**：
    - $R = \R^{2\times 2}$
      - 中心为纯量矩阵，单位矩阵是本原中心幂等元
      - 单元矩阵是本原正交幂等元，从而 $I_2 = E_{11} + E_{22}$
      - $R$ 是极小双边理想，$R = RE_{11}\oplus RE_{22}$
  - **反例（局部含幺，但无极小单边理想）**：
    - Jacobson半单且非Artin的单环，其自身是极小双边理想，不含任何极小左理想，故无法直和分解
