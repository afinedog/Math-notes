# 表示空间的完全分解

- **符号约定**：
  - $M_n(D)$ 表示 $D$ 上的 $n$ 阶矩阵环

## 态射矩阵表示法

- **Wedderburn定理**：
  - 设 $B$ 是域 $K$ 上有限维单代数，$I$ 是 $B$ 的极小左理想，$D = \Hom_B(I,I)$
  - 则
    - $D$ 是除环，$I$ 是 $D$ 上的有限维右线性空间，$D$ 是域 $K$ 上有限维线性空间 $$ \dim_K I = (\dim_K D)(\dim_D I)$$
    - 存在 $K$ 代数同构 $$ B\cong \Hom_D(I,I) \cong M_n(D)$$
  - **证明**：见下面

### 除环性

- **线性变换定理**：设 $V$ 是除环 $D$ 上的 $n$ 维右线性空间，则 $\Hom_D(V,V)\cong M_n(D)$
  - <font color='red'>右线性空间中，元素是列向量，线性变换是矩阵左乘
  - 左线性空间中，元素是行向量，线性变换是矩阵右乘
  - 习惯上用列向量，故取右线性空间</font>
  - **证明**：
    - 由高代知识，线性空间都同构于数组空间，故矩阵和线性变换一一对应
- **Schur引理1**：设 $V\ncong W$ 都是环 $R$ 上的不可约左模，则 $\Hom_R(V,W) = \{0\}$
  - **证明**：
    - 设 $f\in \Hom_R(V,W)$
    - 显然 $\ker f$ 是 $V$ 子空间，故由不可约性，只能是单射或零映射
    - 再由于 $\Im f$ 是 $W$ 子空间，故由不可约性，只能是满射或零映射
    - 再由不同构性即得只能是零映射
- **Schur引理2**：设 $V$ 是环 $R$ 上的不可约左模，则 $\Hom_R(V,V)$ 是除环
  - **证明**：
    - 由上个引理，同态只能是同构或零映射
    - 再由同构可逆性即得结论
- **单矩阵定理**：设 $D$ 是除环，则 $M_n(D)$ 是单环
  - **证明**：
    - 显然除环是单环。再由线性变换定理 + Schur引理2即得结论

### 线性空间性

- **空间引理**：若取右乘运算 $xd = d(x)$，则 $I$ 是 $D = \Hom_B(I,I)$ 上的有限维右线性空间
  - **证明（线性空间）**：
    - 由Schur引理2得 $D$ 是除环
    - 验证易得满足线性封闭性 + 运算律
  - **证明（有限维）**：
    - **反转公式**：
      - 再由代数的数乘交换结合律，任取 $k\in K，x\in I$ 有 $$kx = (k1_K)x = k(1_Dx) = k(x1_D) = x(k1_K)$$
      - 易得 $(k1)_R:I\to I，x\mapsto x(k1_K)$ 是模同态，即 $(k1)_R\in D$
    - **基代换**：
      - 由 $B$ 是有限维代数即得子模 $I$ 在 $K$ 上是有限维的
      - 设 $\dim_K I = m$，则存在一组基 $\a_1,...,\a_m$
      - 此时基表出公式满足 $$\forall x\in I，x = \sum\limits^m_{i=1} k_i\a_i = \sum\limits^m_{i=1} \a_i(k_i1)_R$$，故也是 $D$ 上的有限维右线性空间
- **维数公式**：
  - <font color='red'>由模论结论，当线性空间满足嵌套关系 $I\subset D\subset K$ 时，可得维数公式</font>
  - **证明**：
    - **线性空间**：若取右乘运算 $kd = d\circ (k1)_R$，易得 $D$ 是 $K$ 上的双边线性空间
    - **有限维性**：易得 $ \forall x\in I，(kx)d = k(xd)$，故 $D\subset \Hom_K(I,I)$，从而 $$\dim_K D\leq \dim_K\Big[ \Hom_K(I,I) \Big] = (\dim_K I)^2$$

### 态射类同构


- **态射代数引理**：$\Hom_D(I,I)$ 是 $K$ 上的代数
  - **证明**：
    - 取线性变换的加法和乘法，易得其构成环
    - 取数乘运算 $(kA):x \mapsto k(Ax)$，易得其构成代数
- **代数同构引理1**：$B$ 和 $\Hom_D(I,I)$ 是代数同构关系
  - **证明**：
    - 任取 $b\in I$，易得左平移作用 $b_L\in\Hom_D(I,I)$
      - <font color='chartreuse'>$b_L(xd) = b(xd) = (bx)d  = b_L(x)d$</font>
    - 考虑 $\sigma:B\to \Hom_D(I,I)，b\mapsto b_L$
      - **保幺同态性**：易得
      - **单射性**：
        - $\ker\sigma$ 是 $B$ 的双边理想，再由 $B$ 不可约得是单射或零映射
        - 由左平移存在性得只能是单射
      - **满射性**：
        - 只需证 $B_L = \Im\sigma$ 是陪域的左理想，由其含幺性即得满射性
        - 易得 $IB$ 是 $B$ 的双边理想，再由单性得 $IB = B$，故只需证 $(IB)_L$ 是左理想
        - 任取 $T\in \Hom_D(I,I)，y\in I，b\in B$，由于 $Ty\in I$，故只需证 $T(yb)_L = \Big[ (Ty)b \Big]_L$，即等价于证 $T(yx) = (Ty)x$
        - 易得右平移作用 $x_R\in \Hom_B(I,I) = D$，从而上式成立

### 矩阵同构

- **矩阵代数引理**：$M_n(D)$ 是 $K$ 上的代数
  - **证明**：
    - 已知 $D$ 是 $K$ 上的双边线性空间，将该右乘运算拓展到矩阵上即得 $M_n(D)$ 也是 $K$ 上线性空间
    - 再验证易得其满足代数的运算性质
- **代数同构引理2**：$\Hom_D(I,I)$ 和 $M_n(D)$ 是代数同构关系
  - **证明**：
    - 易得是环同构
    - 再验证发现它保数乘运算，故也是代数同构



## 直和分解

### 矩阵环的单边理想分解

- **单列左理想**：设 $M_n^{(j)}(D)$ 是全体除第 $j$ 列外元素均为 $0$ 的矩阵，则它是左理想
- **除环矩阵分解定理**：
  - 设 $D$ 是除环
  - 则 $M_n(D)$ 可分解为彼此同构的极小左理想的直和 $$M_n(D) = \sum\limits^n_{i=1}M_n(D)E_{ii}$$
  - **证明**：
    - **直和性**：
      - 显然 $M_n(D) = \sum\limits^n_{j=1}M_n^{(j)}(D)$
      - 再易得 $E_{ii}$ 是正交幂等元，且 $M_n^{(j)}(D) = M_n(D)E_{ii}$
    - **极小性**：
      - 反设 $J\subset M_n(D)E_{kk}$
      - 任取 $C = (c_{ij})\in J$，不妨设 $c_{lk}\neq 0$，显然 $$ (c_{lk}^{-1}E_{kl})C = (c_{lk}^{-1}E_{kl})\sum_{i,j}E_{ij} = E_{kk}$$
      - 由理想吸收性，$E_{kk}\in J$，从而 $M_n(D)E_{kk}\subset J$
    - **同构性**：
      - 由于 $E_{1i}E_{ij} = E_{1j}\neq 0$，故 $\Big[ M_n(D)E_{ii} \Big]\Big[ M_n(D)E_{jj} \Big] \neq \{0\}$
      - 由极小左理想定理，两者彼此同构


### 有限维单代数的单边理想分解

- **有限维单代数分解定理**：
  - 设 $B$ 是域 $K$ 上的有限维单代数，$I$ 是 $B$ 的极小左理想，$D = \Hom_B(I,I)$
  - 则 $B$ 可被彼此同构的极小左理想直和分解，因子个数为 $\dim_D I$
  - **证明**：
    - 由Wedderburn定理 + 除环矩阵分解定理直得

## 有限维半单代数的完全分解

- **完全分解定理**：
  - 设
    - $A$ 是 $K$ 上的有限维半单代数
    - $A$ 作为环到极小双边理想的分解为 $A = A_1\oplus ... \oplus A_s$
    - $A$ 作为环到极小左理想的分解为 $A = \sum\limits^{m_1}_{j=1} L_{1j} \oplus ... \oplus \sum\limits^{m_s}_{j=1} L_{sj}$
    - $D_i = \Hom_{A_i}(L_{i1},\ L_{i1})$
    - $\dim_K L_{i1} = d_i$
    - $\dim_{D_i} L_{i1} = \tilde d_i$
  - 则
    - 极小双边理想 $A_i$ 的极小左理想分解的因子个数 $m_i = \tilde d_i$
    - $\dim_K A = \sum\limits^s_{i=1} \tilde d_id_i$
  - **证明**：
    - 上一章的两个定理得到了分解的结构，这一章的定理得到了分解的维数计算方法



### 代数闭域情况

- **Schnr引理**：
  - 设 $A$ 是代数闭域 $K$ 上的代数，$V$ 是有限维不可约左 $A$ 模，$D = \Hom_A(V,V)$
  - 则 $D = K1_V \cong K$
  - **证明（右包左）**：
    - 已知 $D\subset \Hom_D(V,V)$，故线性变换 $d$ 存在特征值 $\l$
    - 任取 $\a\in V_\l$，$a\in A$，则 $$ d(a\a) = a(d\a) = a(\l\a) = ... = \l(a\a) $$
    - 故 $a\a\in V_\l$，即 $V_\l$ 是左 $A$ 模，再由 $V$ 不可约性即得 $V_\l = V$，即其上只有数乘变换，从而 $D\subset K1_V$
  - **证明（左包右）**
    - 任取 $k1_V\in K1_V$，则同上易得 $k1_V \in \Hom_A(V,V) = D$，即 $K1_V\subset D$
- **完全分解定理（代数闭域）**：
  - 设 $A$ 是代数闭域 $K$ 上的有限维半单代数，记号同上
  - 则
    - $\forall 1\leq i\leq s$，存在环同构 $D_i\cong K$，从而 $\tilde d_i = d_i$
    - 即 $\dim_K A = \sum\limits^s_{i=1} \Big[ \dim_K(L_i1) \Big]^2$
  - **证明**：
    - 由完全分解定理 + Schnr引理直得
