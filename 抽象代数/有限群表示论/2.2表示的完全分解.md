# 表示的完全分解

- **符号约定**：
  - $e_i$ 表示本原中心幂等元，个数为 $s$
- **类函数**：
  - 设 $f$ 是群 $G$ 上的函数
  - 若 $G$ 的共轭类的函数值都相等，则 $f$ 称为 $G$ 上的类函数

## 总理论

- **群表示完全分解定理**：
  - 设 $G$ 是有限群，$\char K$ 不整除 $|G|$
  - 则
    - 任意 $K$ 表示都可分解为不可约表示的直和
      - 极小双边理想 $A_i$ 对应彼此等价的不可约表示之和，个数 $s$ 是本原中心幂等元个数
      - 极小单边理想 $L_{ij}$ 对应彼此等价的不可约表示，个数 $\tilde d_i$ 和次数 $d_i$ 由后面的定理给出
      - <font color='red'>但不一定包含全部不可约表示</font>
    - 正则 $K$ 表示是唯一满足直和因子 $\p_i$ 的重数均为 $\deg\p_i$ 的 $K$ 表示
      - <font color='red'>在所有（包含全部不可约表示）的表示里，正则表示是次数最小的
      - "全包含表示"都是正则表示添加某些重复因子而已</font>
  - **证明（对应性）**：
    - 已知正则表示的表示空间就是左正则模 $K[G]$，由Masche定理 + 群代数定理得它是有限维半单代数，由Masche定理（正则版本）得它包含全部的不可约表示，故上面的完全分解定理就是正则表示的分解定理
    - 由Masche定理得任意 $K$ 表示都可分解，再由Masche定理（正则版本）得任意分解都是正则表示分解的一部分

## 次数

- **重数**：（不可约表示 $\p$）在（正则表示 $\rho$ 的直和分解式）中对应因子的重数
- **重数定理**：若 $K$ 是代数闭域，则 $\p$ 在 $\rho$ 中重数 $= \deg\p$
  - **证明**：
    - 已知表示的次数就是表示空间的维数，再由完全分解定理（代数闭域）得此时重数 $\tilde d_i$ 等于维数 $d_i = \deg\p_i$
- **次数定理**：
  - 设
    - $G$ 是有限群，$K$ 是代数闭域
    - $\p_1,...,\p_s$ 是互不等价的不可约复表示
  - 若 $\char K$ 不整除 $|G|$，则 $|G| = \sum\limits^s_{i=1} (\deg \p_i)^2$
  - **证明**：
    - 由重数定理 + 完全分解定理（代数闭域）直得

## 个数


- **个数引理**：
  - 设
    - $G$ 是有限群，$K$ 是域
    - $s$ 是 $G$ 的互不等价的不可约复表示个数，$r$ 是 $G$ 的共轭类个数
  - 若 $\char K$ 不整除 $|G|$，则 $s\leq r$
  - <font color='red'>中心就是共轭不变元，显然共轭类之和满足，再发现它构成中心的基
  - 即共轭类数量 = 群代数中心的维数（基的数量）</font>
  - **证明**：
    - 已知 $s$ 是 $K[G]$ 的本原中心幂等元个数，由正交性易得 $e_i$ 线性无关，从而 $s\leq \dim_K C\ddkh{K[G]}$
    - 已知 $G$ 是 $K[G]$ 的基，故 $a\in C\ddkh{K[G]} \LR \forall g\in G，gag^{-1} = a$
      - 设 $a = \sum\limits_{x\in G} k_xx$，则 $$ gag^{-1} = \sum_{x\in G}k_xgxg^{-1} = \sum_{y\in G} k_{g^{-1}yg} y = \sum_{x\in G} k_{g^{-1}xg}x $$
      - 再由基表出的唯一性，$a\in C\ddkh{K[G]} \LR \forall g,x\in G，k_{g^{-1}xg} = k_x$
      - <font color='red'>即 $x$ 的共轭类的系数 $k_x$ 都相等</font>
    - 设 $C_1,...,C_r$ 是全部共轭类，类和 $c_i = \sum\limits_{x\in C_i} x$，显然 $c_i\in C\ddkh{K[G]}$
      - 由系数相等，取共轭类的代表元系 $x_i$，则 $a\in C\ddkh{K[G]} \LR a = \sum\limits^r_{i=1} k_{x_i}c_i$
      - 再易得 $c_i$ 线性无关，故构成 $C\ddkh{K[G]}$ 的一组基，即 $\dim_K C\ddkh{K[G]} = r$
  - **理解**：
    - 中心共轭不变性 + 基表出唯一性 = 中心共轭类被表出系数相等
    - 再加上共轭类和线性无关性 = 中心元素的共轭类和表出式 = 共轭类和是中心的基
- **个数定理**：在上面条件下，若 $K$ 是代数闭域，则 $s = r$
  - <font color='red'>要求中心在 $K$ 上的维数
    - 首先将中心直和分解
    - 将因子同构为矩阵，再用代数闭域化为 $K$ 上矩阵
    - 最后发现矩阵的中心就是 $K$ 本身，从而维数为 $1+...+1 = s$</font>
  - **证明**：
    - 由极小双边理想分解定理，$K[G] = A_1 \oplus ... \oplus A_s$
      - 其中 $A_i$ 是单环，$L_{i1}$ 是 $A_i$ 的极小左理想
    - **中心分解**：
      - 已知 $A_iA_j = \{0\}$，故中心满足直和传递性 $C\ddkh{K[G]} = C(A_1) \oplus ... \oplus C(A_s)$
    - **矩阵同构**：
      - 设 $D_i = \Hom_{A_i}(L_{i1},\ L_{i1})$，$\tilde d_i = \dim_{D_i} L_{i1}$，则由Wedderburen定理得 $A_i\cong M_{\tilde d_i}(D_i)$
      - 再由完全分解定理（代数闭域），$D_i\cong K$，故 $A_i\cong M_{\tilde d_i}(K)$
    - **矩阵中心**：
      - 易得 $C\ddkh{M_{\tilde d_i}(K)} = KI_{\tilde d_i} \cong K$
      - 故 $$C\ddkh{K[G]}\cong C\ddkh{M_{\tilde d_1}(K)}\oplus ...\oplus C\ddkh{M_{\tilde d_s}(K)} \cong \sum\limits^s_{i=1} K$$
      - 显然此时 $\dim_K C\ddkh{K[G]} = s$
