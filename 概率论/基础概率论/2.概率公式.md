# 概率公式

## 加法公式（容斥原理）（事件的并）

- **二阶容斥原理**：$P(A\cup B) = P(A) + P(B) - P(AB)$
  - **证明**：取补分拆后，由可加性直得
- **容斥原理（概率形式）**：$$\begin{matrix} P(\mathop{\cup}\limits^n_{j=1}A_j)  & = & \sum\limits^n_{j=1}A_j + (-1)\sum\limits_{1\leq j_1 < j_2\leq n}P(A_{j_1}A_{j_2}) + ... \\\ \\ && + (-1)^{k-1}\sum\limits_{1\leq j_1<j_2<...<j_k\leq n} P(A_{j_1}A_{j_2}...A_{j_k}) + ...  \\\ \\ && + (-1)^{n-1}P(A_1A_2...A_n) \end{matrix}$$
  - **本质**：<font color='red'>只是用了很多次的集合分配律而已</font>
  - **推论**：任意满足有限可加性的集合函数都满足上面的公式
- **容斥原理（古典概型）**：
  - 若所有事件的概率相等，则 $P(\mathop{\cup}\limits^n_{i=1}A_i) = \sum\limits^n_{k=1} (-1)^{k-1} C^k_n P(A_1A_2...A_k)$
  - <font color='red'>它可以把复杂的 $n$ 选 $m$ 问题分解成多个 $n$ 选 $1$ 问题</font>

### 习题（组合数学）

- **复杂排列问题**：设 $n$ 个人分别在 $m$ 个球中各选一个，求至少有一个选中/选不中的概率
- **配对问题**：$n$ 个人乱序排列编号，求至少有一个得到自己顺序编号的概率

## 乘法公式（事件的交）

### 独立事件

- **独立事件**：若事件 $A,B$ 不相交，则称为它们彼此独立。即 $P(AB) = P(A)P(B)$
  - <font color='red'>现实意义就是，事件 $A$ 发生的次数再多，也跟事件 $B$ 的发生概率无关</font>
  <!-- - 所有乘法公式的数量：$\sum\limits^\infty_{i=2} C^i_n = 2^n-n-1$ -->
- **独立事件的传递**：
  - **子集传递性**：独立事件的子集也相互独立
  - **补传递性**：独立事件的补集也相互独立
  - **并传递性**
  - **交传递性**
- **相互独立**：若一列事件的任意组合都不相交，则称它们相互独立
  - **公式定义法**：
    - 设 $A_1,...,A_n$ 是一列事件，$D_i = A_i\ 或\ \overline{A_i}$
    - 若 $P(D_1...D_n) = P(D_1)...P(D_n)$ 均成立，则 $A_i$ 相互独立
    - **证明**：
      - **充分性**：全体乘法公式共有 $2^n-n-1$ 个，而上面的公式共有 $2^n$ 个，故此时所有乘法公式都成立
      - **必要性**：归纳法即可
  - **实例（两两独立，但不相互独立）**：
    - 设四面骰的三个面分别是 $A,B,C$ 色，一个面同时有三色
    - 则投骰子时，事件 $A,B,C$ 两两独立，但整体不独立
    - **证明**：
      - $P(A)=P(B)=P(C) = \dfrac{1}{2}$
      - $P(AB)=P(AC)=P(BC)=\dfrac{1}{4}$，显然两两独立
      - $P(ABC) = \dfrac{1}{4}$，故不相互独立
- **独立事件列**：相互独立的一列事件

### 独立试验

- **独立试验**：彼此互不影响的试验
- **独立定理**：独立试验的事件彼此独立
  - **证明**：显然
- **直积定理**：将多次独立试验看作一次整体试验时，则整体的样本空间是各个独立试验的直积
  - **证明**：显然

### 实例

- **多次抽签问题**：$n$ 个签里，有 $m$ 个好签。每次无放回抽取一个，则第 $j$ 次抽中的概率是 $\dfrac{m-j+1}{n}$
  - <font color='red'>每次抽取后，都可看作一个新抽签模型。即每次抽取互为独立试验</font>
- **单次抽签问题**：$n$ 个签里，有 $m$ 个好签。每次无放回抽取 $k$ 个，则抽中 $L$ 个的概率是 $P(l) = \cfrac{C^l_mC^{k-l}_{m-l}}{C^k_n}$
  - <font color='red'>因为是同一时刻抽取，所以是超几何分布</font>

## 条件概率

- **条件概率**：$P(B|A)$ 表示已知事件 $A$ 发生的条件下，求事件 $B$ 发生的概率
  - **实例**：
    - 已知连续生了 $n$ 个男孩时，下一胎是女孩的概率不是 $50\%$
      - 因为生男生女的 $50\%$ 是统计学意义下的概率，而非独立事件的概率。所以应当使用条件概率的公式（贝叶斯公式）
- **条件概率公式**：$P(B| A) = \cfrac{P(AB)}{P(A)}$
  - **证明**：古典概型的样本点证明法
- **一般的乘法公式**：
  - 设 $A_1,...,A_n$ 是一列事件（不相互独立）
  - 则 $P(A_1A_2...A_n) = P(A_1)P(A_2| A_1)...P(A_n| A_1...A_{n-1})$
  - **证明**：由条件概率定义式 + 累乘法直得
- **$\sigma$ 域的限制**：
  - 已知概率空间 $(\Omega,\mathcal{F},P)$，若 $C \in \mathcal{F}$ ，则条件概率 $P_C$ 也是 $\mathcal{F}$ 上的概率
    - 已有非负性
    - $\Omega$ 只需取子集 $C \to$ 和1性
    - 独立性的交集传递 $\to$ 可列可加性
  - **叠加公式**：$P_C(A| B) = P(A| BC)$（定义证明）
    - 本质是限制的叠加

### 实例

  - 无法挽回问题（摔坏、造假）

## 限制公式

### 全概率公式（Lebesgue可测）（限制的相加）

- **全概率公式（二阶）**：
  - 设 $A,B$ 是两个事件
  - 则 $P(B) = P(B| A)P(A) + P(B|\ol A)P(\ol A)$
  - **证明**：由条件概率公式直得
- **完备事件组**：互不相容的一组事件
- **全概率公式（完备事件组）**：$P(B) = \sum\limits^n_{j=1}P(A_j)P(B|A_j)$

#### 实例

- **二重分类问题**：
  - 设
    - 坐自行车上班的概率为 $a_1$，晚点的概率为 $a_2$
    - 坐汽车上班晚点的概率为 $b_1$，晚点的概率为 $b_2$
  - 已知上班晚点的情况下，求坐自行车和坐汽车的概率
  - **解**：
    - 设上班晚点的事件为 $L$，则由全概率公式得 $$P(L) = P(L|A)P(A) + P(L|B)P(B) = a_2a_1 + b_2b_1$$
- **不记名调查问题**
  - 设总人群中，某些人具有敏感特征
  - 现开展不记名调查，只记录回答"是"或"否"，不记录问题
  - 设
    - $A$ 表示回答是，$\ol A$ 表示回答否
    - $B$ 表示抽到敏感问题，$\ol B$ 表示抽到非敏感问题
  - 已知抽到敏感问题的概率为 $\pi$，调查 $n$ 人有 $m$ 人回答"是"，求敏感特征比例
  - **解**：
    - 设比例为 $p$，则 $$ P(A) = P(A|B)P(B) + P(A|\ol B)P(\ol B) = p\pi + (1-p)(1-\pi) $$
    - 再由于 $P(A) = \dfrac{m}{n}$，解方程即得 $p$
- **赌徒破产模型**：
  - 设本金有 $a$ 元，赢 $b$ 元结束，输赢概率相等，求输光概率
  - **解**：
    - 设 $k$ 元本金输光为 $B_k$，本局赢为 $A$，则显然有 $\begin{cases} P(B_k|A) = P(B_{k+1}) \\\\ P(B_k|\bar{A}) = P(B_{k-1}) \end{cases}$
    - 再由全概率公式即得递推公式，从而 $P(B_a) = 1-\cfrac{a}{a+b}$
- **零和博弈模型**：
  - 设有 $n$ 个赌徒，都想要赢得其它所有人的本金。求第 $i$ 个赌徒输光概率
  - **解**：
    - $P(a_i) = 1-\frac{a_i}{\sum a_i}\to 1$
- **波利亚坛子模型**：
  - 设坛子中有 $b$ 个黑球，$r$ 个红球，取完球后放回相同的球 $a$ 个，求第 $n$ 次取出黑球的概率 
  - **解1**：数学归纳法 + 二阶全概率公式证明 $P = \cfrac{b}{b+r}$
  - **解2**：直接全概率公式即可


### 贝叶斯公式

- **贝叶斯公式（二阶）**：$P(A|B) = \cfrac{P(B|A)P(A)}{P(B|A)P(A) + P(B|\bar{A})P(\bar{A})}$
  - <font color='red'>就是条件概率形式 + 全概率公式
  - 无需死记硬背，只需要记住它是用条件概率去求条件概率，然后自己倒腾倒腾就行</font>
  - **证明**：
    - $P(A|B) = \cfrac{P(AB)}{P(B)}$，分母用全概率公式，分子用条件概率公式
- **Bayes公式（完备事件组）**：设 $A_1,...,A_n$ 是完备事件组，则 $$P(A_j|B) = \cfrac{P(A_j)P(B|A_j)}{\sum\limits^n_{i=1}P(A_i)P(B|A_i)}，1\leq j\leq n$$

#### 实例

- **条件反转问题**：二重分类问题下，已知二级结果，反推一级结果
- **上班晚点**：
- **贝叶斯决策**：决定哪种二重分类更适用
  - 定义先验概率和后验概率
  - 抽取我们期望的特征，求该后验概率确定时不同抽取方法的先验概率，哪个大选哪个

## 概率极限

- **上极限**：$A_n\ i.o.$
- 包含关系、对偶关系、单调收敛关系
- **Borel-Cantelli引理**：
  - 若概率级数收敛，则 $P(A_n\ i.o.) = 0$
  - **证明**：
    - $P(\mathop{\bigcap}\limits^\infty_{n=1}\mathop{\bigcup}\limits^\infty_{j=n} A_j) = P(\mathop{\cap}\limits^\infty_{n=1}C_n\downarrow)$
    - 概率连续性，$ = \lim\limits_{n\to\infty}P(\mathop{\cup}\limits^\infty_{j=n}A_j)$
    - 三角不等式，$\leq \lim\limits_{n\to\infty}\sum\limits^\infty_{j=n}p_j$
    - 由Cauchy收敛原理，结果为0
  - 若事件独立，概率级数发散，则 $P(A_n\ i.o.) = 1$
  - **证明**：
    - $P(\mathop{\cap}\limits^\infty_{n=1}\bar{A}_j)$，独立乘法公式 + 补集的概率
    - 由不等式 $1-x \leq e^x$，指数性质化乘法为加法，极限为0，则补集极限为1
  - **推论**：独立事件列的概率上极限只能是1或0
  - **应用**：墨菲定律（P=1）、低维几何概型（P=0）

### 棋局问题

- **棋局问题**：
  - 设甲和乙下棋，甲胜的概率为 $p$，乙胜的概率为 $q$，在一方连续赢两次时结束游戏
  - **解（事件列法 + 方程法）**：
    - 设 $\begin{cases} A_n：到第n局时甲获胜 \\ B_n：到第n局时乙获胜 \\ C_n：到第n局时平局 \end{cases}$
    - 若没有出现过平局
      - 显然 $\begin{cases} P(A_n) = P(D_{n-2})p^2 \\ P(B_n) = P(D_{n-2})q^2 \end{cases}$。再由概率的和1性即得 $P(A_n) = \cfrac{p^2}{p^2+q^2}$
    - 若出现过平局
      - 因为前面的求法和平局的概率无关，而且有平局的获胜条件和没有平局一样，所以概率相等（相当于平局是穿插在胜负局中的无意义事件）
  - **解（古典概型法 + 数列法）**：
    - 若没有出现过平局
      - 不断列举甲获胜的情况，发现其概率构成等比数列，加和得到概率 $P = \frac{p^2(1+pq)}{1-pq}(q=1-p)$
