# 基础数理统计

- **总体**：所有随机变量构成的集合
- **总体分布**：总体组合成的随机向量的分布
- **总体平均**：总体的算术平均值 $\ol X = \dfrac{1}{n}\sum\limits^n_{i=1} x_i$
- **中位数**：若 $P(X\leq m) = F(m) = \dfrac{1}{2}$，则称 $m$ 是随机变量 $X$ 的中位数
- **总体方差（算术方差）**：$\sigma^2 = \dfrac{1}{m}\sum\limits^m_{i=1} (x_i-\mu)^2$

## 数学期望（加权平均值）

- **随机变量的数学期望（均值）**：$E(X) = \sum\limits_{全体取值x} xP(X = x)$
  - **离散型**：$E(X) = \sum\limits^\infty_{j=0} x_jp_j$
  - **连续型**：$E(X) = \dis\int^{+\infty}_{-\infty} xf(x)dx$
  - <font color='red'>数学期望其实就是加权平均值，$x_i$ 是样本值，$p_i$ 是样本权重（所占比例/所占数量）
  - 算数平均值是特殊的加权平均值，每个样本的权重相等（概率相等）</font>
- **存在性**：我们定义：若 $|X|$ 的数学期望有限，则称 $X$ 的数学期望存在
  - <font color='red'>实际上勒贝格可积就是定义为绝对可积的
  - 这样做的目的是防止随机变量的相加顺序重排后结果不同</font>
  <!-- - **连续型**：$\dis E|X| = \int^{+\infty}_{-\infty} |x|f(x)dx$ -->
- **唯一性**：每个分布的期望是唯一的
<!-- - **平移意义**：数学期望又称为概率分布的重心 -->
- **矩**：设 $E(X)$ 是数学期望，则 $E(X-c)^k$ 称为随机变量 $X$ 关于点 $c$ 的 $k$ 阶矩
    - **原点矩**：$c = 0$
    - **中心矩**
    - **偏度系数**：$\beta = \frac{}{}$
- **矩空间 $L^r$**：存在 $r$ 阶矩的所有随机变量构成线性空间
  - <font color='red'>实际上就是测度论的 $L^p$ 空间</font>

### 频率极限

- **独立重复试验的期望**：进行无限次独立重复试验后，随机变量的取值收敛到算数平均值 $\ol{X_n} = \cfrac{\sum X_i}{n}$
  - <font color='red'>数学期望的统计意义就是进行无穷次试验后的平均值</font>
  - **证明**：
    - 已知频率比例的极限 = 概率
    - 故 $\lim\limits_{n\to\infty} X_n = \sum\limits^{k最大值}_{k=0} k× 频率比例N(概率p_k) = E(X)$
  - **实例**：
    - 柯西分布的数学期望不收敛，平均值发散
    - 柯西分布的绝对值，数学期望无穷，平均值随试验次数增加而递增

### 常见分布的数学期望

- **伯努利分布**：$X\sim \mathcal{B}(1,p)$：$EX = p$
  - **应用**：示性函数服从伯努利分布，所以 $EI[Y\leq y] = F_Y(y)$
- **二项分布**：$X\sim \mathcal{B}(n,p)$：$EX = np$
  - **证明**：<font color='chartreuse'>利用 $jC^j_n = nC^{j-1}_{n-1}$ 配凑二项式幂</font>
- **泊松分布**：$X\sim \mathcal{P}(\l)$：$EX=\l$
  - **证明**：<font color='chartreuse'>分离 + 退化 = 配凑“概率和1式”</font>
- **几何分布**：$X\sim G(p)$：$EX = \frac{1}{p}$
  - **证明**：<font color='chartreuse'>逐项求导定理，配凑为级数的导数</font>
- **指数分布**：$X\sim \mathcal{E}(\l)$：$EX = \frac{1}{\l}$
  - **证明**：<font color='chartreuse'>直接计算</font>
- **超几何分布**：$X\sim H(N,M,n)$：$EX = \frac{nM}{N}$
  - **证明**：<font color='chartreuse'>抽签问题中，有放回和无放回都是 $EX_i = \frac{M}{N}$，分解成抽签问题，利用期望线性即可</font>
- **对称分布**：若 $f(\mu+x)=f(\mu-x)$，则 $EX=\mu$
  - **证明**：
    - 先换元为 $t+\mu$，再线性分解为 $\dis\int_R \mu f(x)dx + \int_R tf(t+\mu)dt$
  - **应用**：
    - 正态分布 $EX=\mu$
    - 均匀分布 $U(a,b)\ EX=\frac{a+b}{2}$

### 计算方法

- **线性**：$E(aX + bY) = aEX + bEY$
  - **证明**：定义易得
- **独立乘法公式**：若 $X,Y$ 独立，则 $XY$ 期望存在，且 $E(XY) = EX\cdot EY$
  - **证明**：
    - 由独立性得 $f(x,y) = f_1(x)f_2(y)$，累次积分即可
- **数学期望映射定理**：
  - 设 $g$ 是随机变量的映射
  - 若 $g(X)$ 的数学期望存在，则 $Eg(X) = \sum\limits_{全体取值x}xP\dkh{g(X) = x}$
    - **离散型**：$Eg(X) = \sum\limits^\infty_{j=1} g(x_j)p_j$
    - **连续型**：$Eg(X) = \dis\int^{+\infty}_{-\infty} g(x)f(x)dx$
  - **证明**：定义易得
- **二维情况以及映射定理**
- **换序公式**：设 $X$ 是非负随机变量
  - **离散型**：$EX = \sum\limits^\infty_{k=1}\sum\limits^\infty_{j=k}p_j$
  - **连续型**：$EX = \dis\int^{+\infty}_0 P(X>x)dx$
  - **证明（离散型）**：
    - 显然 $EX = \sum\limits^\infty_{j=1} jp_j = \sum\limits^\infty_{j=1}\sum\limits^j_{k=1}p_j = \sum\limits^\infty_{k=1}\sum\limits^\infty_{j=k} p_j$
  - **理解**：
    - 画一个二维下三角表格。前面是横着加，后面是竖着加
    - 横着相加只是数量的累积，也就是给权重以样本值（而不是通常意义的给样本值以权重）
    - 竖着加贯彻了这一特征，还采用了筛选制，一层一层淘汰那些样本值不够的权重
  - **证明（连续型）**：
    - 易得 $\dis x =\int^x_0 dy = \int^{+\infty}_0 \chi_{\{y<x\}}dy$
    - 将期望公式化为二重积分，再累次、换序、重组即可 $$\hspace{-0.5em}\dis EX = \int^{+\infty}_{-\infty} xf(x)dx = \int^{+\infty}_0 dy\int^{+\infty}_{-\infty} \chi_{\{y<x\}}f(x)dx = \int^{+\infty}_0 P(X>y)dy$$

### 习题

- **单调性**：若 $P(X_1\leq X_2) = 1$，则 $EX_1\leq EX_2$
  - **证明**：设 $Y=X_2-X_1$，再由线性即可
- **Jensus不等式**：设 $g(x)$ 是博雷尔可测实值凸函数，若 $EX$ 存在，则 $g(EX) \leq Eg(x)$ 
  - **证明**：由凸函数的Jensus不等式易得
- **C-R不等式**：
  - 若 $X_1,X_2\in L^r$，则 $E|X_1+X_2|^r \leq C_r\ddkh{E|X_1|^r + E|X_2|^r}$
  - 其中 $C_r = \begin{cases} 1，\quad 0<r<1 \\ 2^{r-1}，\quad r\geq 1 \end{cases}$
  - **证明**：
    - $r\geq 1$ 时
      - 显然 $x^r$ 是凸函数，由三角不等式 + 琴生不等式即得 $|\frac{X_1+X_2}{2}|^r \leq \frac{|X_1|^r + |X_2|^r}{2}$，两边取期望即可
    - $0<r<1$ 时
      - 三角不等式 + 通分放缩得 $|X_1+X_2|^r \leq \cfrac{|X_1|+|X_2|}{(|X_1|+|X_2|)^{1-r}} \leq |X_1|^r+|X_2|^r$

### 实例

- **应用**：
    - **二维推一维**：$X\sim N(0,1)，EX^2 = \frac{E(X^2+Y^2)}{2} = 1$
    - **分解**：
      - 二项分布分解为n个伯努利分布，超几何分布分解为n个抽签问题
      - 配对问题，分解为 $X_i=第i个元素正确配对$，概率为 $P(X_i=1) = \frac{A^{n-1}_{n-1}}{A^n_n}$，从而利用线性即可
  - $E|X|=0 \longleftrightarrow P(X=0)=1$
    - 以概率1发生：$X=0\ wp1.$(with probability 1)
    - 几乎处处必然：$X = 0\ a.s.$


## 方差

- **符号约定**：
  - $\sigma_X^2$ 和 $\Var(X)$ 表示随机变量 $X$ 的方差
  - $\sigma_X$ 表示随机变量 $X$ 的标准差
  - $\mu_X$ 和 $EX$ 表示随机变量 $X$ 的数学期望
  - <font color='red'>数学期望不是算数平均值，是加权平均值</font>
- **方差（加权方差）**：若随机变量的数学期望收敛，则方差定义为 $\Var(X) = E(X-\mu)^2$
- **标准差**： $\sigma_X = \sqrt{\Var(X)}$
- **存在性**：若 $X$ 存在二阶矩，即 $X\in L^2$，则方差存在（有限）
- **唯一性**：
- **矩空间关系定理**：$L^2\subset L^1$
  - <font color='red'>方差存在则数学期望必定存在
  - 注意：一般的测度空间不满足，必须是概率测度才行</font>
  - **证明**：
    - 设 $X\in L^2$，$Y\equiv 1$
    - 则由C-S不等式即得 $E|X| = E(|X|\cdot 1) \leq \|X\|_2\|1\|_2 = \sqrt{E(X^2)}$，从而有限
- **计算公式**：
  - **完全平方展开**：$\Var(X) = EX^2-(EX)^2$
    - <font color='red'>这是最基础的方法，计算时应当首先尝试</font>
    - **证明**：
      - 由独立乘法公式得 $E(X^2-2X\mu+\mu^2)$，再由期望线性即得结论
    - **理解**：方差的展开式，可以看作先算平方期望，再算普通期望，再作差。反正数学期望是唯一的，其具有所有代数性质（结合律、分配律、消去律等），不同计算顺序结果相同
  - **阶乘矩公式**：$\Var(X) = E[X(X-1)] + EX - (EX)^2$
    - <font color='red'>$E[X(X-1)]$ 称为二阶阶乘矩
    - 配凑幂函数的导数、配凑阶乘时都可以逐级使用</font>
    - **证明**：显然
    - **实例**：
      - $E[X(X-1)] = \sum\limits^\infty_{k=1} k(k-1)·p_k$

### 常见分布的方差

- **伯努利分布**：$X\sim \mathcal{B}(1,p)$：$\Var(X) = p(1-p)$
  - **证明**：<font color='chartreuse'>显然 $X^2=X$，完全平方展开即可</font>
- **二项分布**：$X\sim \mathcal{B}(n,p)$：$\Var(X) = np(1-p)$
  - **证明**：<font color='chartreuse'>阶乘矩公式 + 映射定理 + 组合数配凑</font>
- **泊松分布**：$X\sim \mathcal{P}(\l)$：$\Var(X)=\l$
  - **证明**：<font color='chartreuse'>分离 + 退化即可</font>
- **几何分布**：$X\sim G(p)$：$\Var(X) = \dfrac{1-p}{p^2}$
  - **证明**：<font color='chartreuse'>配凑二阶导数</font>
- **超几何分布**：$X\sim H(N,M,n)$：$\Var(X) = \frac{nM}{N}(1-\frac{M}{N})·\frac{N-n}{N-1}$
  - **证明**：
    - $EX = n\frac{M}{N}$
    - 把每次抽取的事件进行分解，变为伯努利分布的n个加和。
    - $EX_iX_j = P(X_i=1,X_j=1)$，两事件不独立，使用条件概率，得 $\frac{M-1}{N-1}·\frac{M}{N}$
    - 利用非独立线性公式
- **均匀分布**：$X\sim \mathcal{U}(a,b)$：$\Var(X) = \frac{(b-a)^2}{12}$
  - **证明**：<font color='chartreuse'>直接计算</font>
- **指数分布**：$X\sim \mathcal{E}(\l)$：$\Var(X) = \frac{1}{\l^2}$
  - **证明**：<font color='chartreuse'>直接计算</font>
- **正态分布**：$X\sim N(\mu,\sigma^2)$：$\Var(X) = \sigma^2$
  - **证明**：<font color='chartreuse'>已知 $EY^2 = 1$，映射定理即可</font>

### 性质

- **平方性**：$\Var(aX + b) = a^2\Var(X)$
  - **证明**：直接计算
- **最小性**：对任意 $c\neq \mu$ 都有 $\Var(X) = E(X-\mu)^2 < E(X-c)^2$
  - **证明**：数学期望添项分离 + 平方非负性
- **稳定意义**：$\Var(X)=0 \LR P(X=\mu) = 1$
  - **证明**：平方非负性 + 非负=0则必然
- **独立加法公式**：若 $X_1,...,X_n$ 独立，则 $\Var(\sum\limits^n_{j=1} X_j) = \sum\limits^n_{j=1} \Var(X_j)$
  - <font color='red'>实际上只需要不相关即可</font>
  - **证明**：若独立，则只有 $EX_j^2 - (EX_j)^2$ 不为0，再已知它就是 $\Var(EX_j)$
- **非独立加法公式**：$$\hspace{-0.5em}\Var(\sum\limits^n_{j=1} X_j) = \sum\limits^n_{i=1}\sum\limits^n_{j=1} \big[ E(X_iX_j) - \mu_i\mu_j \big] = \sum\limits^n_{j=1}\Var(X_j) - 2\sum\limits_{i\neq j} E(X_iX_j-\mu_i\mu_j)$$
  - <font color='red'>最右端式子中，前项是方差线性公式，后项是协方差
    - 即协方差是方差线性公式的余项，表示随机变量相关的部分</font>
  - **证明**：
    - 第一个等号是方差普通计算公式
    - 第二个等号是数学期望线性公式
- **标准化公式**：设 $Y = \cfrac{X-EX}{\sigma_X}$，则 $EX = 0，\Var(X) = 1$
  - **证明**：计算即可
- **独立的方差均值公式**：
  - 设 $X_1,...,X_n$ 是独立同方差的随机变量
  - 则 $\Var(\dfrac{1}{n}\sum\limits^n_{j=1}X_j) = \dfrac{1}{n}\sigma^2$
  - **证明**：
    - 由独立加法公式 + 方差平方性即得左式可化为 $\dfrac{n}{n^2}\sigma^2$

## 随即变量的相关性

### 内积

- **一阶矩空间的内积**：设 $X,Y$ 是存在数学期望的随机变量，则 $\lang X,Y\rang = E(XY)$ 是内积
  - **证明**：已知存在数学期望的随机变量构成线性空间 $L^1$，再由泛函知识易得它可定义内积
- **C-S不等式**：$|E(XY)| \leq \sqrt{EX^2EY^2}$
  - <font color='red'>本质就是判别式证明法</font>
  - **证明**：
    - 构造 $E(aX+bY)^2 = \begin{pmatrix} a,b \end{pmatrix}\begin{pmatrix} EX^2 & E(XY) \\ E(XY) & EY^2 \end{pmatrix}\begin{pmatrix} a\\b \end{pmatrix}$，是二次型
    - 平方的数学期望非负，因此 $\Sigma$ 满足非负定性，从而行列式 $\geq 0$，移项得到结果
  - **推论**：
    - 若存在 $a,b\neq 0$ 使得 $P(aX+bY=0) = 1$ 或 $E(aX+bY)^2=0$
    - 则等号成立
    - <font color='red'>本质就是 $X,Y$ 线性相关
    - $P$ 式子表示几乎处处线性相关
    - $E$ 式子表示平方积分为零，而平方值非负，故只可能是几乎处处为零（几乎处处线性相关）</font>

### 协方差

- **符号约定**：
  - $\sigma_X$ 表示 $X$ 的标准差
  - $\sigma_{XY}$ 或 $\Cov(X,Y)$ 都表示协方差
- **协方差**：$\Cov(X,Y) = E[(X-\mu_X)(Y-\mu_Y)]$
  - 还是二次，但是由两个一次混合的
- **计算公式**：$\Cov(X,Y) = E(XY) - (EX)(EY)$
  - <font color='red'>协方差的本质是随机变量的相关部分
    - 期望独立乘法公式的余项
    - 方差独立加法公式的余项</font>

### 相关性

- **相关系数 $\rho_{XY}$**：$ \rho(X,Y)= \cfrac{\sigma_{XY}}{\sigma_X\sigma_Y}$
  - <font color='red'>本质是向量的余弦
    - 如果将 $L^2$ 看作线性空间，则 $\sigma_{XY}$ 就是内积，$\sigma_X,\sigma_Y$ 就是长度
    - 余弦为 $1$ 表示共线，余弦为 $0$ 表示正交，其它值表示相关</font>
- **相关程度**：$|\rho| = E\dkh{\dfrac{X-\mu_X}{\sigma_X}}\dkh{\dfrac{Y-\mu_Y}{\sigma_Y}} \leq 1$
  - <font color='red'>这里的 $\dfrac{X-\mu_X}{\sigma_X}$ 就是随机变量的标准化（将值域变为 $[0,1]$）
  - 相关系数 $\rho$ 就是两个随机变量标准化后的协方差</font>
  - **证明**：
    - 第一个等号是显然的
    - 再易得 $E\dkh{ \dfrac{X-\mu_X}{\sigma_X} }^2 = 1$，再由C-S不等式即可
  - <font color='red'>余弦的取值范围</font>
- **相关性**：我们定义 $X,Y$ 不相关 $\LR \rho(X,Y) = 0 \LR \sigma_{XY}=0$
  - <font color='red'>不相关本质就是 $L^1$ 空间上向量的线性无关</font>
- **正线性相关性**：$\rho(X,Y) = 1 \LR$ 存在 $a > 0，b\in\R$ 使得 $P(Y = aX+b) = 1$
  - <font color='red'>几乎处处线性相关，此时C-S不等式取等
  - 如果值为 $-1$，则 $a < 0$，即负线性相关</font>
  - **证明**：计算易得
    - $\rho$ 不是变换矩阵的角度余弦，因为前面的二维正态分布中，标准化后 $Y_1,Y_2$ 同分布，但 $(X,Y)$ 标准化后也不同分布

### 独立性和相关性

- **独立不相关定理**：独立的随机变量必定不相关
  - **证明**：由数学期望的独立乘法公式直得
- **反例（不相关但不独立）**：
  - **定义域问题**：设 $(X,Y)$ 是单位圆内的均匀分布，则它们不相关，但不独立
    - **证明**：
      - 由对称性易得 $EX=EY=0$。再计算易得 $E(XY)=0$，从而不相关
      - 但定义域边界存在函数关系，故不独立
  - **概率公式问题**：设 $(X,Y)$ 在 $[0,1]^2$ 上有联合密度 $f(x,y) = \dfrac{1}{4}\Big[ 1+xy(x^2-y^2) \Big]$
    - **证明**：
      - 由于 $f$ 关于 $x,y$ 都是奇函数，故 $EX = EY = 0$
      - 计算易得 $E(XY) = 0$，故不相关
      - 但联合密度公式无法因式分解，从而不独立
    - <font color='red'>此时只能证明它们没有线性相关关系，但可能存在更高次数的相关关系</font>

## 随机矩阵的期望和方差

- **符号约定**：
  - 小写字母是向量，大写字母是矩阵
  - $E_X$，$\mu_X$ 表示随机矩阵的数学期望
- **随机矩阵的数学期望**：设 $Y = \tvec{Y_{11} & Y_{12} \\ Y_{21} & Y_{22}}$，则 $EY = \tvec{ EY_{11} & EY_{12} \\ EY_{21} & EY_{22} }$
  - <font color='red'>跟向量的定义一样</font>

### 期望的计算性质

- **转置公式**：$ (EY)^T = E(Y^T)$
  - <font color='chartreuse'>显然</font>
- **线性**：$E(aX + b) = aEX + b$
  - <font color='chartreuse'>显然</font>
- **常数乘法公式**：若 $A,B$ 是常数矩阵，则 $E(AXB) = AE(X)B$
  - <font color='chartreuse'>由矩阵线性直得</font>
- **独立乘法公式**：若 $X,Y,Z$ 彼此独立，则 $E(XYZ) = E(X)E(Y)E(Z)$
  - **证明**：由期望的独立乘法公式 + 期望和矩阵的线性，计算即可
  - **反例（两两不相关不行）**
