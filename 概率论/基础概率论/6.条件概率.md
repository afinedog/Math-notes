# 向量的相关性

- **符号约定**：
  - $A$ 一般表示条件事件
  - $f_X$ 表示 $X$ 的概率密度函数
- 视角：
  - 向量视角：条件事件有两个变量，X和Y，本质上是具有相关性的向量
  - 空间视角：$X$ 在 $Y_i$ 空间上的限制

## 条件分布

- **条件概率空间**：$(\Omega,\mathcal{F},P_A)$
- **条件事件**：$X|Y$ 表示事件 $Y$ 发生后事件 $X$ 也发生
  - 条件事件的取值：$A$ 发生后，$X\geq 0$，则为非负随机变量
  - 条件事件独立性：$\{X\leq x\}$ 和 A独立，则 $X和A独立$
  - 和1性 $\LR$ 全概率公式
- **条件随机变量**：$X|\{Y=y_j\}$ 表示 $Y$ 取 $y_j$ 时 $X$ 的取值
  - <font color='red'>给定的是 $Y$，变化的是 $X$</font>
- **离散型条件随机变量**：若 $X,Y$ 都是离散型随机变量，则 $X|Y$ 称为离散型条件随机变量
  - **概率公式**：设联合概率为 $p_{ij}$，$Y$ 的概率分布为 $q_j$，则 $P(X=x_i|Y=y_i) = \cfrac{p_{ij}}{q_i}$
    - <font color='red'>分子是离散分布，分母是边缘分布</font>
- **连续型条件随机变量**：若 $(X,Y)$ 是连续型随机向量，且 $f_Y(y) > 0$，则 $X|Y$ 称为连续型条件随机变量
  - **概率密度函数**：$f(x|y_i) = \cfrac{f(x,y_i)}{f_Y(y_i)}$
  - **分布函数**：$F(x|y) = P(X\leq x|Y=y) = \dis\int^x_{-\infty} \frac{f(s,y)}{f_Y(y)}ds$
    - <font color='red'>它是个含双参变量的上限函数，是二元函数</font>

### 条件事件的独立性

- **条件独立定理**：$X、Y$ 独立与下列条件等价
  - $f(x|y) = f_X(x)$
    - <font color='chartreuse'>由概率密度的独立乘法公式直得</font>
  - $F(x|y) = F_X(x)$
    - <font color='chartreuse'>计算易得</font>

### 条件数学期望

- **条件数学期望**：$E_{y_i}X = E(X|Y=y_i) = \sum\limits^\infty_{j=1} x_jP(X=x_j|Y=y_i)$
  - **离散型**：$E(X|Y = y_i) = \sum\limits^\infty_{j=1} x_j\cfrac{p_{ij}}{q_i}$ 
  - **连续型**：$E(X|Y = y_i) = \dis\int^\infty_{-\infty} x\cfrac{f(x,y_i)}{f_Y(y_i)}dx$
- **示性函数定理**：$E(X|A) = \cfrac{E(X\chi_A)}{P(A)}$
  - **证明（定义法）**：
    - 显然 $\{X>x\}\cap \{A\} = \{X\chi_A>x\}$，然后用条件概率公式即可

### 数学期望的条件写法

- **数学期望的全概率公式**
  - 若 $A_i$ 是完备事件组，则 $EX = \sum\limits^\infty_{i=1} P(A_i)E(X|A_i)$
  - **离散型**：$EX = \sum\limits^\infty_{i=1} \Big[ E(X|Y=y_i)\cdot P(Y=y_i) \Big]$
  - **连续型**：$EX = \dis\int^{+\infty}_{-\infty} \Big[ E(X|Y=y)\cdot f(y) \Big]dy$
  - **证明**：由事件组完备性 + 全概率公式 + 期望定义，计算即可
- **数学期望的嵌套形式**：$EX = E\big[ E(X|Y) \big]$
  - **证明**：由上面的全概率公式直得


### 习题

- $P(X^2=k)$ 和 $EX^2$ 的区别：前者是 $X^2$ 的取值的概率，后者是 $X^2$ 的取值的均值。这么理解就可以。而我以前习惯把 $X^2$ 先逆投影到X上，这是微分法的思想。但微分法的思想不能用到数学期望中来。
- 独立同分布，$S_n = \sum\limits^n_{i=1}X_i$，则 $E(X_i|S_n) = \frac{1}{n}\sum\limits^n_{j=1}X_j$（同分布下，数学期望相等，且独立加和公式）
- 答题格式
  - **函数形式的期望**：$E(X|Y=y) = y$（y为参数）
  - **含参期望**：$E(X|Y) = Y$
  - **含参变量形式的密度**：$f(X|Y)$（y为参数）

### 条件正态分布


- **条件正态分布**：
  - 设 $(X,Y)\sim N(\mu_1,\mu_2;\sigma_1^2,\sigma_2^2;\rho)$
  - $\mu_y = \mu_1 + \rho\frac{\sigma_1}{\sigma_2}(y-\mu_2)$、$\sigma_y^2 = (1-\rho^2)\sigma_1^2$
  - 计算得到 $f_{X|Y}(x|y)\to N(\mu_y,\sigma_y^2)$
  - 然后根据正态分布的形式，确定为条件正态分布的期望和方差
  - $X|\{Y=y\} \sim N(\mu_1 + \rho\frac{\sigma_1}{\sigma_2}(y-\mu_2)，(1-\rho^2)\sigma_1^2)$

## 极值分布

- **顺序统计量**：
  - 取一组样本 $X_1,...,X_n$，设它们的某个统计量的相应观测值为 $x_1,...,x_n$
  - 将观测值从小到大排列为 $x_{(1)},...,x_{(n)}$，则它们构成随机变量 $X_{(1)},...,X_{(n)}$
  - 此时 $X_{(1)}$ 称为最小值变量，$X_{(n)}$ 称为最大值变量，$(X_{(1)},...,X_{(n)})$ 称为顺序统计量
- **非独立同分布性**：原始样本通常独立同分布（总体的分布相同），但顺序统计量不独立也不同分布

### 最值的分布

- 最值其实就是 $max(X_i)、min(X_i)$，它的分布求法前面已经有了，用定义法即可
- **最大值变量 $X_{(n)}$**：
  - **分布函数**：$F(x) = \big[ F(x) \big]^n$
  - **概率密度函数**：$f(x) = nf(x)\big[ F(x) \big]^{n-1}$
  - **证明**：
    - 显然 $F(x) = P\dkh{\mathop{\bigcap}\limits^n_{i=1} \{X_{(i)} \leq x\}}$，由独立性得 $= \prod\limits^n_{i=1} P(X\leq x)$，再由同分布性即得结论
    - 
- **最小值变量 $X_{(1)}$**：
  - **分布函数**：$F(x) = 1-\big[ 1-F(x) \big]^n$
  - **概率密度函数**：$f(x) = nf(x)\big[ 1-F(x) \big]^{n-1}$
  - **证明**：
    - **Jordan法**：$F(x) = P\dkh{\mathop{\bigcup}\limits^n_{i=1} \{X_{(i)} \leq x\}}$
      - <font color='chartreuse'>（这里要用Jordan加法公式，太麻烦，换一种方法）</font>
    - **反向法**：$F(x) = 1-P(X_{(1)}>x) = 1-\prod\limits^n_{i=1}P(X_i>x)$
    - 再由导数性即得概率密度函数
- **最值向量 $(X_{(1)},X_{(n)})$**：
  - **联合分布函数**：$F(x_1,x_n) = [F(x_n)]^n - [F(x_n)-F(x_1)]^n$
  - **联合密度函数**：
  - **证明**：
    - $F_{1,n}(x_1,x_n) = P\ddkh{X_{(1)}\leq x_1，X_{(n)} \leq x_n}$
    - 添项作差课化为 $P\ddkh{X_{(n)}\leq x_n} - P\ddkh{X_{(1)}>x_1，X_{(n)}\leq x_n}$
    - 显然前项就是最大值分布函数
    - 显然后项可化为 $P\dkh{\mathop{\bigcap}\limits^n_{j=1}\{x_1 < X_j\leq x_n\}} = \prod\limits^n_{j=1} P(X_1<X_j \leq X_n)$

### 顺序统计量

- **顺序统计量 $(X_{(1)},...,X_{(n)})$**：
  - **联合分布函数**：$F(x_1,...,x_n) = F()$
  - **联合密度函数**：$f(x_1,...,x_n) = n!f(x_1)...f(x_n)$
  - 大小排序依赖于 $x_i$ 的值，和随机变量序号没有关系，所以取 $X$ 全排列即可
  - $P(X_{(1)} = x_1,...,X_{(n)} = x_n) = P(\mathop{\bigcup}\limits_{i\in I} \{X_{i_1}=x_1,...,X_{i_n}=x_n\}) = n!P(X_1 = x_1,...,X_n = x_n)$
- **单个统计量 $X_{(k)}$**：
  - **分布函数**：$F_k(x) = \sum\limits^n_{j=k} C^j_n \big[F(x)\big]^j \big[ 1-F(x) \big]^{1-j}$
  - **概率密度函数**：$f_k(x) = nC^{k-1}_{n-1} \big[ F(x) \big]^{k-1} \big[ 1-F(x) \big]^{n-k}f(x)$
  - **证明**：
    - $P(X_{(k)} = x) = C^{k-1}_nC^1_{n-k+1} P\dkh{\mathop{\bigcap}\limits^{k-1}_{i=1}\{X_i<x\}, X_k=x, \mathop{\bigcap}\limits^\infty_{j=k+1}\{X_j>x\}}$
    - 再使用独立乘法公式即可
- **任意二个统计量$(X_{(i)},X_{(j)})$，$(i<j)$**
  - **联合分布函数**
  - **联合密度函数**：$$\hspace{-3.7em} f(x,y) = C^{i-1}_nC^{j-i-1}_{n-i+1}C^{n-j}_{n-j+2}C^1_2 \cdot [F(x)]^{i-1}·[F(y)-F(x)]^{j-i-1}\cdot [1-F(y)]^{n-j}f(x)f(y)$$
  - **证明**：计算 $P(X_{(i)} = x, X_{(j)} = y)$ 即可

## 母函数

- **符号约定**：
  - 本部分的随机变量均为离散型，取值均为非负整数
  - 为了方便，规定 $0^0 = 1$
  - $g_X$ 表示随机变量 $X$ 的母函数
- **概率母函数**：$g_X(s) = E(s^X) = \sum\limits^\infty_{j=0} s^jP(X=j)，s\in [-1,1]$
  - <font color='red'>类似组合数学中的母函数</font>
- **计算性质**：
  - **概率分布**：$p_k = P(X=k) = \cfrac{g^{(k)}(0)}{k!}$
    - **证明**：计算即可
  - **数学期望**：$EX = g'(1)$
    - **证明**：计算即可
  - **独立加法公式**：设 $Y=\sum\limits^n_{i=1}X_i$，则母函数 $g_Y(s) = \prod\limits^n_{i=1}g_i(s)$
    - **证明**：计算即可
- **应用**：
  - 等概率事件，化为等比数列求和，简化计算
  - 母函数 $\LR$ 分布/期望（**无简化意义**）
  - 求解线性分布
    - **再生性**：二项分布、泊松分布
    - **Taylor级数**：$\sum\limits^\infty_{k=1} C^k_n s^k = (1+s)^k$
    - **减法**：$X-Y$ 的母函数：$E(s^{X-Y}) = E(s^X)E((s^{-1})^Y) = g(s)g(s^{-1})$

### 母函数复合公式

- **数量随机的独立同分布随机变量之和**：
  - 设 $N$ 是随机变量，$X_1,...,X_N$ 相互独立同分布，$Y = \sum\limits^N_{j=1} X_j$
  - 若 
    - $N$ 的母函数 $f(s) = \sum\limits^\infty_{i=1} s^iP(N=i)$
    - $X$ 的母函数 $g(s) = \sum\limits^\infty_{j=0} s^jP(X=j)$
  - 则 
    - $Y$ 的母函数 $h(s) = \sum\limits^\infty_{h=0} s^hP(Y=h) = f(g(s))$
  - **证明**：
    - 显然 $P(Y=h) = \sum\limits^\infty_{i=1}P(N = i\mid X_1+...+X_i = h)$
    - 则由母函数定义得 $h(s) = \sum\limits^\infty_{h=0} P(N=i)\sum\limits^\infty_{i=1}P(X_1+... + X_i = h) s^h = \sum\limits^\infty_{h=0} P(N=i) \big[ g(s) \big]^i$
- **复合定理**：
- **实例**：
  - **复合泊松分布**：$h(s) = e^{\l(g(s)-1)}$

### 常用分布的母函数

- **二项分布**：$X\sim \mathcal{B}(n,p)$：$g(s) = (1-p + sp)^n$
- **泊松分布**：$X\sim \mathcal{P}(\l)$：$g(s) = e^{\l(s-1)}$
- **几何分布**：$X\sim G$：$g(s) = \cfrac{sp}{1-s(1-p)}$


## 特征函数

- **复值随机变量**：设 $X,Y$ 是随机变量，则 $Z= X+iY$，称为复值随机变量
  - **数学期望**：$EZ = EX + iEY$
  - **方差**：$\Var(Z) = E\Big[ (Z-EZ)\ol{(Z-EZ)} \Big]$
  - <font color='chartreuse'>直接计算即可</font>
- **特征函数**：设 $X$ 是随机变量，则 $\phi(t) = Ee^{itX}$ 称为它的特征函数
- **密度函数特征公式**：设 $f$ 是 $X$ 的概率密度函数，则 $\phi(t) = \dis\int^\infty_{-\infty} f(x)e^{itx}dx$
  - <font color='red'>特征函数是密度函数的傅里叶逆变换</font>
  - **证明**：
- **分布函数特征公式**：$F(b)-F(a) = \dis\frac{1}{2\pi} \lim\limits_{T\to \infty} \int^T_{-T} \frac{e^{-ita}-e^{-itb}}{it}\phi(t)dt$
  - <font color='red'>分布函数（左）和特征函数（右）的转化公式</font>
  - **证明**：
    - 右式做傅里叶逆变换，则特征函数化为密度函数积分
    - 易得变换后依然可积，积分换序化为 $\dis\int_\R g(T,x,a,b)f(x)dx$
      - 其中 $g(T,x,a,b) = \dis\frac{1}{\pi}\int^T_0 \dkh{ \frac{\sin [t(x-a)]}{t} - \frac{\sin [t(x-b)]}{t} } dt$
    - 由狄利克雷积分结果得 $\lim\limits_{T\to\infty} g = \begin{cases} 0, & 其它 \\\frac{1}{2}, & x=a或b \\1, & x\in(a,b) \end{cases}$
    - 最后用N-L公式计算积分即可
  - **理解**：
    - 就是根据Fourier变换 + N-L公式
  - **推论**：
    - **唯一性**：分布的特征函数唯一
      - **证明**：显然特征函数可唯一确定分布函数（在分布函数特征公式中令 $a\to-\infty,b=x$ 即可）
    - **控制性**：若特征函数绝对可积，则分布函数连续可微
      - **证明**：微分不等式得控制条件，再由控制收敛定理即可

### 特征函数的基本性质

- **有界性**：$|\phi(t)| \leq 1$
  - **证明**
    - 由欧拉公式得 $|\phi(t)| = |E\cos(tX) + iE\sin(tx)|$
    - 再由C-S不等式得 $(E\cos(tX))^2 \leq E\cos^2(tX)$，$\sin$ 同理
    - 最后由三角不等式即得结论
- **共轭反号性**：$\phi(-t) = \overline{\phi(t)}$
  - **证明**：欧拉公式即可
- **独立加法公式**：设 $X_1,...,X_n$ 彼此独立，$Y=\sum\limits^n_{i=1}X_i$，则 $\phi_Y(t) = \prod\limits^n_{i=1}\phi_i(t)$
  - **证明（归纳法）**
    - 显然 $Ee^{itY} = E[e^{itX_1}...e^{itX_n}]$，再由期望的独立乘法公式即可
- **一致连续性**：特征函数在 $\R$ 上一致连续
  - **证明**：
    - 一致连续定义 + 欧拉公式，分区间讨论 + 积分上界不等式
- **非负定性**：对任意实数列 $\{t_n\}$ 和复数列 $\{\l_n\}$，有 $\sum\limits^n_{k=1}\sum\limits^n_{j=1} \phi(t_k-t_j)\l_k\overline{\l_j}\geq 0$
  - **证明**：
    - 乘积分解 + 共轭化模可得 $E|\sum\limits^n_{k=1} e^{it_kX}\l_k|^2$，显然它非负

### 特征函数的判定


- **Bochner–Khinchin定理**：设 $\phi:\R\to \C$，则它是某个概率分布的特征函数 $\LR$ 它满足下列三个条件
  - **归一化**：$\phi(0) = 1$
  - **连续性**：$\phi$ 在 $\R$ 上一致连续
  - **非负定性**
  - <font color='red'>即特征函数是某个概率测度的傅里叶变换</font>
  - **证明**：
  - **推论**：特征函数的非负定性 + 连续性 = 一致连续性

### 特征函数的解析性

- **可微性**：若 $X\in L^n$，则特征函数可 $n$ 阶微分，$\phi^{(k)}(0) = i^kE(X^k)$
  - **证明**：
- **解析定理**：
  - 设 $X$ 是随机变量
  - 若
    - $X$ 的任意阶矩存在
    - 泰勒展开式的余项存在绝对收敛半径 $t_0$，即 $\forall |t|\leq t_0$ 都有 $\lim\limits_{n\to\infty} \dfrac{E|X|^n}{n!}|t|^n = 0$
  - 则特征函数可展开为 $\phi(t) = \sum\limits^\infty_{n=0}\dfrac{EX^n}{n!}(it)^n$
  - **证明**：
    - 作差 + 逆用期望线性 + 期望绝对值不等式，得到余项


### 特征函数的封闭性

- **幂封闭性**：特征函数的正整数幂还是特征函数
  - **证明**：由独立加法公式直得
- **模平方封闭性**：$|\phi(t)|^2$ 也是特征函数
  - **证明**：设 $X$ 和 $Y$ 独立同分布，$Z = X-Y$，则 $\phi_Z(t) = \phi(t)\overline{\phi(t)} = |\phi(t)|^2$
  - **反例（绝对值不是特征函数）**：
- **凸组合封闭性**：
  - 设 $\{\phi_n(t)\}$ 是一列特征函数，$\{p_n\}$ 是凸组合系数
  - 则特征函数的凸组合 $f(t) = \sum\limits^\infty_{n=1} p_n\phi_n(t)$ 也是特征函数
  - **证明**：
    - 特征函数的凸组合与分布函数的凸组合一一对应
      - 由特征函数一致收敛性，交换积分即可
    - 分布函数的凸组合还是分布函数
  - **实例**：
    - 随机取下标的随机变量和，其特征函数也是凸组合
