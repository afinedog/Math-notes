# 调和方程边值问题解的性质

- **思想**：
  - 上一节只叙述了基本解和卷积解的性质。它们是全空间上的解，但并不是边值问题的解
  - 现在我们讨论有界开区域上，边值问题的解（调和函数）的性质
    - 此时我们甚至都不能确定边值问题的解是否存在、是否唯一、解是什么，只是在做先验估计
    - 但实际上，通过分析拉普拉斯算子本身的极好性质，能得到下面大量惊人的结论
- **主线**：本章的分析有两种主要方法
  - **极值法**：通过拉普拉斯算子本身的性质（调和函数的均值定理）分析，得到结论更多
  - **能量法**：通过构造能量泛函进行分析，适用于绝大多数方程，但结论更弱

## 概念的扩充

- **广义调和函数**：若 $u$ 在 $U$ 内部调和，在 $\pa U$ 上一阶连续可微，则称它在 $\ol U$ 上调和
  - <font color='red'>如果只是取定义域为闭包的话，边界处一般无法定义法向导数，所以我们必须人为假定 $u$ 在边界上连续可微
  - 在此意义下，我们同样把调和函数的定义进行拓展</font>
- **符号约定**：
  - 以后默认闭包上的调和就是广义调和
  - 以后默认边值问题的解至少在边界处一阶光滑

## 传递性

- **线性传递性**：
  - <font color='red'>线性算子和拉普拉斯算子可交换</font>
  - **证明**：由微分的线性传递性直得
- **导数传递性**：设 $u\in C^3$，若 $u$ 调和，则 $\forall 1\leq i\leq n，u_{x_i}$ 也调和
  - <font color='red'>微分算子和拉普拉斯算子可交换</font>
  - **证明**：此时 $u\in C^3$，连续可微，故可混合求偏导。对Laplace方程取偏微分即得结论
- **卷积传递性**：若卷积存在，则调和函数和任意函数的卷积也调和
  - <font color='red'>卷积算子和拉普拉斯算子可交换</font>
  - **证明**：
    - 设 $v$ 调和，则由微积分结论得 $\D (v*f) = \D v*f = 0*f = 0$

## 均值性

- **均值定理**：若 $u\in C^2(U)$ 调和，则 $u(x) = \aintp udS = \aintb udy\\$ 对 $U$ 中任意球成立
  - **证明（表面积）**：
    - 设 $\phi(r) = \aintp u(y)dS(y)$
    - 换元 $y = x+rz$，得 $\phi(r) = \aint{\pa B(0,1)}{3.1}u(x+rz)dS(z)$
    - 对其求导，由链式法则得 $\phi'(r) = \aint{\pa B(0,1)}{3.1}Du(x+rz)\cdot zdS(z)$
      - <font color='chartreuse'>换元后，由微分向量形式的结论，$S(y)$ 变成 $r^{n-1}S(z)$，同时积分域 $\pa B(x,r)$ 变成 $\pa B(0,1)$，由移动区域变为固定区域。也就是说，这一步换元的本质是把积分域的微分转移为函数的微分，避免使用移动区域微分公式（但实际上用移动区域微分公式也不难做）</font>
    - 此时 $z$ 是边界法向量，故 $\phi'(r) = \aintp \dpfrac{u}{\nu}dS(y)$
    - 再由第一格林公式即得 $\phi'(r) = \dfrac{r}{n}\aintb \D u(y)dy = 0$
      - <font color='chartreuse'>因为是均值积分，而表面积和体积有差值，从而导出了 $\dfrac{r}{n}$</font>
    - 从而 $\phi$ 为常函数，也即 $\phi(r) = \lim\limits_{r\to 0}\phi(r) = u(x)$
  - **证明（体积）**
    - 已知球体积等于表面积的径向积分，故 $\dis\int_{B(x,r)}udy = \int^r_{0}\dkh{\int_{\pa B(x,s)}udS}ds$
    - 由表面积均值定理，表面积积分可化为 $n\a(n)s^{n-1}u(x)$
    - 由于被积变量为 $y$，故 $u(x)$ 可提出积分，原式变为表面积径向积分，结果为 $\a(n)r^nu(x)$
    - 求均值即得结果
  - **理解**：通过求导化为 $\D u$，从而可应用调和性质得到结论
- **均值调和性**：若 $u\in C^2(U)$ 满足均值定理，则其调和
  - **证明**：反设 $\D u \not\equiv 0$，则存在 $B(x,r)$ 使得其上 $u>0$，即 $\phi'(r) > 0$，矛盾
- **强最大值原理**：
  - 设 $u\in C^2(U) \cap C(\ol U)$ 在 $U$ 上调和
  - 则 $\max\limits_{\ol U} u = \max\limits_{\pa U} u$
  - **证明**：
    - 反设内部存在最大值点 $x_0$，则由均值定理，$M = u(x_0) = \aint{B(x_0,r)}{3}udy \leq M$
    - 此时只能是球内恒为最大值
    - 再由此时最大值区域是所有 $\{B(x_0,r)\mid x_0 是最大值点\}$ 的并，球链法得该区域为闭开集
    - 拓扑连通性定义得 $U$ 连通时，其内部闭开集只能是 $U$ 本身（**证毕**）
  - **推论**：若 $U$ 连通且能取 $u$ 最大值，则 $u$ 是常函数
  - **本质**：球链法

## 解的唯一性

- **解的唯一性定理**：
  - 设 $g\in C(\pa U)，f\in C(U)$
  - 则泊松边值问题最多存在一个解 $u\in C^2(U) \cap C(\ol U)$
  - **证明（最大最小夹逼）**：
    - 反设存在两个解 $u_1,u_2$，易得 $w = \pm(u_1-u_2)$ 也是调和函数
    - 由强最大值原理，两种情况下均有 $w \leq (u_1-u_2)|_{\pa U} = 0$，从而 $u_1 \equiv u_2$
  - **证明（能量方法）**：见后面

## 光滑性

- **调和函数的光滑性**：若 $u\in C(U)$ 满足均值定理，则 $u\in C^\infty(U)$
  - **证明**：
    - 设 $\eta$ 是标准磨光子，其为径向函数，设 $u$ 的磨光为 $u^\e$，只需证明 $U_\e$ 上 $u\equiv u^\e$ 即可
    - 由定义 $u^\e(x) = \dfrac{1}{\e^n}\dis\int_{B(x,\e)}\eta(\ts\dfrac{|x-y|}{\e})u(y)dy$

## 局部估计

- **导数估计定理**：
  - 设 $u$ 在 $U$ 上调和
  - 则 $\forall B(x_0,r)，\forall |\a| = k$，都有 $|D^\a u(x_0)| \leq \large\frac{C_k}{r^{n+k}} \|u\|_{L^1\dkh{B(x_0,r)}}$ 
  - 其中 $C_0 = \dfrac{1}{\a(n)}，C_k = \dfrac{(2^{n+1}nk)^k}{\a(n)}$
  - <font color='red'>具体的系数值其实无关紧要，我们关心的是：解的任意阶导数都可被积分控制，即索伯列夫空间可连续嵌入 $L^1$ 空间</font>
  - **证明（归纳法）**：
    - $k=0$ 时，其即为均值定理
    - $k=1$ 时，由微分保调和性，取 $B(x_0,\dfrac{r}{2})$ 上的体积均值公式，用格林定理化为表面积积分，然后再取均值积分，即得 $$|u_{x_i}(x_0)| = \biggm| \frac{2n}{r}\aint{\pa B(x_0,\frac{r}{2})}{3.6} u\nu^idS \biggm|$$
      <!-- - $$|u_{x_i}(x_0)| = \biggm| \frac{1}{\a(n)(\frac{r}{2})^n}\int_{\pa B(x_0,\frac{r}{2})} u\nu^i dS \biggm|$$  -->
      - 再由积分上界不等式即得 $原式 \leq \ts\dfrac{2n}{r}\|u\|_{L^\infty\Big(\pa B(x_0,\frac{r}{2})\Big)}$
        - <font color='chartreuse'>由最大值原理，$u$ 在边界上取到最大值。故本性上确界中的 $\pa B$ 可替换成 $B$</font>
      - 再由均值定理，放缩积分域得 $|u(x)| \leq \cfrac{1}{\a(n)(\frac{r}{2})^n}\|u\|_{L^1\Big( B(x_0,r) \Big)}$
      - 综合两个结论即得所需不等式
    - $k-1$ 前均成立时，以 $(D^\b u)_{x_i}$ 为例（其中 $|\b| = k-1$）
      - 同上得 $|D^\a u(x_0)| \leq \dfrac{nk}{r}\|D^\b u\|_{L^\infty(\pa B(x_0,\frac{r}{k}))}$
      - 再由归纳假设，$|D^\b u(x)| \leq \cdots$
      - 综合两个结论即得所需不等式
  - **理解**：本来更好的想法是不要前面那个 $C_k$ 系数的。但因为积分上界不等式中取的是本性上确界，我们不能保证 $\|u\|_{L^\infty} \leq |u|$，故只好在积分域上再进行一次放缩。那么一开始设的积分域就要小一些，比较规律的逐渐缩小积分域的取法就是 $B(x_0,\dfrac{r}{k})$

## 解析性

- **刘维尔定理**：设 $u:\R^n\to \R$ 有界调和，则其为常函数
  - <font color='red'>调和方程在无界区域上不可能存在有界解</font>
  - **证明**：
    - 任取 $x_0\in \R^n，r>0$
    - 由导数估计 + 积分上界不等式，$$|Du(x_0)| \leq \cfrac{\sqrt{n}C_1}{r^{n+1}}\|u\|_{L^1(B(x_0,r))} \leq \cfrac{\sqrt{n}C_1\a(n)}{r} \|u\|_{L^\infty(\R^n)}\to 0$$
- **卷积表示公式**：
  - 设 $f\in C^2_c(\R^n)，n\geq 3$，$\Phi$ 是拉普拉斯方程的基本解
  - 则任何泊松方程的有界解都可表为 $$u(x) = \dis\int_{\R^n} \Phi(x-y)f(y)dy  + C$$
  - 其中 $C$ 仅依赖于边值 $g$
  - <font color='red'>右端函数可看作狄拉克函数的加权叠加（源项看作所有点源的叠加），卷积就是平移（取对称）再加和（取乘积积分）的操作</font>
  - **证明**：前面已证
  - **反例（必须是基本解）**：
    - 若取全空间调和函数，则由调和函数的卷积传递性得 $\D (v*f) = 0$，不是解
- **调和函数解析性**：在区域 $U$ 上调和的函数也在 $U$ 上解析
  - **证明**：
    - 只需证明幂级数余项 $\to 0$
    - 任取 $x_0\in U$，设 $r = \dfrac{\dist(x_0,\pa U)}{4}$，$M = \dfrac{1}{\a(n)r^n}\|u\|_{L^1(B(x_0,2r))} < \infty$
    - **引理**：$\|D^\a u\|_{L^\infty(B(x_0,r))} \leq CM\dkh{\dfrac{2^{n+1}n^2e}{r}}^{|\a|}\a!$
      - 由导数估计定理，$左式 \leq M\dkh{\dfrac{2^{n+1}n}{r}}^{|\a|} |\a|^{|\a|}$
      - 再由泰勒展开得 $\dfrac{k^k}{k!} < e^k$，从而 $|\a|^{|\a|} \leq e^{|\a|}|\a|!$
      - 再由多项式定理，$n^k = \sum\limits_{|\a| = k} \dfrac{|\a|!}{\a!}$，从而 $|\a|! \leq n^{|\a|}\a !$
      - 综上放缩三次即可
    - 已知 $x_0$ 处泰勒展开式为 $\sum\limits^\infty_{|\a|=1} \dfrac{D^\a u(x_0)}{\a!} (x-x_0)^\a$
      - 设 $|x-x_0| < \dfrac{r}{2^{n+2}n^3e}$<font color='chartreuse'>（先给定一个猜想收敛域，再验证其收敛）</font>
      - 设 $R_N(x)$ 是 $|\a| = N$ 后的Peano余项，则由 $u$ 的连续性，$x-x_0$ 方向上必定存在某个 $x_0$ 的相邻点 $t(x-x_0)$，满足其上的值等于该余项。即此时 $$|R_N(x)| = \biggm| \sum_{|\a|=N} \frac{D^\a u\Big(x_0+t(x-x_0)\Big)}{\a!} (x-x_0)^\a \biggm|$$
        - 由C-S不等式 + $L^\infty$ 上界性 + 引理不等式 + 收敛域假设，最终得 $$|R_N(x)| \leq CM \frac{n^N}{(2n)^N} \to 0\quad (N\to\infty)$$，从而展开式收敛
- **Harnack不等式**：
  - 设 $V\Subset U$ 是两个连通开集，$u>0$ 是 $U$ 上的调和函数
  - 则存在只依赖于 $V$ 的常数 $C > 0$ 满足 $\sup\limits_{V} u \leq C\inf\limits_{V} u$
  - <font color='red'>若调和函数非负，则最大值和最小值存在固定比例
  - 这里最关键的是 $C$ 和 $u$ 无关，即非负调和函数空间存在一致的比例，从而非负调和函数列具有良好性质</font>
  - **证明**：
    - 设 $r = \dfrac{1}{4}\dist(V,\pa U)$，任取 $x,y\in V$ 满足 $|x-y|\leq r$
    - 则由 $u>0$ + 积分域单调性得 $$u(x) = \aint{B(x,2r)}{3.1} udz \geq \dfrac{1}{\a(n)2^nr^n}\dis\int_{B(y,r)}\ts udz = \dfrac{1}{2^n}\aint{B(y,r)}{2.7} udz = \dfrac{u(y)}{2^n}$$
    - 因此 $2^nu(y) \geq u(x) \geq \dfrac{u(y)}{2^n} \quad (\forall x,y\in V,|x-y|\leq r)$
    - 再由 $V$ 的单连通性和紧含性，可使用有限圆链法传递不等式到整个 $V$ 上，最终系数依然有界。此时取两边一个是最大值，一个是最小值即可（**证毕**）
  - **理解**：
    - 用两次均值定理，第一个积分域取 $B(x,2r)$，则其包含 $B(y,r)$，将其取为第二个积分域，由于均值积分域的大小不同，故可得到存在系数 $2^n$ 的不等式

## 能量方法

- **思想**：
- **能量泛函**：$I[w] = \dis\int_{U}\ts \Big( \dfrac{1}{2}|Dw|^2 - wf \Big)dx$，其中 $w\in\mc A$
  - <font color='red'>它其实就是数值线性代数中，最速下降法的 $\p$，其最小值就是 $Dw = f$ 的解</font>
  - **容许集**：$\mc A = \hkh{w\in C^2(\ol U)\Bigm| w = g\pad (\forall x\in\pa U)}$
- **能量法证解的唯一性**：
  - **证明**：
    - 反设 $\wt u$ 是另一个解，设 $w = u-\wt u$
    - 此时 $\D w = 0$，从而 $\dis\int_U w\D wdx = -\int_U |Dw|^2dx = 0$，只能是 $Dw \equiv 0$，即 $w$ 为常函数
    - 再由于 $\pa U$ 上 $w = g-g = 0$，故 $w$ 在 $U$ 上恒为0
  - **本质**：和线性系统中证 $X_{NC}$ 的常解性思想相同，都是凑积分内平方，然后只能取零
- **能量法证解的稳定性**：
