# 基本群

- **符号约定**：
  - $h:(X,x_0)\to (Y,y_0)$ 表示 $h:X\to Y$ 将 $x_0$ 映射到 $y_0$

## 第一同伦群

- **环路**：首尾相同的道路
- **基本群（第一同伦群）**：$x_0$ 上环路的道路同伦类，赋予同伦积运算 $*$ 后，称为基点为 $x_0$ 的基本群 $\pi_1(X,x_0)$
  - **群性**：
    - **证明**：易得满足封闭性，再由前面的广群性即得结论
  - **实例**：
    - **平凡群**：基本群 $\pi_1(X,x_0)$ 同伦于**平凡路** $x_0\to x_0$
      - 凸空间中基本群只有平凡群
        - $\pi_1(\R^n,x_0)$ 是平凡群，仅存在恒等映射，其环路均同伦于单点道路 $\{x_0\}$
        - 其上凸子集也是平凡群
    - **圆周**：$S^1$ 上的基本群均为圆周

### 基本群与道路连通性

- **（定理52.1）基本群同构**：
  - 设 $\a$ 是 $x_0\to x_1$ 的道路
  - 则 $\wh\a : \pi_1(X,x_0)\to \pi_1(X,x_1)，[f]\mapsto [\ol \a]*[f]*[\a]$ 是同构
  - **证明**：
    - 保运算性：易得
    - 双射性：逆映射为 $\wh\b:[h]\mapsto [\ol \b] * [h] * [\b]$，其中 $\b = \ol \a$
  - **理解**：中间必须经过的定点是本来就被固定的两端点，故拼接后还是普通同伦类
- **（推论52.2）道路的基本群**：
  - 设 $X$ 是起始点为 $x_0,x_1$ 的道路，则 $\pi_1(X,x_0) \cong \pi_1(X,x_1)$
  - **证明**：
    - 同构映射为 $\wh X:[f]\mapsto [\ol X] * [f]  * [X]$
- **道路简化定理**：若 $C$ 是 $X$ 中包含 $x_0$ 的道路连通分支，则 $\pi_1(C,x_0) = \pi_1(X,x_0)$
  - <font color='red'>从此以后我们只需研究道路连通空间的基本群即可</font>
  - **证明**：
    - 从 $x_0$ 出发的任意道路都无法经过道路不连通的部分，故环路当然也不行

### 单连通和多连通

- **单连通空间**：基本群均平凡的道路连通空间
  - **符号表示**：$\pi_1(X,x_0) = 0$
- **$n$ 连通空间**：第 $n$ 同伦群均平凡的道路连通空间
  - <font color='red'>只用基本群无法定义 $n$ 连通空间</font>
- **（引理52.3）无洞定理**：单连通空间中，首尾相同的道路均道路同伦
  - **证明**：
    - 设 $\a,\b$ 是 $x_0\to x_1$ 的道路，则 $\a*\ol\b$ 是 $x_0$ 上的环路
    - 由单连通性，所有环路都零伦，从而 $[\a*\ol\b]*[\b] = [e_{x_0}]*[\b]$，从而 $[\a] = [\b]$
  - <font color='red'>两个道路是否同伦只需看空间有没有洞，如果两道路在某个洞的两侧则不同伦
  - 同伦群是观测空间洞数量的探针</font>

### 基本群的函子性

- **带基点的拓扑空间范畴**：$\Top_*$
  - **对象**：拓扑空间和其中某点的配对 $(X,x_0)$
  - **态射**：连续映射 $f:(X,x_0)\to (Y,y_0)$
- **基本群函子**：$\pi_1:\Top_*\to \Grp$
  - **对象作用**：$(X,x_0)\mapsto \pi_1(X,x_0)$
  - **态射作用**：诱导同态
- **诱导同态**：
  - 设 $h:(X,x_0)\to (Y,y_0)$ 是连续映射
  - 则 $h_*:\pi_1(X,x_0)\to \pi_1(Y,y_0)，[f]\mapsto [h\circ f]$ 是同态
  - <font color='red'>基本群函子将（拓扑范畴的连续映射）对应到（群范畴的群同态）</font>
  - **证明**：
    - 连续性：连续映射的复合传递性
    - 保运算性：$h_*(fg) = h\circ (f*g) = (h\circ f) * (h\circ g) = h_*(f)*h_*(g)$
  - **理解**：由连续保道路性，$h$ 也将原空间的环路映射到环路
  - **实例**：
    - 平凡映射的诱导同态是平凡的
    - 球包含映射的诱导同态：$j_*:\pi_1(S^n,x_0)\to \pi_1(B^{n+1},x_0)$
- **（定理52.4）诱导同态运算法则**：
  - **复合传递**：设 $\begin{cases} h:(X,x_0)\to (Y,y_0) \\\\ k:(Y,y_0)\to (Z,z_0) \end{cases}$ 都是连续映射，则 $(k\circ h)_* = k_*\circ h_*$
  - **恒等传递**：若 $i:(X,x_0)\to (X,x_0)$ 是恒等映射，则 $i_*$ 是恒等同态
  - **同胚传递**：同胚的诱导同态是同构
  - **证明**：
    - 定义验证易得
