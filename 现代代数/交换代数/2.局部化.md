# 局部化

- **思想**：
  - 通过取合适的乘法集构成分式环，可将交换环化为局部环
- **符号约定**：
  - $\p_S: R\to S^{-1}R，r\mapsto (rs)/s$ 表示分式环同态

## 分式环补充

- **分式扩张理想**：设 $A$ 是 $R$ 的理想，则 $A^c = \p_S(A)\cdot S^{-1}R$ 是 $S^{-1}R$ 的理想
  - **实例**：
    - $\p_{\N^+}(\N)\Q = \Q$
- **分式收缩理想**：设 $B$ 是 $S^{-1}R$ 的理想，则 $B^c = \p_S^{-1}(B)$ 是 $R$ 的理想
  - **实例**：
    - $\p^{-1}_{\N^+}(\Q) = \N$，删去了 $\Q$ 中所有真分数
- **对偶定理**：
  - **自反性**：$A^{cc} = \mathop{\bigcup}\limits_{s\in S} (A:S)$
    - **证明**：
  - **对称性**：若 $A = B^c$，则 $B = A^c$
    - **证明（互包）**：
      - 任取 $\dfrac{a}{s} \in A^c$
        - 此时 $\p_S(a)\in B$，从而 $\dfrac{a}{s} = \dfrac{1}{s}\dfrac{as}{s} = \dfrac{s}{\p_S(a)} \in J$，从而 $A^c \subset J$
      - 任取 $\dfrac{a}{s} \in B$
        - 此时 $\p_S(a) = \dfrac{as}{s} = \dfrac{a}{s}\dfrac{s^2}{s} \in J$
        - 从而 $r\in \p_S^{-1}(J) = I$，则 $r/s\in S^{-1}I$，即得 $J\subset S^{-1}I$

    - <font color='red'>将理想扩张为分式理想后，无论再怎么收缩，都不比原来小
    - 可为一一对应性提供引理</font>

    - **理解**：$S^{-1}I$ 是 $I$ 的扩张，其包含分式同态的像集 $\p_S(I)$。再由逆映射扩大性即得结论

## 环的局部化

- **$R$ 在 $P$ 上的局部化**：
  - 设 $R$ 是含幺交换环，$P$ 是素理想
  - 取乘法封闭集 $S = R\j P$，则 $R_P = S^{-1}R$ 称为 $R$ 在 $P$ 上的局部化

### 局部理想

- **局部化理想定理**：
  - 设 $A$ 是 $R$ 的理想，则 $A^c = S^{-1}A = \hkh{\dfrac{a}{s}\Bigm| a\in A，s\in S} \LR R_P$ 上的理想
    - **证明**：定义易得
  - **实例**：
    - $R = \Z，P = (2)，S = \set{2k+1}，R_P = \set{\dfrac{m}{2k+1}\mid m,k\in\N}$，其中可取某个 $I_P = \dfrac{3k}{2k+1}$

### 局部性

  - **限制对应性**：（$P$ 的素理想）和（$R_P$ 的素理想）保序对应
    - **证明**：
      - 由于 $P$ 中素理想也是 $R$ 上素理想，由素理想保序对应性可得双射 $R\to R_P$，再取其限制，易得也是双射
    - **实例**：
      - 在上面的整数环局部化中，$(6)$ 是 $P = (2)$ 中素理想，故存在双射 $f:(6)\to \dfrac{(6)}{2k+1}，6m\mapsto \dfrac{6m}{2k+1}$

### 习题

- **素理想自反性**：
  - 设 $f:A\to B$ 是环同态，$P$ 是 $A$ 的素理想
  - 则 $P$ 是 $B$ 中素理想的收缩 $\LR P^{cc} = P$
  - **证明**：
    - **必要性**：设 $P = Q^c$，则 $P^{cc} = Q^{ccc} = Q^c = P$
    - **充分性**：
      - 设 $S = f(A\j P)$，易得是乘法集，再由素理想收缩不变性得 $P^c\cap S = \varnothing$
      - 此时 $P^c$ 在 $S^{-1}B$ 中的扩张 $N$ 是真理想，设含于极大理想 $M$ 中
      - 设 $Q = M|_B$，$Q^c = Q|_{A}$，$R = N|_B$
      - **左包右**：
        - 由 $M\supset N$ 得 $Q\supset R \supset P^c$，从而 $Q^c \supset P^{cc} \supset P$
      - **右包左**：
        - 由于 $Q$ 是极大理想 $M$ 的限制，则由素理想保序对应性，$Q$ 是 $B$ 的素理想，且和 $S$ 无交
        - 由于 $S = f(A\j P)$，故 $f(A)\cap Q\supset f(P)$，故 $Q^c = f^{-1}(Q) \subset f^{-1}(f(P)) \subset P^{cc} = P$。从而 $Q^c = P，Q$ 是素理想


## 分式模


- **分式模**：
  - 设 $S$ 是环 $R$ 的乘法集，$M$ 是 $R$ 上的模
  - 则约分等价类 $S^{-1}M$ 是 $S^{-1}R$ 上的模
    - **加法**：$\dfrac{m}{s} + \dfrac{n}{t} = \dfrac{tm + sn}{st}$
    - **零元**：$\dfrac{0}{1}$
    - **数乘作用**：$\dfrac{a}{s}\dfrac{m}{t} = \dfrac{am}{st}$
- **实例**：
  - **自身分式模**：$S^{-1}R$ 是自身模
  - **分式理想模**：设 $A$ 是 $R$ 的理想，$S$ 是乘法集，则 $S^{-1}A$ 是分式模
  - **模的局部化**：设 $P$ 是素理想，$S = R-P$，则 $M_P = S^{-1}M$ 是 $R_P$ 模（$M$ 在 $P$ 处的局部化）
- **分式模同态**：
  - 设 $f:M\to N$ 是R模同态，$S$ 是 $R$ 的乘法集
  - 则映射 $S^{-1}f: S^{-1}M\to S^{-1}N，\cfrac{m}{s} \mapsto \cfrac{f(m)}{s}$ 是模同态

- **子模运算律**：

  - **交**：$S^{-1}(N\cap P) = S^{-1}N \cap S^{-1}P$
    - **证明**：
  - **同构**：$S^{-1}\cfrac{M}{N} \cong \cfrac{S^{-1}M}{S^{-1}N}$
    - **证明**：
- **正合性**：$S^{-1}$ 是正合算子
  - **证明（互包）**：
    - **核包像**：由正合性 $gf = 0$，故 $(S^{-1}g)(S^{-1}f) = S^{-1}(gf) = 0$，从而 $\Im (S^{-1}f) \subset \ker (S^{-1}g)$
    - **像包核**：
      - 设 $\dfrac{c}{s} \in \ker(S^{-1}g)$，则 $\dfrac{g(c)}{s} = \dfrac{0}{1} \in S^{-1}C$，从而存在 $t\in S$ 使得 $tg(c) = 0 \in C$
      - 再由同态性得 $g(tc) = 0$，从而 $tc\in \ker g = \Im f$
      - 即存在 $b\in B$ 使得 $tc = f(b)$，从而 $\dfrac{c}{s} = \dfrac{f(b)}{st} = (S^{-1}f)(\dfrac{b}{st}) \in \Im(S^{-1}f)$，即 $\ker(S^{-1}g) \subset \Im (S^{-1}f)$
